### 环境互动系统现状（`TS/系统/03．技能系统/04．快捷键技能/04．环境互动`）

- 技能 ID `A08E`（不是 `A0E8`），默认触发范围 300。
- API：`注册环境互动调查点` / `注销环境互动调查点` / `清理全部环境互动调查点`（`00．通用/01．环境互动核心.ts`）。
- 触发点接口：`{ID, X, Y, 触发范围?, 一次性?, 提示文本?, 延迟提示文本?, 奖励物品ID?, 触发回调}`。
- 语义：回调返回 `true` 且 `一次性 !== false` 时核心自动注销该点；返回 `false` 表示条件不满足、点保留。
- 已有内容：
  - `01．任务/01．失踪的精灵侍从`：任务 10024，精灵王城三处线索，纯推进任务目标（questDB.updateObjective）。
  - `02．旧环境互动`：9 种类型——水触手（召唤怪）、书架（+1 魔法恢复、+1% 魔法伤害）、精灵小屋（+1% 命中）、空木桩/树上物品（果实）、隐藏木桩（3 选 1 随机）、普通提示、Boss 入口（需英雄 ≥9 级）、物品奖励。
- 复用封装：特效 `lib.扩展函数.封装函数.01．通用工具.03．特效`（创建点特效 / createTimedEffect）、提示 `系统.09．表现系统.06．广播提示消息`、延时 `系统.00．核心系统.05．中心计时器` addDelayedCallback、物品 `lib.扩展函数.物品相关函数.创建物品函数`、属性存档 YDUserData 安全版、Buff `Star扩展库.04B．快速Buff接口`。

### 系统层待补（新增点位前建议先做）

1. 空挥无反馈：范围内无点/条件不满足时玩家按技能完全没反应，体验差。
2. 常驻视觉提示没有统一托管，现在每个任务自己创建销毁特效（重复代码）；建议接口加 `常驻特效路径?` 由核心统一管理。
3. 清理粒度只有"全清"，第三章场景切换多（恶魔城→火山→神殿→墓地），需要按场景/前缀分组清理，避免残留与误伤。
4. 多人共享语义：`已调查线索ID表` 是全局的，新增点位前需确认是否维持全队共享。

## 已落地：环境互动空挥反馈

改动文件：`04．环境互动/00．通用/00．环境互动配置.ts`、`00．通用/01．环境互动核心.ts`、`04．环境互动/README.md`。局部构建通过，生成 Lua 已核对无 self/nil 错位。

- 配置新增：`环境互动空挥提示文本`（"这里似乎没什么可查的。"）、`环境互动空挥提示持续毫秒`（2000）、`环境互动空挥提示冷却毫秒`（3000）。
- 核心新增 `提示空挥`（局部具名函数，`this: void`），在扫描循环未命中任何点后调用；覆盖"范围内无点"和"有点但回调全返回 false"两种情况。
- **关键坑**：提示必须用 `发送单位提示给玩家`（单播），不能用失踪侍从任务里那种 `广播单位提示`（遍历全部玩家槽群发）。空挥是高频操作，用广播会让全服跟着刷屏。
- 节流时间源用 `getGameTime()`（`系统.00．核心系统.05．中心计时器`，返回游戏内已过毫秒，同步确定），按玩家 ID 存在 `空挥提示上次时间表`。
