# 精灵往事：祖地双灵卫副本制作计划

## 文档用途

本文件同时作为祖地双灵卫副本的制作计划和实现复盘记录。正式实现前，先把 PDF 要求、现有系统核对结果和仍待确认的地图数据记录在这里，避免压缩上下文后丢失约束。

## 世界线归属

- 分类：第三章，灵心归源世界线，精灵往事。
- 副本名称：祖地双灵卫。
- 本副本与封印守卫战是两个独立副本；测试命令使用 `双灵卫X`，不使用 `封印9`。
- 道中单位技能已经按第三章普通小怪、小精英和精英分类落在单位技能目录；正式副本入口、试炼和 Boss 场景仍由本副本流程接入。

## 已确认流程

1. 世界地图创建祖地入口守门单位 `e060`，玩家接近时提示精灵族禁地。
2. 主线进度 `35-36` 时，通过 `e08Q` 本·思雅开启祖地任务对白。
3. 接受任务后创建/启用祖地守护官埃德里安 `e082`，完成守门广播并打开入口闸门。
4. 埃德里安提供三个必须单人完成的试炼：持续 DPS、单次高额伤害、限时治疗。其他玩家参与对应试炼时，该试炼单独失败并重置。
5. 三个试炼全部完成后，开启祖地双灵卫永久传送点，打开通往 Boss 场景的两道门。
6. 玩家进入 Boss 入口范围后播放前导对白，随后启动祖地双灵卫 Boss 战。
7. 双灵卫 Boss 战结束后，玩家返回埃德里安提交任务，再发放首通奖励和全队 `+1` 能量碎片。

## PDF 原文补充约束

- 守门者放行时打开的祖地外门是 `gg_dest_ZTd2_5491`；试炼完成后打开的两道内门才是 `gg_dest_B00Z_5040`、`gg_dest_B00Z_5039`。
- 任一试炼被其他玩家介入时，埃德里安必须通过广播系统说明违规原因，并重建、重置当前这一项的靶子。
- 任一试炼完成后，对应靶子立即消失；完成状态保留，玩家再次点击埃德里安时在任务要求中显示“已完成”。
- 埃德里安会在每项通过后分别广播认可文本。
- 持续输出靶和治疗靶的头顶 UI 显示剩余秒数；持续输出靶同时显示当前平均 DPS；单次伤害靶显示目前打出的最高单次伤害。
- 三项全部完成后自动完成试炼阶段，不需要返回埃德里安提交，直接创建永久传送点并打开两道内门。
- Boss 击败后才需要回埃德里安提交任务；首领奖励选择和全队 `+1` 能量碎片都在提交后发放。

## Boss 场景已确认数据

### 战斗区域

- Boss 战入口触发中心：`(-25047.2, -2479.5)`。
- 入口检测半径：`300`。
- Boss 战矩形：现有 Boss 启动属性配置 `ancestral-twin-guards-battlefield`，范围 `left=-26688, right=-23712, bottom=-3584, top=-864`。
- Boss 战开始期间应保持 Boss、玩家和场景状态由 Boss 战启动桥接统一管理。

### 力量之墙

- 真实内部四位 ID：`Dofw`。
- 创建时机：Boss 战锁定/正式启动后创建。
- 创建坐标：`X=-26748.2, Y=-2503.9`。
- 朝向：`0` 度。
- 缩放：`1`。
- 变体：`0`。
- 运行时设为不可破坏，避免玩家通过攻击提前打开封锁。
- 战斗结束、提前中止或清理 Boss 战运行上下文时删除动态创建的墙。
- 只允许祖地双灵卫流程管理这面墙，不能复用为封印守卫战的封锁物。

## 现有实现核对结论

- 项目已有可破坏物动态创建封装 `CreateDestructableLoc`，以及 `RemoveDestructable`、`SetDestructableInvulnerable` 的具名调用范式。
- 项目已有亚伦柯斯/安兹乌尔恭封锁墙模块，可作为生命周期参考，但祖地双灵卫必须使用独立模块和独立状态，不能共用其 Boss 类型判断。
- Boss 战运行驱动统一经过 `启动Boss战运行` 和 `结束Boss战运行上下文`；力量之墙应接入这两个生命周期边界。
- 双灵卫配置已经注册四种 Boss 形态：`U00F`、`U00B`、`U00E`、`U00D`，正式流程应按实际出场形态管理，不把测试场景当成正式入口。

## 实现拆分计划

- `副本配置`：NPC、闸门、坐标、试炼阈值、Boss 入口、奖励和提示文案。
- `副本状态`：任务接受、三个试炼进度、Boss 战状态、完成提交和一次性标记。
- `入口与对话`：守门单位、本·思雅、埃德里安、选择/进入触发和广播。
- `埃德里安试炼`：单人参与过滤、开始/失败/重置/完成、目标单位和世界坐标进度 UI。
- `传送与闸门`：永久传送点、玩家组传送和闸门生命周期。
- `Boss 场景`：Boss 前导、正式启动、`Dofw` 力量之墙、场景表现和战斗结束清理。
- `奖励收束`：返回 NPC 提交、首通奖励 UI、全队能量碎片发放。
- `index`：只负责初始化和注册入口，不承载业务细节。

## 联机与清理要求

- 试炼结果、Boss 状态、奖励资格在同步的游戏状态层处理；本地 UI 只负责本地表现。
- 所有计时器、区域、触发器、目标单位、特效和墙体句柄都必须有对应清理路径。
- 具名回调优先，JASS/Dz/timer 回调禁止匿名闭包。
- 不使用 Lua 数学库；随机和距离计算沿用项目已有封装。
- 不修改 `fix-lua-for-pack.js`，不混用 `jass`、`BJ`、`japi`；底层调用优先通过项目安全版封装。

## 待继续核对

- PDF 中三个试炼的正式任务文本、对白顺序和目标单位创建点，需要接入现有剧情/任务封装后再落地。
- 双灵卫正式出场单位、死亡结算和延迟奖励触发点，需要结合现有 Boss 死亡结算与隐藏 Boss 奖励池确认。
- `e060`、`e082`、`e08Q` 的地图预置/动态创建来源，需要在实现入口模块时逐项确认，避免重复创建。
- 进度 UI 需使用 `TS/系统/09．表现系统/15．世界坐标进度UI` 的现有 API，不自行复制一套 UI。

## 构建记录

- 已完成副本配置、运行状态和世界线入口骨架，并通过局部构建。
- 已实现埃德里安三项试炼运行模块：
  - 持续伤害靶锁定首个玩家来源，20 秒累计达到 `40000` 最终伤害后完成。
  - 单次伤害靶要求单次最终伤害严格超过 `10000`。
  - 治疗靶从 `1/5000` 生命开始，首个有效治疗开始计时，10 秒内治满后完成。
  - 其他玩家介入时只重置当前试炼，不影响另外两项已经取得的进度。
  - 三个靶统一替换为 PDF 指定靶模型，并各自创建世界坐标进度 UI。
  - 三项完成后通过具名完成监听派发后续永久传送点流程。
- 已实现祖地入口与 NPC 对话模块：
  - 世界初始化创建祖地守门者，未接任务的玩家首次靠近时播放禁地警告。
  - 主线进度 `35-36` 时创建本·思雅，点击后可通过对话框接受“精灵往事”委托。
  - 接受委托后创建埃德里安；玩家携信物靠近守门者后，通过三段广播完成放行，打开 `gg_dest_ZTd2_5491` 外门并创建三项试炼。
  - 只有本·思雅和埃德里安的任务交互使用对话框；守门者及其他非任务剧情提示统一使用广播消息系统。
  - 点击埃德里安可查看三项试炼的实时“已完成/未完成”状态。
- 已实现永久传送与内门模块：
  - 三项试炼全部完成后自动打开 `gg_dest_B00Z_5040`、`gg_dest_B00Z_5039`。
  - 在 `(-21522.4, -11822.2)` 创建永久传送灵阵，登记玩家英雄进入后传送到 `(-27872.5, -1664.6)` 并面向 `270` 度。
  - 传送表现复用特效库已登记的 `Common\\Effect\\Form\\Portal\\SealGuardWavePortal.mdx`。
- 已实现 Boss 场景与战斗完成桥接：
  - 玩家首次进入 Boss 入口范围后播放广播前导，并在预警点每 `100ms` 重建一次 3 倍预警特效，持续 `3.5` 秒。
  - 预警结束后创建并冻结赤誓灵卫、苍影灵卫，在两名 Boss 脚下播放 2 倍出场特效；对白结束后同时启动两套 Boss 战运行上下文。
  - 力量之墙继续由 Boss 战运行驱动按双 Boss 引用计数创建和清理。
  - 双灵卫最终净化不再立即打开首领奖励，改为派发具名战斗结束事件，剧情流程据此进入“返回埃德里安提交”阶段。
- 已实现奖励提交模块：
  - Boss 战完成后，点击埃德里安进入任务提交对话；未提交前不会发放任何首领奖励。
  - 提交成功后只执行一次，向玩家 `1-6` 中所有在局用户分别打开祖地双灵卫奖励池，并各增加 `1` 能量碎片。
  - 提交文本和广播统一使用“能量碎片”语义，不显示木材名称。
