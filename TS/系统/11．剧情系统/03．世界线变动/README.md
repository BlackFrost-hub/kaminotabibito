# 世界线变动

本目录用于管理会跨越章节、改变后续主线状态或结局条件的隐藏剧情线，与 `01．主线任务`、`02．支线任务` 同级。

## 分类边界

- 普通主线：推进当前章节的必经剧情。
- 普通支线：可以独立完成，但不会显著改写后续主线世界状态。
- 世界线变动：由隐藏条件开启，跨章节回收伏笔，并改变后续人物、区域、副本、援军或结局条件。

世界线变动可以借用主线或支线的触发点，但其状态、设计文档和后续实现统一收录在本目录，避免分散后无法追踪。

## 推荐结构

每条世界线建立独立子目录，优先按以下顺序组织：

1. `00．世界线总案.md`：记录已确认设定、完整流程、分歧和待定项。
2. `01．触发与状态设计.md`：记录触发条件、状态变量和断点恢复。
3. `02．剧情步骤/`：存放实际剧情片段与对白。
4. `03．副本与战斗设计.md`：记录世界线专属副本、Boss 与机制。
5. `index.ts`：正式接入后统一导出；纯设计阶段不提前创建空入口。

## 设计原则

- 世界线必须对后续主线产生可感知的变化，不能只是奖励更高的长支线。
- 关键真相允许由多份立场不同的记录拼合，不用单个角色一次讲完。
- 历史人物保持灰度，避免为了隐藏结局把原有反派简单洗白。
- 世界线未触发时，普通主线仍须能够完整推进；完美结局可以要求世界线完成。
- 未确认的推测必须显式标注为“暂定”或“待定”，不得直接当作正式史实写入对白。
