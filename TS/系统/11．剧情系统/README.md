# 剧情系统

剧情系统负责把主线、支线、Boss 战前后、过场和任务提示统一到可复用的步骤结构里。

## 当前结构

- `00．公共`
  - 剧情共用能力，先放基础内容。
- `01．主线任务`
  - 主线剧情迁移入口。
- `02．支线任务`
  - 集中维护支线 NPC 配置，并预留后续支线剧情入口。

## 现在的组织方式

- 剧情不再按单个 JASS 大触发器硬塞。
- 一条主线章节会先拆成一个“剧情集合”，再在集合里拆成多个子段。
- 当前集合入口按顶部 `index.ts` 统一导出。
- 原生电影系统仍可作为阻塞壳子，但正式内容以步骤播放器为准。

## 约定

- 对话优先用步骤播放。
- 任务提示、更新提示、获得提示，仍可保留 `QuestMessageBJ(...)` 作为兼容出口。
- 后续如果新增剧情，就优先补集合与子段，不要先堆一个巨大对白函数。
