# 主线任务

这里是主线剧情迁移的正式入口。

## 当前结构

- `00．剧情系统核心工具`
  - 主线剧情动作上下文、剧情进度读写、任务消息/小地图/大门/广播等桥接函数。
- `00．主线任务配置表.ts`
  - 主线任务兼容配置与旧数据入口。
- `01．主线配置驱动.ts`
  - 主线推进、提示刷新、预览文本等驱动层。
- `01．主线剧情入口`
  - 主线 NPC 创建、YDUserData 兼容绑定、矩形/范围入口注册的配置与初始化实现。
- `02．剧情步骤`
  - 正式剧情步骤系统。

## 当前分组方式

- 一个章节不再拆成一堆孤立小文件。
- 先按大集合分组，再在集合里按真实 JASS 触发链拆成少量章节片段。
- 精灵村与蛇人族集合当前挂表片段：
  - 精灵村入口到长老发布任务
  - 击败地精到长老说去沙漠来
  - 沙漠到蛇人族
  - 蛇人族击败食人魔到护卫对战
  - 回村击败第一章最终Boss教派

## 迁移原则

- 先对齐真实 JASS 执行顺序，再做中文润色。
- 一段剧情里允许混合对白、广播、等待、镜头、音乐、特效、物品、Boss 启动。
- 原生 `QuestMessageBJ(...)` 只保留在任务语义明确的地方。
- Boss 死亡触发到主线剧情时，优先走剧情系统片段；只有后续死亡分支足够多时，才新增轻量 `Boss死亡剧情索引`，不要把具体剧情写进 Boss 运行清理文件。
- 当前已经有 `02．剧情步骤/06．Boss死亡剧情索引.ts`，用于维护 Boss 死亡到剧情片段的映射；具体剧情内容仍放在片段文件内。
- `01．主线剧情入口` 已接入主线任务 `init()`，负责创建主线 NPC、写入兼容 YDUserData、注册 TS 侧剧情入口事件；旧 JASS 的 `主线剧情NPC4.0S` 不应再同时启用，否则会重复创建 NPC。
