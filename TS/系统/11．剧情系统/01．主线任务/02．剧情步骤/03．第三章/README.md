# 第三章剧情步骤

第三章从第二章里科特战败撤离后开始，主线区域依次为：

1. 精灵王城战后收束。
2. 返回第一章沙漠并抵达熔岩小镇。
3. 进入万浴熔灵。
4. 初至恶魔城，接触由不同恶魔族群组成的城邦。
5. 追查熔岩核心、双重凤凰与英灵封印之处。

当前正式接入 `35-44`：

- `35`：查看克林姆德王伤势，取得前往熔岩小镇的主线线索。
- `36`：熔岩小镇镇长说明教派已进入恶魔城。
- `37`：玩家初入恶魔城，听见神秘声音的远距离呼唤。
- `38`：初见恶魔城领主阿瓦尔，进入恶魔城调查阶段。
- `39`：调查锻造区、赤尾与下层仓库，收集教派内应证据。
- `40`：返回阿瓦尔汇报，获得前往中部火山取得火灵核心的目标。
- `41`：接受熔岩恶魔试炼，取得火灵核心并完成交付。
- `42`：前往旧熔炉门，与熔岩恶魔王·巴尔扎罗斯对峙并启动 Boss 战。

后续节点仍处于预设计阶段：

- `43`：火焰神殿入口与双重凤凰·菲尼克斯尔现身，完成战前对白。
- `44`：启动双重凤凰·菲尼克斯尔 Boss 战，战后承接尚未接入。
