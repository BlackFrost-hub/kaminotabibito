# 41-48 主线链路坐标核对记录

> 用途：记录熔岩恶魔开门、巴尔扎罗斯、菲尼克斯尔、亚伦柯斯到封印核心的实际运行链路。
>
> 使用规则：后续审查或制作 41-48 时先读本文，再按需要读取对应片段。不要为了核对坐标反复扫描整个主线目录。
>
> 记录范围：只记录当前 TS 实际配置和已确认的地图全局名；没有确认的坐标不自行补写。

## 1. 链路总览

```text
41 熔岩恶魔
  死亡 -> 打开两扇熔岩大门 -> 火灵核心交付点 -> 进入 42
42 巴尔扎罗斯
  死亡 -> 战后对白 -> 注册传送门 -> 火焰神殿入口 -> 进入 43
43/44 菲尼克斯尔
  死亡 -> 战后对白 -> 注册传送门 -> 英灵墓地入口 -> 步行到亚伦柯斯
46/47 亚伦柯斯
  死亡 -> 删除墓地阻挡 -> 注册传送门 -> 封印核心外层落点 -> 步行到封印核心
48 封印核心
  进入入口 A -> 移动到对白站位 B -> 场景 NPC 对话
```

7. 传送到 `(10641.80, -9804.50)` 后播放一次抵达对白，玩家继续步行到封印核心入口。
