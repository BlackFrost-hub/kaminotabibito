# 主线剧情

这里是正式主线剧情的单进度目录。

## 规则

- `01` 到 `34` 按进度编号对齐。
- 每个文件只维护一个进度段，名称用剧情语义，不用内部 4 位 ID。
- 无进度前置事件，放到对应进度文件顶部。
- 通用能力继续放在 `00．剧情系统核心工具`。
- `18 -> 19` 不再按“确认跳过”处理，现已落到 `01．第一章/18．精灵城章节承接.ts`。
- `19 -> 20` 现已落到 `19．精灵森谷传送抵达.ts`，触发方式为森林传送阵附近使用 `环境互动`。
- `14 -> 15` 现已查实为 `N05L` 受击血线触发；`14．蛇人族卫队长试炼.ts` 只放真实血线事件配置，原先的试炼宣告已并入 `13．蛇人族交还食人魔凭证.ts`。
- 第一章 Boss 为 `教派`。
- 第二章 Boss 为 `里科特王子`。
- `33` 是第二章王子 Boss 战后的承接，不是章节终点。
- `34` 是第二章后续承接，不表示全剧情结束。

## 说明

- 物品事件和特殊事件统一由 `01．主线剧情入口/05．主线剧情事件配置表.ts` 配置，再分别交给 `03` / `04` 初始化文件注册监听。
- Boss 死亡承接仍由 `06．Boss死亡剧情索引.ts` 统一映射。
