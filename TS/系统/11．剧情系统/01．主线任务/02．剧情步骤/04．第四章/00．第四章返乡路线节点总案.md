# 第四章返乡路线节点总案

> 状态：路线预设计。节点编号暂接第三章 `50`，尚未绑定地图矩形、单位配置、任务触发和正式对白；帝都俯瞰视觉方向已确认。

## 一、章节定位

第四章开场不是从万浴熔灵直接传送回帝都，而是让玩家亲自穿过帝国边境。

这段返乡路需要完成四件事：

- 让玩家从第三章的远古封印危机，逐步回到人类社会与帝国政治。
- 展示帝国虽然强盛，但边境道路、民生和地方权力并非毫无裂缝。
- 通过风龙与枫叶村，给连续高压的熔岩、墓地场景一次自然过渡。
- 在进入帝都前，让塞西亚教会和帝国高层的分歧先露出轮廓。

这只是第四章的返乡序章。玩家抵达帝都后，天外来客、英灵史案、封印危机和帝国内部分歧才进入本章主体。

## 三、路线节奏

| 段落 | 氛围 | 主要作用 |
|------|------|----------|
| 边境哨卡 | 戒备、疲惫、秩序尚在 | 交代帝国已察觉世界异变，但消息并不完整 |
| 风啸峡谷 | 狭窄、危险、真假传闻混杂 | 处理强盗威胁，揭示边境失序并非只有一种原因 |
| 山顶风龙 | 高空、古老、自由 | 可选世界线，不把古老生灵默认写成必须讨伐的怪物 |

| 帝都山路 | 庄严、逼近、政治压力上升 | 让玩家意识到带回的证据会改变帝国内部格局 |

## 四、预设计节点

### 节点 51：离开万浴熔灵

- 奥斯特利一世重新沉睡，封印核心暂时稳定。
- 玩家带着守墓誓章、军令残卷、墓志拓本和七色水晶抽取记录离开。
- 返回路线沿熔岩小镇与旧沙漠道路北上，不重新展开第一章沙漠剧情。
- 阿伦劳特说明帝国边境哨卡拥有最快的军用驿路，但没有提前解释帝都目前的政治局势。
- 任务更新为：`前往奥斯特利帝国边境哨卡。`

### 节点 52：人类边境哨卡

- 哨卡是玩家回到帝国控制区的第一处明确标志。
- 守军没有无条件放行。阿伦劳特出示帝国远征团凭证，玩家则需要说明携带的是封印急报，而非公开展示全部证物。
- 哨卡指挥官确认近期峡谷商路多次中断，失踪者既有商旅，也有携带帝都公文的驿使。
- 守军兵力被分散在边境异变和难民安置上，无法抽调整队士兵深入峡谷。
- 指挥官提供临时通行文书，并请求玩家找到失踪驿使或至少取回公文袋。
- 他提醒玩家：峡谷中的风声未必都来自传说中的风龙。

哨卡的作用不是给玩家发布一串杂务，而是说明帝国仍有秩序，却已经开始顾此失彼。

### 节点 53：进入风啸峡谷

- 峡谷道路存在人为设置的落石、假路标和收费关卡。
- 强盗利用山顶风龙的传说恐吓商旅，并用风鸣器具或简陋法术制造类似龙啸的回声。
- 玩家最先遇到的并非匪首，而是一批负责望风和搬运货物的外围成员。
- 这些人中既有主动劫掠者，也有因商路断绝、债务或家园受灾而被裹挟的人。
- 玩家可以通过俘虏、搜查货物或救下伤者，得知失踪驿使被押往峡谷旧寨。

此处不把所有强盗洗白。匪首与核心成员长期杀人劫货，并主动借灾乱扩张；复杂性主要体现在外围成员和地方失序的成因。

### 节点 54：峡谷旧寨与强盗首领

- 旧寨储存着被劫的教会药物、村民冬粮、帝都公文和用于伪造龙啸的器具。
- 匪首知道公文价值，准备把它卖给一名未露面的帝都买家或教派联络人。
- 玩家救出仍存活的驿使，并夺回密封公文袋。
- 战斗中可以设置投降或逃散阈值，让外围成员在匪首失势后停止作战。
- 战后获得两条路线：直接前往枫叶村，或根据寨中地图登上风龙栖息的山顶。
- 是否宽恕外围成员、是否把物资全部交还，以及是否保留匪首交易记录，可作为后续枫叶村评价和世界线变量。

公文袋原则上保持密封。玩家带回的是证据和失踪驿使，不需要靠偷看帝国公文推动剧情。

### 节点 55：山顶风龙支线

- 风龙是峡谷古老居民，不是强盗豢养的战兽，也不是默认敌对 Boss。
- 近期风龙频繁掠过峡谷，是因为强盗盗走了巢穴中的风鸣石、幼龙遗蜕或其他护巢之物，用来制造龙啸和操纵峡谷乱流。
- 玩家携带失物登顶后，可以选择归还、交涉或主动挑战。
- 归还路线让风龙平息峡谷乱流，并给予一枚风之信物，后续可影响山路通行、世界能量本源或隐藏 Boss 条件。
- 挑战路线应表现为强者试炼，而非为了通关屠杀古老生灵。战败后的风龙可以认可玩家，不必死亡。
- 无视支线也能继续主线，但帝都山路可能保留更恶劣的风雪或落石事件。

风龙的正式名称、形态、是否具有语言能力，以及信物是否关联三份世间能量本源，暂不确定。

### 节点 56：抵达枫叶村

- 枫叶村位于峡谷与帝都山路之间，是商旅、朝圣者和边境居民的中转地。
- 村庄视觉应以红枫、石路、木屋和大型教堂为核心，与第三章熔岩和墓地形成明显反差。
- 玩家到达时，村中正在安置峡谷难民和受伤商旅，因此平静中仍有现实压力。
- 若玩家救回驿使、药物或冬粮，村民会通过具体结果认识玩家，而不是一见面便知道全部事迹。
- 大教堂的钟声和水系治愈仪式可以承担场景转场，让返乡路第一次真正慢下来。

### 节点 57：塞西亚大教堂与主教

- 大教堂属于水之女神塞西亚的正统教会体系，不属于分离教派。
- 主教是当地受尊敬的宗教与民事权威，不预设为幕后反派。
- 他先处理伤者、核验哨卡文书与驿使身份，再在私下接见玩家，避免在教堂大厅公开封印情报。
- 守墓誓章和七色水晶残留会让他意识到事件等级远超普通边境急报。
- 主教可利用教会的水镜、圣泉共鸣或专用信使，先向帝都发出一封内容受限的预警。
- 他提醒玩家，证据进入帝都后会触碰王室、军部和教会对历史与天外变量的不同立场，不能随意交给第一位前来接收的官员。
- 他为玩家签发山路通行与教会见证文书，但不替玩家决定应相信帝都中的哪一派。

主教应表现出信仰、判断力和地方责任。他可以对帝国部分做法保留意见，但不能因此自动等同于叛徒或教派内应。

### 节点 58：帝都山路

- 离开枫叶村后仍需经过一段山路，避免教堂与帝都在空间上紧贴，削弱世界尺度。
- 山路承担返乡序章最后一次压力升级，不必再安排完整大型 Boss。
- 可选事件包括：帝都接应队提前抵达、身份不明者试图接管证物、峡谷余党截杀，或因风龙支线结果产生不同天气与道路状态。
- 阿伦劳特在此明确要求证物继续由主角团保管，直到进入帝都正式议事场所。
- 若有人要求玩家在城外移交证物，其命令来源必须可核验，不能靠一句“奉命行事”强迫剧情推进。

### 节点 59：抵达奥斯特利帝国都城

- 玩家走完帝都山路后，镜头切换到高空近垂直俯视视角，第一次展示帝都全貌。此处采用固定电影镜头与地面绘景模拟，不要求在可玩地形中真实搭建整座帝都。
- 帝都已收到主教的有限预警，但尚不知道封印核心的全部真相。
- 玩家携带的证据会同时引发三类反应：立即修复封印、重新审理英灵史案、调查预言中的天外变量。
- 教皇强硬派与阿伦劳特一方的分歧从这里进入公开剧情，但不在城门口一次性解释完毕。
- 任务更新为：`进入帝都，向帝国议事机构提交万浴熔灵急报。`

#### 帝都俯瞰演出方案

- 这是高空直接向下观察帝都的 RTS 俯视画面，不是人物站在山崖边远眺城市。镜头中不得出现前景悬崖、人物背影、地平线、远山天际线或写实航拍构图。
- 视觉风格以经典 War3 式手绘地形和简化低模建筑为准：轮廓清楚、比例略夸张、细节柔和、远处对比度较低；禁止做成写实建筑概念图或现代 3D 航拍。
- 先锁定高空镜头的高度、俯角和画幅，再按照该镜头绘制帝都贴图。贴图本身必须已经具有正确的俯视透视，不能依赖运行时旋转平面补救。
- 帝都主体使用铺在地形方向上的大面积绘景平面或等效地面贴图承载，不使用面向镜头自动旋转的公告牌，也不使用纯屏幕 UI Frame 假装三维地面。
- 画面边缘只使用白云、薄雾和少量地面装饰遮接缝。地面装饰可以包括树冠、花坛、雕像、喷泉、旗帜、路灯、庭院和水渠，不再使用悬崖作为画框。
- 推荐分为 `帝都绘景底层`、`少量真实地面装饰层`、`独立动态云层` 三层。云层缓慢经过城市上方，负责提供高度感和遮盖贴图边缘，但不能长期挡住大教堂、王宫、主道路和广场。
- 已确认准备两档绘景：远景版展示帝都整体布局，中景版放大大教堂、王宫、广场、花园与水渠。大幅拉近时借云层遮屏切换贴图，不持续放大同一张低分辨率绘景。
- 同一张贴图只允许小幅拉近或降低镜头高度。镜头不得大幅横移、环绕或改变俯视方向，否则平面城市缺少真实视差的问题会暴露。
- 帝都绘景模型材质优先检查 `Unshaded`、`Unfogged` 与双面显示；独立云层使用可靠的透明 BLP 和过滤模式，必须进游戏检查黑底、脏边和排序问题。
- 演出结束后再切入帝都内部的独立可玩区域，不要求俯瞰绘景与帝都内部地形保持一比一空间对应。

## 五、人物与势力建议

### 边境哨卡指挥官

- 务实、疲惫、仍坚持程序。
- 他不是故意为难玩家，而是在兵力不足和假冒使者增多的情况下承担边境责任。
- 暂不命名，等待单位模型和正式剧情落地时确定。

### 峡谷强盗

- 核心匪帮：主动利用灾乱牟利，必须承担劫掠和杀人的责任。
- 外围成员：来源复杂，可投降、逃散或接受后续处置。
- 未露面的买家：可连接分离教派、帝都腐败官员或第五章幕后势力，但当前不宜过早定死。

### 风龙

- 象征不受帝国与教会完全支配的古老力量。
- 与玩家的关系由行为决定，可以成为隐藏挑战、后续援助或世间本源线索。
- 不建议写成单纯守着宝箱等玩家击杀的野外怪物。

### 枫叶村主教

- 是塞西亚教会在边境地区的正式代表，也是当地长期承担救济、医疗和文书见证的人。
- 他知道帝国内部存在分歧，但掌握的信息有限，不应像全知角色一样提前说破第五章真相。
- 他对阿伦劳特可以产生“此人身份不止远征团长”的怀疑，但只通过礼节、观察或一句试探表现。

## 六、可变世界线记录

第四章返乡路线可以先预留以下变量：

| 变量 | 可能影响 |
|------|----------|
| 驿使是否存活 | 帝都是否拥有第一手峡谷证词 |
| 公文袋是否完整 | 边境线索可信度与后续政治争论 |
| 被劫物资是否归还 | 枫叶村民意、教堂救治能力与支线奖励 |
| 外围强盗如何处置 | 后续治安、招募或报复事件 |
| 是否归还风龙失物 | 帝都山路环境、风龙态度与隐藏世界线 |
| 是否主动挑战风龙 | 风之信物等级、隐藏 Boss 记录或后续援助方式 |

这些变量只记录结果，不立即给出绝对善恶评价。第四章和第五章可以通过实际后果回应玩家选择。

## 七、暂不确定事项

- 枫叶村、峡谷和风龙的正式地名与角色名。
- 风龙信物是否就是三份世间能量本源之一，或只负责指向真正的风之本源。
- 峡谷匪首背后的买家属于分离教派、帝国腐败势力，还是第五章挚友控制的暗线。
- 枫叶村主教在帝国教会中的派系和等级。
- 帝都山路是否需要一场小型战斗，还是以接应、审查和政治对峙为主。
- 第四章正式起始节点是否从 `51` 开始；需等待第三章 `39-50` 正式落地后最终确认。
