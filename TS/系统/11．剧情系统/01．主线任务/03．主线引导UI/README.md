# 主线引导 UI 规则

本规则只适用于 `TS/系统/11．剧情系统/01．主线任务/03．主线引导UI` 及其与主线剧情节点的对接，不提升为项目通用规则。

## 主线节点同步检查

- 制作、迁移或修改任何主线剧情节点时，必须同时检查并按需更新 `01．主线引导配置表.ts` 中对应进度的引导配置，不能等剧情代码完成后再补查。
- 审查任何主线剧情节点时，即使本轮不修改剧情代码，也必须检查对应进度的主线引导，并在审查结论中明确说明引导进度、提示文本和镜头目标是否一致。
- 引导配置索引必须与节点完成后实际写入的 `剧情进度` 一致，不能沿用前一节点或提前指向后一节点。
- `提示文本` 必须描述该进度下玩家当前要完成的主线目标，并与剧情片段结束时发布的主线任务提示一致。
- `镜头X / 镜头Y` 或 `镜头跟随单位` 必须指向提示文本中的实际目标，不能出现文本指向一个 NPC、镜头指向另一个 NPC 或旧坐标的情况。
- 核对时必须沿完整链路确认：剧情入口条件 -> 剧情片段写入进度 -> 片段结束任务提示 -> 主线引导进度配置 -> UI 点击后的镜头与消息。
- 若当前进度没有明确可指向的目标，可以不配置镜头；不得为了填满配置而复用无关坐标。
- UI 点击行为保持玩家隔离：只移动点击玩家的镜头，只向点击玩家发送提示消息；共享剧情进度仍按同步游戏状态读取。

## 完成检查

每次主线剧情节点改动完成前，至少确认以下四项一致：

1. 剧情节点写入的进度值。
2. 主线引导配置表使用的进度索引。
3. 剧情任务目标与主线引导提示文本。
4. 实际目标单位或地点与主线引导镜头坐标。

只做剧情审查时也必须逐项完成上述检查；不能因为引导配置文件未发生改动而省略主线引导结论。
