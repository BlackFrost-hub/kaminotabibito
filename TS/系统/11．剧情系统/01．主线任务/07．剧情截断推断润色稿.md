## 教派 Boss 章节末承接

### STRING 938

原功能定位：
- `『精灵族长』` 解释 `『黑魔一族』` 与 `『西里尔一脉』` 的旧怨
- 用来承接上一句“黑魔法一脉单传、嫡系传承”的设定说明

推断补全：

`当年『黑魔一族』可以说是『黑魔法』最强的使用种族。为了施展黑魔法，他们盯上了我族的皇族血脉，我族拼尽全力，才将黑魔一族围剿殆尽。据说就在那一场战争之后，我『西里尔一脉』迅速衰落。相传正是黑魔一族在最后时刻施展了某种极其恶毒的诅咒魔法。只可惜，岁月太久，真相早已难以查证。更何况那一战中，我族本就折损了大量高手，当任族长亦被同归于尽之术重创，此后血脉与传承，都再难恢复旧日荣光。`

### STRING 944

原功能定位：
- `『精灵族长』` 解释 `『分离教派』` 的历史起源与核心理念

推断补全：

`这其中牵扯太大，『分离教派』自当年『分裂之灾变』后便已成立。『分离教派』应该是大陆最大教派之一。他们当年主张，大陆分离乃自然原因，不该人为干预，反对『奥斯特利一世』的救世之举，认定那是在违逆世间本该运行的规则。`

### STRING 946

原功能定位：
- `『精灵族长』` 继续说明 `『分离教派』` 的组织结构与渗透形式

推断补全：

`据说他们共有一位教皇与六位主教带领，旗下有三大军团与一个神秘的『肃正暗杀团』。具体有多少人，我也无法断言，只能从祖上传下的记载里窥见一角。真正麻烦的是，『分离教派』历史太过悠久，成员渗透极深，许多人在明面上都有各自的身份，甚至早已扎根于各族与诸方势力的权位之中。若无确凿证据，外人往往根本无从分辨。`
