## 与旧背景草稿的关系

剧情系统根目录的 `大概背景.MD` 是早期主线草稿，其中“五百年前大陆分裂、奥斯特利一世建立牵引阵法”等内容暂不删除。

当前采用的兼容解释是：

- 万年前发生的是影响整个世界的黑暗时代，八位远古神明将灾难拆分封印。
- 五百年前发生的是封印长期衰退后的一次大型次生灾难，塞利尔大陆险些再次分裂。
- 奥斯特利一世不是八神之一，而是水之女神塞西亚职责与血脉的后世继承者。
- 奥斯特利一世建立的牵引阵法，是现世对远古封印体系的一次局部加固，而非世界最初的封印。

后续正式润色旧主线时，应以本目录设定为准，逐步把早期草稿中的冲突内容改成同一条历史因果链。

## 维护原则

- 已确认设定与推测性方案分开记录。
- 八位远古神明尚未全部确定前，不提前补齐名字、种族和权能。
- 背景设定只提供世界规则；具体人物选择和历史争议仍应保留多方立场。
- 新增世界线时，应链接到对应背景文档，不在每条世界线内重复整套世界史。
