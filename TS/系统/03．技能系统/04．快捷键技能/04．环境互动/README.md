# 环境互动快捷键技能

环境互动是玩家英雄自带的通用探索入口。技能本身只负责把“玩家英雄施放技能”转换为一次附近触发点扫描，具体探索内容按类别维护。

制作或修改环境互动前，先读 [环境互动制作规则](环境互动制作规则.md)。

## 目录分类

- `00．通用/`：环境互动技能 ID、默认范围、触发点接口和扫描核心；不绑定具体任务。
- `01．任务/`：任务专属的调查、搜寻和环境交互配置，按任务继续建立独立子文件夹。
- `03．区域探索/`：不绑定任务的常驻探索点，按“章节/场景”建子目录。第一章包含静灵森和精灵村；第二章包含精灵王城、王城外围、精灵祖地和精灵传送阵；第三章包含恶魔城、万浴熔灵、火焰神殿、英灵墓地、封印核心，以及前置场景灼热火山和城镇熔岩小镇。

任务定义、接取条件和提交奖励仍由任务系统维护；只有“能被环境互动技能触发”的坐标、特效和处理逻辑放在这里。

## 文件职责

- `00．通用/00．环境互动配置.ts`：维护技能 ID、默认触发范围和触发点接口。
- `00．通用/01．环境互动核心.ts`：接入技能事件中心，校验玩家英雄，按距离分发触发点，并提供注册/注销/统一清理。
- `01．任务/`：维护任务专属的环境互动触发点。
- `03．区域探索/`：维护按章节和场景组织的常驻探索点；注册入口在 `init环境互动` 中与旧环境互动并列调用。
- `index.ts`：对外导出模块。

## 接入约定

业务系统只调用 `注册环境互动调查点` 注册自己的坐标、范围和具名回调；完成后调用 `注销环境互动调查点`。触发点回调返回 `true` 时，核心会自动注销该点，返回 `false` 表示本次施法不满足业务条件，触发点保留。触发点不限定为调查，也可以由回调实现树桩搜寻、花田拾取、环境机关等交互。

施法范围内没有任何互动可取、或范围内的触发点全部返回 `false` 时，核心会向施法玩家单独发送 `环境互动空挥提示文本`。这句话走单播而不是广播，并按玩家做了 `环境互动空挥提示冷却毫秒` 节流，连续施法不会刷屏。

多人地图里的正式区域探索点默认是世界级一次性：首次成功触发后由核心注销，奖励只给首次触发者。只有明确要求可重复、带冷却或每玩家独立领取时，才配置 `一次性: false` 并实现对应状态；不要默认创建按玩家 ID 的领取表。

当前技能 ID 以技能数据表为准：`A08E`。它是环境互动，不是 `A0E8`。
