# 技能冷却与消耗系统 - 规划文档

## 一、系统概述

| 项目 | 说明 |
|------|------|
| 系统名称 | 技能冷却与消耗系统 |
| 建议归属 | 03．技能系统 |
| 触发时机 | 技能施放事件（SPELL_EFFECT） |

## 二、核心功能模块

### 2.1 冷却缩减计算

```
原始CD → 读取冷却缩减属性 → 应用上限 → 设置技能CD
```

**属性来源：**
- `冷却缩减`：玩家属性，从YDUserData读取
- `冷却缩减加成`：突破上限的额外加成

**上限规则：**
| 类型 | 默认上限 | 突破方式 |
|------|----------|----------|
| 通用 | 33% | 冷却缩减加成 |
| A0IM技能 | 25% | 不可突破 |
| A0IP技能 | 20% | 不可突破 |
| A0DG技能 | 33% | 不可突破 |

### 2.2 技能黑名单

以下技能ID不参与冷却缩减计算：
```lua
-- 完全排除
'A0FW', 'A01W', 'A0IN', 'A0IO', 'A0J8', 'A0K5', 'A0JP', 'A0J3', 'A0K6', 'A0KR', '0005'

-- 独立设置冷却（在各自技能触发中处理）
'A0EA', 'A0DB', 'A0DG'
```

### 2.3 通魔类技能特殊处理

**风暴之刃系列（A0JJ/A0JI/A0JK）：**
- 基础CD：12秒
- 设置A0JH技能冷却

**三连斩系列（SLSQW/SLSQE/SLSQR）：**
- 基础CD：9秒
- 设置A0JT技能冷却

### 2.4 魔法消耗返还（暗夜精灵族）

**触发条件：** 技能种族为 `nightelf`

**计算流程：**
```
技能消耗 = 固定消耗 + 百分比消耗 × 最大魔法
返还蓝量 = 技能消耗 × 魔法消耗减少属性
```

**特殊处理：**
- 百分比消耗 ≥ 90% 的技能不处理（非通魔面板技能）
- 爱德华单位：被动技能扣血代替扣蓝

## 四、接口设计

### 4.1 冷却缩减计算

```typescript
/**
 * 计算并应用技能冷却缩减
 * @param unit 施法单位
 * @param abilityId 技能ID
 * @returns 实际冷却时间
 */
export function applyCooldownReduction(unit: any, abilityId: number): number;

/**
 * 获取冷却缩减上限
 * @param abilityId 技能ID（部分技能有独立上限）
 */
export function getCooldownCap(abilityId: number): number;
```

### 4.2 魔法消耗返还

```typescript
/**
 * 处理暗夜精灵族技能消耗返还
 * @param unit 施法单位
 * @param abilityId 技能ID
 */
export function handleManaRefund(unit: any, abilityId: number): void;
```

## 六、特殊单位处理（单独文件）

### 爱德华被动处理

**触发文件：** `TS/系统/03．技能系统/03．特殊单位处理/01．爱德华被动.ts`

**逻辑：**
- 检测单位是否为「爱德华」（存储在YDUserData "爱德华"/"单位"）
- 被动技能施放时，扣除生命值代替魔法值
- 扣除量 = 技能消耗值
