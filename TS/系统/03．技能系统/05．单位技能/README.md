# 单位技能

这里放单位类技能本体，不放单位初始化挂载逻辑。

## 目录约定

- `00．公共`
  - 放四类单位技能共用的类型、工具、索引、筛选和公共驱动。
- `01．杂鱼技能`
  - 放普通小怪、杂兵、量产敌人的技能。
- `02．精英技能`
  - 放精英怪、强化怪、特殊敌人的技能。
- `03．Boss技能`
  - 放 Boss 的主动、被动、阶段、机制技能。
  - `01．主线Boss`：章节主线必经 Boss。
  - `02．挑战与隐藏Boss`：可选挑战、隐藏支线与特殊守卫 Boss。
  - `03．异界Boss`：异界来源或异界挑战体系 Boss。
- `04．英雄技能`
  - 放玩家英雄、敌方英雄、剧情英雄技能。
- `99．技能复盘`
  - 记录已发生的技能实现问题、强制检查表和构建规则；新增或修复单位技能前后都要核对。

## 放置原则

- 技能逻辑本体放这里，不放到单位系统。
- 单位系统只负责“谁挂什么技能”和“什么时候初始化”。
- 如果一套技能会被多类单位复用，优先沉到 `00．公共`。
- 如果技能已经能抽象成通用技能函数，优先继续沉到 `00．公共/技能模板+函数`。
- Boss 分类按剧情定位判断，不按强度、模型或技能风格判断；详细规则见 `03．Boss技能/README.md`。
- 异界 Boss 的“战斗启动后才生效”的被动，优先放到 `03．Boss技能/03．异界Boss` 下的独立子目录，再由 Boss 战启动层显式拉起和停止。

## 当前配置入口

- 杂鱼 / 精英 / 英雄 / 异界Boss 的分类汇总配置，放在各自子目录下的 `00．技能配置.ts`；常规 Boss 目录按具体 Boss 子目录维护 `00．配置.ts`、运行时和单技能文件，不再额外放一份通用 `00．技能配置.ts`。
- 英雄配置表不放在这里，统一使用：
  - `TS\系统\01．单位系统\00．单位初始化创建\01．玩家英雄\00．玩家英雄配置.ts`

## 暴击公共规则

- `B00U` 是旧 JASS 暴击入口里的强制暴击 Buff。
- 单位身上存在 `B00U` 时，本次伤害暴击率直接视为 `100%`。
- 该规则由 `00．公共\05．原生Buff必定暴击修正.ts` 默认注册，不要在具体单位文件里重复写一遍。
- 判断原生 Buff 时优先使用 `GetUnitAbilityLevel(unit, buffId) > 0` 这类窄封装，不要为了判断 Buff 直接走 BJ 文件里的 `UnitHasBuffBJ`，避免 TSTL 调用形态风险。

## 单位目录约定

- 单位技能按“一个单位一个文件夹”维护。
- 目录内默认至少包含：
  - `00．配置.ts`
  - `01．被动效果.ts`
  - `index.ts`
- 如果后续该单位有更多主动、阶段、机制效果，再在同目录继续顺延：
  - `02．主动技能A.ts`
  - `03．主动技能B.ts`
  - `04．阶段技能.ts`

## 约定

- 新迁移的 JASS 技能，先判断应该落在哪一类，再考虑是否抽公共函数。
- 如果同一份技能后续要给多类单位复用，先写成可配置结构，再分表接入。
- 单位系统里的配置表和这里的技能表是两层，不要混写。
