# 单位技能

这里放单位类技能本体，不放单位初始化挂载逻辑。

## 目录约定

- `00．公共`
  - 放四类单位技能共用的类型、工具、索引、筛选和公共驱动。
- `01．杂鱼技能`
  - 放普通小怪、杂兵、量产敌人的技能。
- `02．精英技能`
  - 放精英怪、强化怪、特殊敌人的技能。
- `03．Boss技能`
  - 放 Boss 的主动、被动、阶段、机制技能。
- `04．英雄技能`
  - 放玩家英雄、敌方英雄、剧情英雄技能。
- `05．异界Boss`
  - 放异界 Boss 的独立技能分组。

## 放置原则

- 技能逻辑本体放这里，不放到单位系统。
- 单位系统只负责“谁挂什么技能”和“什么时候初始化”。
- 如果一套技能会被多类单位复用，优先沉到 `00．公共`。
- 如果技能已经能抽象成通用技能函数，优先继续沉到 `00．公共/技能模板+函数`。

## 当前配置入口

- 杂鱼 / 精英 / Boss / 异界Boss 的配置，放在各自子目录下的 `00．技能配置.ts`。
- 英雄配置表不放在这里，统一使用：
  - `TS\系统\01．单位系统\00．单位初始化创建\01．玩家英雄\00．玩家英雄配置.ts`

## 当前公共工具

- `00．公共\00．技能配置类型.ts`
- `00．公共\01．技能配置工具.ts`
- `00．公共\02．全部技能配置索引.ts`

## 约定

- 新迁移的 JASS 技能，先判断应该落在哪一类，再考虑是否抽公共函数。
- 如果同一份技能后续要给多类单位复用，先写成可配置结构，再分表接入。
- 单位系统里的配置表和这里的技能表是两层，不要混写。
