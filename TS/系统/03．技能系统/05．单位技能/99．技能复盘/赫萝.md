# 赫萝技能复盘

## 昼夜被动周期驱动公共化

- 昼夜被动仍由 Boss 战启动桥接显式启动/停止，不额外登记手动测试命令；测试场创建后应自然观察白天/黑夜状态值和移动速度切换。
- 被动运行时状态由数组记录活动单位，改用公共 `创建周期机制调度器` 驱动，避免每个检查周期执行 `Object.keys` 扫描表；单位死亡或战斗结束后从列表移除，列表为空立即停止调度器。
- 运行时仍使用 JAPI 写入动态单位状态值，并用 JASS 设置移动速度；本批没有改动昼夜数值、检查间隔或启动入口。
- 构建验证：本批文件已通过 `npm run build:files`；生成 Lua 已抽查调度器实例方法保留正确 `self`，未打包地图。
