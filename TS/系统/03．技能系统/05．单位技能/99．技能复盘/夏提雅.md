# 夏提雅技能复盘

## 伤害类型

- 问题：净化投枪及其英灵复刻版本使用了 `ATTACK_TYPE_MAGIC` 提交魔法技能伤害。
- 原因：把原生攻击类型误当成项目的魔法伤害分类。
- 结论：统一技能链路使用 `ATTACK_TYPE_NORMAL`，魔法分类继续由 `DAMAGE_TYPE_MAGIC` 决定。

## 测试命令与阶段覆盖

- 基础命令：`1/2/3/4` 每次主动恢复 P1 实际生命与运行时阶段，避免先测 P2/P3 后基础命令继承旧阶段。
- 强化命令：补齐 `1-2/1-3/2-3/3-2/3-3`，分别覆盖滴管穿心英灵复刻、P3 两段猎血起手、P3 轮舞加速、投枪英灵复刻与 P3 双投枪；P2/P3 专属技能 `5/6/7/8` 保留纯数字基础命令。
- 阶段来源：P2/P3 命令通过 JAPI 读取 Boss 动态最大生命，再把当前生命设置到对应阈值区间，同时同步运行时阶段，保证即时释放与后续周期刷新使用同一阶段来源。
- 被动覆盖：强化普攻在测试场创建后自然监听，不增加空被动命令；`9` 只准备 P3 一次性复生触底场景，测试上下文显式绑定挑战生命下限，随后输入 `55` 验证锁血与复生。
- 真祖血宴：测试命令先在 P1 创建三枚血印，再切入 P3 结算，避免 P3 禁止创建血印导致血宴层数始终为零。

## 施法硬直、动作与朝向

- 问题：调度器的“忙碌时间”只阻止下一次技能调度，不会阻止 Boss 在预警或引导期间移动；部分技能虽然播放了动作，但没有实际硬直。
- 方向技能：强化穿刺、滴管穿心、血月轮舞、净化投枪、镜像夹击和血月终舞均在释放时按锁定目标或锁定路径设置 Boss 朝向。
- 硬直范围：强化穿刺覆盖蓄力，滴管穿心与镜像夹击覆盖冲锋前预警，血月轮舞覆盖横扫与反刺前摇，净化投枪覆盖全部已锁定投枪结算，血月终舞覆盖四段扇区引导；进入冲锋后继续由冲锋系统接管单位暂停与位移。
- 阶段技能：英灵战乙女登场补齐 1.5 秒本体动作、朝向和硬直；真祖血宴补齐转阶段演出硬直；血之复生原本已使用单位暂停和仪式动作，无需重复叠加硬直。
- 非方向机制：鲜血回收补齐回收前摇硬直，但不强制朝向任一血印；真祖血宴、血之复生均为自身中心阶段机制，不设置目标朝向。

## 吟唱条审计

- 项目约定：有明确施法/前摇窗口的技能使用“常规技能”吟唱条；大招使用“大招”通道。
- 已补齐常规吟唱条：强化穿刺、滴管穿心、血月轮舞、净化投枪、鲜血回收、英灵战乙女登场、镜像夹击、真祖血宴。
- 已有无需重复：血月终舞使用“大招”吟唱条，血之复生使用“大招”吟唱条。
- 吟唱条时长与对应硬直/施法窗口一致；P3 净化投枪覆盖两枚已锁定投枪的完整结算等待。

## 测试命令阶段重置运行时报错

- 现象：选择 `Boss夏提雅` 后输入 `1`，提示正在测试但技能没有表现，运行时报 `attempt to call a nil value (method 'slice')`。
- 原因：测试阶段重置通过 `血印句柄列表.slice()` 制作清理快照；该列表在 Lua 运行时是普通 table，不提供 JavaScript 数组的 `slice` 方法，命令在释放滴管穿心前已经中断。同类写法还存在于血印净化、鲜血回收和真祖血宴路径。
- 修复：相关文件统一改为具名本地函数或显式循环复制数组，再遍历快照执行会修改原列表的清理操作；不依赖 Lua 数学库、不修改底层 `lib` 和打包修复脚本。
- 验收：重新 `Run Map` 后输入 `Boss夏提雅`、`1`，应先出现滴管穿心直线预警，再由夏提雅冲锋并对路径目标结算；继续验证 `3` 的血印净化、`4` 的鲜血回收和 `7` 的真祖血宴不再出现 `slice` 报错。

## 滴管穿心特效生命周期

- 调整：本体与 P2 英灵复刻的红色突进拖尾统一复用冲锋残影表现封装，每 `0.02` 秒生成一个实例，每个实例生命周期为 `0.3` 秒；关闭冲锋底层原有的即时销毁路径特效，避免重复叠加。
- 命中：`ShalltearBloodMoonImpact.mdx` 命中爆发的定时销毁时间由 `1.1` 秒调整为 `1.0` 秒。
- 验收：测试 `1` 与 `1-2`，确认红色拖尾不会瞬间消失或长时间残留，命中爆发在创建后约 `1` 秒进入销毁。
