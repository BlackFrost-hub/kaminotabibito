# 树魔首领技能复盘

## Buff 与广播说明精确化

- 问题现象：树魔首领的 Buff 说明和技能广播只写“提高攻击力”“降低治疗”“放置陷阱”等概念，玩家无法从说明中得到倍率、持续时间、范围和规避方式。
- 涉及文件：`TS/系统/05．Buff系统/03．Buff表/01．Boss/01．主线Boss/04．树魔首领.ts`、`TS/系统/03．技能系统/05．单位技能/03．Boss技能/01．主线Boss/05．树魔首领/00．配置.ts`。
- 修改内容：补齐 6 个 Buff 的实际数值、持续/刷新方式、触发范围和叠层规则；补齐 4 个主动技能提示的倍率、时间、范围和分支；为开场、随从、4 个技能广播补充括号内的玩家处理建议；未修改配音台词、配音资源和运行时逻辑。
- 兽群号令：每个存活随从按“当前攻击力减去本 Buff 已有增量后的基准攻击力”增加 20% 攻击力，最多 4 层即 80%；状态每 1.5 秒按存活数量重算，随从死亡或入场会同步增减层数。
- 无从暴怒：无任何自身随从时额外获得 100% 攻速和“默认移动速度×50%”的移速；新随从入场后立即移除，Buff 每 1.5 秒刷新。
- 古树衰弱：扩散冲击波命中后，普通攻击最终伤害降低 40%，持续 7 秒；技能伤害不受影响。
- 远古诅咒：点名等待 3 秒；第一段总伤害按结算时点名目标当前生命值×（60%+20%×N）计算，N 为当前有效玩家数且至少为 1，400 码内目标均分；第一段后每名有效玩家恢复等于第一段总伤害的生命值；N≥2 时再于玩家中心 650 码内延迟 1.8 秒结算第二段。
- 治疗枯竭：生命陷阱每秒刷新一次，每次登记 1.4 秒治疗修正；受到的治疗量降低 50%+难度等级×5%，难度 1/2/3 分别为 55%/60%/65%。
- 静止陷阱眩晕：进入静止陷阱 600 码范围后等待 0.75 秒触发，所有有效玩家获得无视韧性的眩晕 8 秒。
- 图腾分支：巫医对应静止陷阱、猎头者对应生命陷阱、投掷者对应爆炸陷阱；多类随从按存活数量加入候选池，无随从时随机选择。
- 构建验证：执行 `npm run build:files -- "TS/系统/05．Buff系统/03．Buff表/01．Boss/01．主线Boss/04．树魔首领.ts" "TS/系统/03．技能系统/05．单位技能/03．Boss技能/01．主线Boss/05．树魔首领/00．配置.ts"` 成功；`fix-lua-for-pack` 更新 0 个文件；未打包地图。
