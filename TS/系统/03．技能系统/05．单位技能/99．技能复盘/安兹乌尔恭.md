# 安兹乌尔恭技能复盘

## 伤害类型

- 问题：现实断裂、高阶魔法箭、时间停止和天空坠落使用了 `ATTACK_TYPE_MAGIC` 提交技能伤害。
- 原因：把原生攻击类型误当成项目的魔法伤害分类。
- 结论：统一技能链路使用 `ATTACK_TYPE_NORMAL`，具体伤害分类继续由原有 `DAMAGE_TYPE_*` 决定。

## 心脏掌握与高阶魔法箭黑底

- 问题：`AinzHeartCountdown.mdx` 的心脏面片和 `AinzUndeadArrowVolley.mdx` 的箭身面片在 1.27 实机显示为黑色矩形，透明背景没有生效。
- 原因：两张 BLP 回读后均有完整 Alpha，但对应私有贴图层最初使用了 `Blend`；改为 `Transparent` 后黑底仍存在，进一步确认贴图是插件直通编码的 `compression=1 / pictureType=5`，插件可回读但 Warcraft 1.27 实机没有正确应用 Alpha。
- 结论：私有贴图层保持 `Transparent`，贴图改由内置原生转换器输出 `compression=0 / alphaBits=8 / pictureType=4`；生成脚本同时校验材质和 BLP 头。以后遇到整块黑底时必须同时检查 BLP 实机兼容格式与 MDX 材质，插件回读透明不能单独作为结论。

## 心脏掌握读秒与点名提示

- 问题：十二个刻度使用线性 Alpha 插值，已熄灭刻度在读秒过程中出现半透明残留或恢复，玩家无法清楚判断剩余时间。
- 模型修复：仅将十二个刻度的 Alpha 轨道改为 `DontInterp` 离散显隐；心脏本体和外圈的出生、死亡淡入淡出保持线性。回读 MDX 确认 12 条刻度轨道的 `interpolationType` 均为 `0`。
- 表现修复：胸口骨爪点名层按原模型 `2` 倍显示，处决层按原模型 `3` 倍显示，缩放集中在安兹数值与表现配置中。
- 提示修复：点名真正生效时通过 `QuestMessageBJ(..., bj_QUESTMESSAGE_WARNING, ...)` 向全队显示玩家名、技能名、倒计时、救援范围和失败处决效果，同时播放原生任务警告音；不额外创建或播放私有音效句柄。

## 现实断裂路径表现

- 问题：旧实现只在整条路径中点播放一次静态空间切面，表现没有沿结算路径移动，命中反馈也无法区分路径主体和目标命中层。
- 修复：复用 TS 原生弹幕的固定起终点轨迹，让图 1 路径主体按预警锁定方向移动；技能开始时记录可命中的敌对英雄，每个目标最多结算一次。
- 叠加关系：图 2 只在目标命中坐标额外播放，必须叠加在图 1 路径主体上，不能取代图 1。
- 颜色：图 1 使用真实 RGB `255 / 8 / 255`，图 2 使用 `255 / 255 / 255`。模型预览器虽然按 `R / B / G` 展示输入项，TS 与 JAPI 仍必须按真实 `R / G / B` 字段传递。
- 预警坐标：矩形提示底层把传入坐标视为路径起点，并自行前移半个长度得到模型中心；调用方不得预先传中点，否则预警会沿技能方向额外偏移半条路径。
- 模型朝向：`AinzRealityFractureMovingSlash.mdx` 的视觉正向与需求相反，只通过原生弹幕附加特效的 `朝向角偏移: 180` 翻转模型，不得反转弹幕移动方向或伤害路径。
- 命中层角度：`AinzRealityFractureHitSlash.mdx` 每次命中都用 JASS `GetRandomReal(0, 360)` 独立随机角度，不继承路径主体或 Boss 面向。
- 音效时机：现实断裂技能音效与路径主体实际发射使用同一个 `on生效` 节点；预警阶段只播放台词，不提前播放发射音效。
- 载体：现实断裂保留默认 `eaaa` 单位载体，附加特效只承担视觉；单位壳移除蝗虫并设置弹幕生命，因此可被攻击摧毁，也可进入按单位识别的反弹链路。不得把该技能切成纯特效载体。

## 高阶魔法箭音效与死亡序列

- 音效时机：模型内部七支箭的落地关键帧为 `510 / 620 / 740 / 860 / 990 / 1120 / 1250ms`；配套 MP3 长 `450ms` 且 `0ms` 已有明显波形。因此音效在第一轮箭阵特效创建后延迟 `0.51` 秒播放，使音效起点对齐第一支箭落地；不额外叠加落点预警时间。延迟回调登记到 Boss 清理篮子，台词仍在前摇阶段播放。
- 模型问题：`AinzUndeadArrowVolley.mdx` 原 `Death` 序列持续 `500ms`，三层箭体 Alpha 在该区间渐隐，导致落地结算后仍显示横躺箭阵。
- 模型修复：`Death` 改为 `3000-3001ms`，三层 Alpha 在 `3000ms` 首帧直接为 `0`，所有复用该模型的结算都会直接消失。

## 高阶亡灵召唤模型

- 人物主体使用 `Unit\\Summon\\T13ScourgemaleDeathKnight.mdx`；单位壳从英雄类型 `Udre` 改为非英雄近战类型 `hfoo`，继续承载移动、攻击和单位识别，避免召唤物显示为英雄。
- 模型缩放从 `1.15` 调整为 `2.3`，即在原显示尺寸上扩大 `100%`。
- 主体模型与 `_Portrait` 肖像共同迁入 `imports\\Unit\\Summon`，三张私有贴图统一放入共享 `Texture`，模型内部私有路径同步改写；原生 `Textures\\...` 与队伍色槽保持不变。

## 时间停止结算表现与提示

- 问题：时间停止内部保留了旧的静态 `AinzRealityFracture.mdx`，与普通现实断裂已经升级的路径移动和随机命中叠加表现不一致；魔法箭预警也没有安排对应技能音效。
- 修复：时间停止直接复用普通现实断裂的具名移动入口，继续使用可攻击、可反弹的 `eaaa` 弹幕载体，并在每个目标命中时播放随机角度命中层；时间停止魔法箭也从箭阵特效出现时复用普通技能的 `0.51` 秒延迟音效安排。
- 提示：原 `4.4` 秒合并进度条拆为 `2.8` 秒“时间停止前走位”和 `1.6` 秒“时间停止中”两段，文本明确说明解冻后立即开始伤害结算。
- 尺寸：持续钟面和齿轮碎片均在原配置基础上扩大 `60%`，缩放分别为 `2.24` 与 `1.76`。
- 动作与硬直：原实现虽然调用了限时 `5 channel` 动作，但没有给 Boss 本人施加真实硬直，动作可能被移动或攻击覆盖。现在按项目既有成对写法，在完整时间停止序列期间调用 `开始硬直`，动作与硬直使用同一总时长。

## 光辉翠绿体颜色

- 问题：技能直接手算 `80 * 65536 + 255 * 256 + 120` 作为顶点色，缺少 Alpha 通道，`BigYellowOrbShield.mdx` 实机仍显示金黄色。
- 修复：通用特效封装新增 `设置特效颜色`，内部统一使用 `DzGetColor(alpha, red, green, blue)` 组装完整颜色；光辉翠绿体从配置读取 `RGB 80 / 255 / 120`，Alpha 默认 `255`。
- 二次修复：实测确认普通特效实例可以正确染为翠绿，但不采用 `AddSpecialEffectTarget` 或 `DzBindEffect`。最终复用 `创建单位坐标跟随特效`，由中心计时器每 `30ms` 按 Boss 坐标刷新特效位置，并用专属跟随键统一销毁。
- 实机调参：坐标跟随特效高度暂定 `200`，模型缩放调整为 `1.5`（相对原尺寸扩大 `50%`），均集中在安兹数值与表现配置中。
