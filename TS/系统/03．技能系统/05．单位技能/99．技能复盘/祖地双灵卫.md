# 祖地双灵卫技能复盘

## 伤害类型

- 问题：灵印折步、月纹缚魂、失名祷潮和记忆剥落使用了 `ATTACK_TYPE_MAGIC` 提交魔法技能伤害。
- 原因：把原生攻击类型误当成项目的魔法伤害分类。
- 结论：统一技能链路使用 `ATTACK_TYPE_NORMAL`，魔法分类继续由 `DAMAGE_TYPE_MAGIC` 决定。
- 双灵同誓的高血分担也使用 `DAMAGE_TYPE_MAGIC`，避免 Boss 护甲把分担伤害按物理伤害削弱。
- 同息归寂在锁血回调中延迟到当前伤害结算后再进入暂停/无敌，保证守卫先落到 `5%` 生命再进入灵魂崩解。

## 施法表现、位移控制与路径预警审查

- 灵印折步、月纹缚魂、断誓践踏、裂魂坠斩、誓锋壁进、盾刃裁决、失名祷潮和记忆剥落均会在对应前摇前锁定朝向，并在存在可读前摇时显示常规技能吟唱条。
- 誓锋壁进的方向直线预警从冲锋起点创建，路径伤害也使用同一实际起点和结束点；冲锋期间由公共冲锋系统设置 `暂停单位: true`。裂魂坠斩余震、盾刃裁决重斩和失名祷潮同样使用施法者起点，而不是预警模型中心。
- 封门校验的灵魂潮从场地边缘起点创建，封门误判属于中心圆形机制；两者均由联合施法封装同时限制两名守卫并显示大招读条。
- 侵蚀择形原先只有 1.5 秒变身动作和调度忙碌，没有单位硬直或玩家可见读条。现已在变身动作期间施加硬直并显示“侵蚀择形”吟唱条。
- 断誓践踏第一次踏步为即时战斗位移，第二次踏步才有可读预警；第二次落点重新设置朝向、施加硬直并显示吟唱条。誓盾压制和失名祷潮吸收造成的硬直属于被控制状态，不应显示施法吟唱条。
- 阶段强化命令已按真实分支补齐：`7`/`7-3` 分别测试 P2 盾压制与 P3 破壳净化；`10`/`10-3` 分别测试 P2 吸收镇魂印与 P3 校准净化。`11` 的记忆剥落在 P2/P3 行为相同，保持单一基础命令，不登记空强化命令。
- `AronkosGraveSoulField.mdx` 在祖地双灵卫的祷潮蓄势、空白灵域地面层和封门误判入侵覆盖中统一使用 `4.0` 缩放（在原 `2.0` 基础上扩大 100%）；封门误判现在会在中心预警期间实际创建入侵覆盖层。
- 封门误判中心砸地改为红色 `SpiritGuardGateSlamCrimson.mdx` 与蓝色 `SpiritGuardGateSlamAzure.mdx` 双层叠加，统一使用 `7.0` 倍缩放，均在结算点创建并在 `1.2` 秒后销毁；预警阶段额外创建白色方向直线提示，路径起点为最近净化节点、长度为节点到场地中心的实际距离、显示宽度为 `360`，用于明确标识安全通道。玩家位于月白安全通道时，在最近净化节点坐标创建 `AronkosSoulReleaseAux.mdx` 作为净化反射表现，沿用已有 `12%` 净化反冲易伤。白色方向直线和月白通道均仅是表现层，实际安全判定仍为最近净化节点到场地中心的胶囊区域，判定宽度仍为 `180`、两端半径 `90`。
- `10-3` 实测：测试场景强制使用第 1 个净化节点并切换为“校准”，通过安全站桩恢复/重新固定封装把目标移动到节点坐标；苍影灵卫按目标锁定方向创建原生灵魂潮弹幕，弹幕到达终点后做线段与节点判定。实测目标坐标与节点坐标误差小于 `0.001`，距离平方约 `1.7e-7`，命中为 `true`，节点进入“已净化”，P3 共鸣层数由 `3` 降为 `2`。
- 失名祷潮的 P2 镇魂印吸收改为实时检查飞行中的弹幕单位；命中后先隐藏并按弹幕 ID 销毁，再消耗镇魂印和压制苍影灵卫，避免使用弹幕实例对象导致模型残留。
- 双灵同誓关闭保护时，持续单位连线实例的 `停止` 必须按实例方法调用。接口不能把该方法声明为 `this: void`，否则 TSTL 会生成缺少 `self` 的 Lua 调用；现已改为实例方法签名，并通过具名包装函数统一停止连线。
- 记忆剥落已接入配置中的两层表现：预警阶段在每个锁定坐标创建 `1.5` 倍“褪色预警”符文特效；空白灵域生成后在静态地面特效上叠加动态灵魂波纹层。区域每 `0.25` 秒创建一份动态灵魂波纹，单份约 `0.3` 秒后显式隐藏并销毁；同时对其中单位刷新 `30%` 攻速与移速减速，单次减速持续 `0.5` 秒，离开后自然解除。所有逐 tick 特效均登记到机制清理篮子，战斗结束时取消延迟回调并清理句柄。
- 被动测试命令已改为直接触发可观察结果：`13` 将赤誓灵卫设为 `70%`、苍影灵卫保持 `100%`，形成 `30%` 生命差后更新双灵同誓，再对低血守卫施加 `10%` 最大生命魔法伤害，避开 P1 的 `65%` 侵蚀下限并直接观察减伤与高血分担；`14` 从 P1 满血对赤誓灵卫施加 `90%` 最大生命魔法伤害，验证 `65%` 侵蚀生命下限和首次变异；`15` 先准备 P3，再对赤誓灵卫施加 `80%` 最大生命魔法伤害，验证 `5%` 同息归寂生命下限、暂停无敌和灵魂崩解表现。
- 特殊被动专用命令：`13` 验证双灵同誓低血减伤与高血分担，`14` 验证侵蚀阶段生命下限触底与转阶段，`15` 验证 P3 同息归寂生命下限和崩解触发。纯被动机制仍默认随测试场景自然注册运行。
- 测试上下文显式绑定侵蚀生命下限和同息生命下限控制器；每次执行 `13/14/15` 前解除暂停与无敌、清理双灵卫 Buff、恢复联合生命周期和净化节点表现，避免连续测试时残留状态阻断触发。
