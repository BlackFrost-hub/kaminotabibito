- 同系列另一主角「朱雀院红叶」（长女，本项目 21 号英雄）官方面板为：心 A / 技 S / 体 A / 敏 A+ / 灵 A+（来源：萌娘百科，维度命名与椿的四维面板略有差异，且两部作品分属不同代数，不可直接数值互通）。
- 关键差异方向：红叶「灵 A+ / 敏 A+」偏高速战术 + 高灵；椿「体 A+ / 技 A+ / 灵 A−」偏耐打 + 技巧 + 低灵。制作椿时应体现「低灵、高体技」的内核差异，而非做成红叶换皮。

## 2. 身份与家族背景

### 2.1 朱雀院家

- 战国时代延续至今的武家，历史上是「侍奉大名的武士」，刃道名门。
- 家训/教义方向：「独立独步」——依靠自身力量，自锻刀、自挥刀完成修行，不轻易依赖他人（社区资料，待核对原文）。
- 四姐妹（长女到四女）：
  1. **朱雀院红叶（もみじ）**：长女，头脑派战术家兼剑士，刀「燕长光」（长度超 1 米的长刀），神速砍击 + 精确先读（神眼极手），领悟「诸法无我」境界。其人设偏慵懒、想尽情享乐。→ 本项目已建 21 号英雄。
  2. **朱雀院抚子（なでしこ）**：二女，职业刃道选手（同人二创提及「全国大赛五连冠」，非官方确认）。
  3. **朱雀院都子（とこ）**：三女，与椿关系最好，实力在椿记忆中「四姐妹最强」；在《椿恋歌》中向椿展示朱雀院奥义「炎姬」。后离家、四处见世面。
  4. **朱雀院椿（つばき）**：四女，本作主角。

### 2.2 家族人物（待核对）

- 祖父：朱雀院柾盛（武痴，同人二创描述）。
- 父亲：朱雀院柾胤（入赘，同人二创描述其为「自视甚高」、承受家族压力）。
- 家族压力：椿作为最小者，长期被拿来与优秀姐姐们对比，承受「不能输」的强烈压力。

### 2.3 白狐血统

- 朱雀院家中人具有白狐血统（社区资料 + 萌娘百科）：受到妖气影响时会显现狐耳等兽耳特征；妖气散去后恢复。

## 3. 性格与心理

- **表面**：笑脸常驻、对他人情绪体察入微、品行端正的完美优等生；生气时也笑着发怒（「怒るときも笑顔で怒る」）。
- **内核**：不轻易吐露本心，追求「靠自己一个人就能成立、没有任何缺点的强人」，对他人几乎不示弱。
- **枷锁**：常年被「朱雀院」之名与优秀姐姐们的阴影所困，自卑感强、自我肯定极低，「必须一直赢下去」几乎等同于自我存在的证明，对失败怀有深刻恐惧。
- **对男主**：自称三城刀辉的「姐姐」（青梅竹马、年上一级），对其过度宠爱（ベタ甘），恋爱中追求主动、独占欲强；口头禅式台词（官方角色页）：

> 「刀輝くん？ お姉ちゃん、性欲をコントロールできない男の子はダメだと思うなー？」

## 4. 作品与剧情经历（含剧透）

### 4.1 《绊きらめく恋いろら》（2017）椿线

1. 椿是学园公认最强，但内心被「必须保持不败」压垮，进入一种强大却脆弱的「只有强」状态。
2. 与宿敌千石葵的决战中，椿虽然获胜，但自锻折纸「无铭」被葵击碎——精神也随之被击碎。
3. 朱雀院家认定「本家中人不该有如此寒碜的胜利」，公开与椿断绝关系。
4. 刀辉向椿表白，两人交往；刀辉收集「无铭」碎片重铸成新刀「浴火鸟」，并击败葵。
5. 椿由此打破束缚自己的「笼子」，决定以职业选手为方向。

### 4.2 《绊きらめく恋いろは -椿恋歌-》（2019）

1. 演武祭决赛前，三姐都子向椿展示朱雀院奥义「炎姬」。
2. 演武祭后，椿以「刀仕襧宜」身份赴本土出席活动。
3. 在学园遭遇由灵刀「红朱雀」形成的化妖「辉夜」，被种下妖气之种；因白狐血统，次日长出狐耳（后随妖气散去而消失）。
4. 最终椿以「黄泉凤凰」「加具土命」与脱胎自「炎姬」的二刀流招式击败辉夜，令其恢复为灵刀红朱雀。

## 5. 世界观与能力体系

### 5.1 刃道（じんどう / 灵式机巧刀刃道）

- 正式名称「灵式机巧刀刃道」，通称「刃道」；使用**开刃真刀**进行 1v1 比赛的新型运动/竞技，只要在规则内对战即不会受伤（未来剑道）。
- 剑士装备机巧化的特殊刀具与装具对战。
- 具有神事/祭神性质：「刃道是为神献上的剑舞」，与相扑同类。
- 胜负判定的核心防护机制是「VF 场（VF-Field，不可见防御力场）」；折纸破碎或防护力场失效即判负（社区二创补充「以护盾剩余百分比多少定胜负」，属二创细化，非官方原文）。

### 5.2 灵式机巧刀「折纸」（オリガミ / 折紙）

- 标准名「灵式机巧刀折纸」，通称「折纸」；由三城家于明治维新时发明。
- 属灵式武器（灵刀），由「魂钢」锻造、经刀匠机巧化处理；为刀与鞘的一套总称。
- 可简易发动特殊能力「天咒」。
- 「刃道」即以折纸为武器展开的战斗。

### 5.3 魂钢（たまはがね）

- 将灵山之土、祈祷供奉的翡翠/琥珀等按特定作法投入铁中而得的金属，据传有精神感应作用，故又称「精神感应触媒」。

### 5.4 天咒（てんじゅ）

- 将精神力量转化为物理现象的不可思议能力之总称；一般指借「魂钢」等精神感应触媒发动的能力。
- 主要类型：身体能力提升、展开不可见防御力场「VF 场」等。
- 效果个体差异大，与「触媒相性」共同决定能引出能力的规模。

### 5.5 精神感应系数

- 衡量个体对灵式机巧刀（折纸）性能的发挥资质，是「武艺科」入学/选拔的重要指标。
- 椿的该项在朱雀院四姐妹中最弱（仍高于一般基准），是唯一短板。

### 5.6 战人 / 刀匠（锻冶师）

- **战人（いくさびと）**：以魂钢灵刀为武器战斗者之总称；持折纸战斗的刃道剑士亦称战人。
- **刀匠（刀鍛冶）**：为刃道制作武器的人，需「刀剑加工 / 电子回路 / 编程」等技术；赛时亦担任支援的 operator / 维护技师（男主三城刀辉即刀匠立场）。

## 6. 学园与赛事

### 6.1 丛云学园

- 防卫省管辖，日本唯一、世界唯一专门教授刃道的学园，位于第五海上特区「住吉学府」中央。
- 全寄宿制，学生生活几乎都由学园管理；整座人工岛皆为学园领地。
- 标语「遊びたければ怪我するな」（想玩就别受伤；受重伤会被塞进土日治疗舱）。

### 6.2 学科

- **武艺科**：培养刃道剑士；对折纸使用资质要求高，尤其精神感应系数。
- **技巧科**：培养刃道刀匠；男主所属。

### 6.3 丛云演武祭

- 丛云学园每年夏季举办的刃道大赛，全国转播，含「祭神」意味；鹿岛、热田等神社宫司会聚集举行供刀等仪式，防务省大臣亦出席。
- 「刀仕襧宜」为学园最强武艺者的称号，是众多剑士竞争的目标。

## 7. 战斗能力与风格

### 7.1 核心战斗形态：居合反击 + 二刀流

- **居合反击型**：以居合反击（カウンター）为主轴、擅长「後の先（后发先至）」的防反击型剑士。
- **二刀流高手**：左右手均能随战况临机切换攻防角色；攻击手数多、间合广，守势时尤为坚固。
- **平时封印二刀流**：日常以一刀应战，依据对手强度决定是否解放二刀流。
- 武器为「双太刀」组合，并非常见「二天一流」的太刀 + 小太刀配法。

### 7.2 战术倾向（社区二创细化，符合作品定位）

- 抢先出手、以剑技削弱对手护盾后立即转入守势，靠「护盾剩余比例」取胜（二创细化）。
- 追求「抢分 + 龟缩」的效率型打法，观赏性低但极为坚韧；动机源于「不想输」。
- 训练强度极高：长时间模拟训练（二创提及其训练至设备超温断电、挥刀到极限等）。

> 上述 7.2 为同人二创对官方「居合反击 / 防反击 / 二刀流守势坚固」定位的文学化放大，制作用作气质参考即可，不作为硬性数值依据。

## 12. 制作定位提示（供后续规划参考，非最终结论）

- 从官方四维「体 A+ / 技 A+ / 灵 A−」看，椿是**近战技巧 + 高耐打 + 低灵力**型剑士，天然适配「防守反击 / 二刀流 / 反击技」的近战循环，区别于红叶的「高速先读 / 高灵」。
- 若后续制作，联动资源应围绕「居合反击、二刀流形态、护盾（VF 场）/破绽、刀势类资源」展开，而非法术、召唤、远程规划。
- 白狐血统（妖气显耳）与「炎姬」系奥义可作为特色表现或终结技素材方向。
