## 1. 执行规则

这是给后续迁移模型执行的计划文件。实现时必须先读：

1. `.cursor\rules\gameplay\skills\hero-production-workflow.mdc`
2. `.cursor\rules\gameplay\skills\skill-damage-shape-and-independent-skill.mdc`
3. `.cursor\rules\gameplay\skills\boss-production-workflow\02．技能实现与表现规则.mdc`
4. 本计划文件、塞拉斯两份 JASS 源码、对应物编表和项目公共封装。

硬规则：

- JASS 的事件入口、分支顺序、等待时长、动作、音效、特效、控制和伤害时点是迁移真源；技能介绍与 JASS 冲突时，最终玩法按技能介绍，但冲突必须保留在本文件的审计表中。
- 所有真实游戏数据必须同步。`GetLocalPlayer()` 只能包住 UI、文字、音效等本地表现，不能包住伤害、属性、魔耗、冷却、技能等级、技能可用性、位置、Buff 或状态机。
- 百分比魔耗由项目统一魔耗系统处理。塞拉斯技能文件只提供物编/配置数据，不得再次直接扣除最大魔法值；尤其不能在本地分支修改真实蓝量。
- 伤害必须走项目统一技能伤害封装，禁止在迁移代码中使用裸 `UnitDamageTarget`。
- 技能需要动作或硬直时严格执行：校验 -> 添加项目暂停来源 -> 同阶段立即播放动作 -> 按时间线创建表现/控制/伤害 -> 所有结束路径清理暂停和特效。
- 源 JASS 通过单位马甲只做视觉效果的，先查 `map\table\unit.ini`、物编源表和 `map\table\imp.ini`，核对模型、缩放、飞行高度、朝向、动画速度和生命周期，再改为点特效或绑定特效。单位同时承担碰撞、技能施放、路径、光环或真实玩法时才保留单位载体。
- 特效方向只设置一次最终矩阵。若已经使用旋转封装设置了最终方向，后续跟随移动只能更新坐标，不能重复叠加同一旋转。
- 所有延迟回调、计时器、特效、暂停来源、Buff、技能实例和目标引用都要有正常结束、打断、死亡、目标失效、重复施法和战斗结束清理路径。
- 迁移完成后必须按“正常施法、连续施法、目标死亡/失效、技能被打断、Boss 弱点不存在、Boss 护盾破碎中”逐项验收。

## 4. Boss 弱点公共接口

本次已新增通用接口：

```ts
const { 调查Boss弱点 } = require(
  "系统.03．技能系统.06．AI自动使用技能.03．Boss战启动桥接.03．Boss血条弱点韧性.08．对外接口",
) as {
  调查Boss弱点: (this: void, Boss单位: any, 来源单位?: any) => Boss弱点调查结果;
};

const result = 调查Boss弱点(目标Boss, 施法者);
```

接口行为：

1. 校验 Boss 单位和活动 Boss 运行状态。
2. 校验弱点机制、弱点 UI、弱点伤害结算均已注册。
3. 按当前配置顺序找到第一个 `弱点已暴露列表[i] !== true` 的弱点。
4. 直接显示该弱点的真实图标。
5. 播放全员弱点发现音效和可选的全员提示。
6. 直接削减 1 点护盾；护盾归零时复用现有破盾状态机。
7. 不调用普通伤害入口，不触发普通弱点击中的伤害加成、单弱点保护冷却或命中缩放表现。
8. 返回 `Boss弱点调查结果`，包含成功状态、原因、弱点索引、弱点键、当前护盾值和是否处于破盾状态。

失败原因包括：`单位无效`、`Boss状态不存在`、`弱点机制未启用`、`弱点UI尚未注册`、`弱点结算尚未注册`、`护盾破碎中`、`没有未显现弱点`。

塞拉斯 D 只应调用该接口，不得复制弱点顺序、YD 字段、保护护盾切换和 10 点裸伤害。接口本身是同步玩法逻辑，不能放在 `GetLocalPlayer()` 分支。

## 5. D：天赋技“调查 Boss 弱点”

### 介绍和物编

- 技能：`A0JP`
- 目标：Boss 单位，施法距离 800
- 作用：调查并显示一个尚未显示的弱点；显示新弱点时削弱 Boss 1 点护盾
- 冷却：45 秒
- 魔耗：最大魔法值 5%
- 物编 `Cost=75` 与技能介绍冲突；最终使用统一百分比魔耗系统，技能文件不得写第二份扣魔。

### 源 JASS 行为

- 目标不是当前 Boss 战单位时，只向施法者提示并返回。
- 播放 `gg_snd_SLD_D`。
- 依次检查：剑、杖、枪、短剑、斧、弓、火、冰、雷、风、暗、光。
- 找到第一个已配置且尚未暴露的弱点后立即返回。
- 旧实现暂时关闭保护护盾后用 10 点不同攻击/伤害类型伤害触发显示，再恢复保护状态。

### TS 实现要求

- 目标校验仍由技能入口完成，成功后调用 `调查Boss弱点(目标Boss, 施法者)`。
- 不复制旧 JASS 的 YD 字段，不使用 `UnitDamageTarget`，不使用伤害触发显现。
- `gg_snd_SLD_D` 播放点要与源 JASS 对齐；若公共接口已经播放弱点发现音效，不要在 D 中重复播放同一个弱点反馈音效。
- 没有未显现弱点、Boss 已破盾或状态未注册时，D 不应对 Boss 造成任何额外伤害或状态修改。

### 时间线

| 时点 | 内容 |
|---|---|
| `t0` | 校验施法者、目标、技能等级、当前 Boss 状态 |
| `t0` | 播放 D 技能音效；若源技能需要动作，先添加暂停来源，再立即播放动作 |
| `t0` | 调用 Boss 弱点接口，显现图标并同步削盾 |
| `t结束` | 释放本技能独立上下文，不留下额外暂停、特效或目标引用 |

## 6. Q：魔法知识和三种普通魔法

### Q 入口 `A0JT`

- Q 入口打开三种普通元素魔法。
- `A0JT` 等级同步复制到 `A0JQ`、`A0JR`、`A0JS`。
- 开启/关闭只改变技能的可用性、显示和按钮槽位，不修改真实冷却实例，不走本地技能数据修改。
- 必须接入项目已有技能可用性、技能等级同步和本地按钮显示封装。
- 普通魔法状态不能与大魔法状态同时残留；重复开启时先清理旧状态再建立新状态。

### 普通魔法共同规则

- 目标点为施法点，目标点周围 500 范围。
- 启动后每 `0.21` 秒结算一次。
- 普通状态结算 1 次，大魔法状态结算 2 次。
- 每个技能实例保存本次施法者、目标点、等级、元素、是否大魔法、已结算次数和特效/计时器清理句柄。
- 过滤：存活、非远古、非机械、非建筑、敌对；源被动追加伤害还要求目标不是玩家拥有单位。
- 范围技能按 AOE 伤害形态结算，不能因为本次只命中一个目标而改成单体形态。
- 每一段伤害前后顺序按 JASS 对齐：预警/施法表现 -> 命中特效 -> 统一伤害封装 -> 元素状态/Buff。

### 火焰 `A0JQ`

- 伤害：攻击力 × `(1.40 + 0.10 × A0JT等级)`；一级为攻击力 150%。
- 伤害属性：火。
- 每个命中目标添加火焰攻击标记，供远程普攻被动读取。
- 灼烧：持续 2 秒，每秒造成目标已损失生命值的 1.5%。JASS 使用 `SLSQ` 计数，每次普通火焰命中增加 2 层；迁移为 TS Buff 层数和周期伤害状态。
- 源特效：`war3mapImported\fire.mdl`、`war3mapImported\FireImpact.mdl`、`Objects\Spawnmodels\Other\NeutralBuildingExplosion\NeutralBuildingExplosion.mdl`；灼烧特效为 `war3mapImported\Fire2.mdl`。
- 灼烧周期伤害不能再次触发塞拉斯的远程普攻附加被动。

### 冰冻 `A0JR`

- 伤害：攻击力 × `(1.20 + 0.10 × A0JT等级)`；一级为攻击力 130%。
- 伤害属性：水/冰。
- 冻结 0.6 秒；真实控制走项目控制封装。
- 使用 `SFB_setBuff` 的部分迁移为项目控制封装，并登记玩家可见 TS Buff。
- 源特效：`war3mapImported\FrostNova.mdl`、`war3mapImported\ICE.mdl`。
- 目标死亡、技能打断和多段结算时，不能留下冻结控制或 Buff。

### 雷击 `A0JS`

- 伤害：攻击力 × `(1.40 + 0.10 × A0JT等级)`；一级为攻击力 150%。
- 伤害属性：雷。
- JASS：`SFB_setSlow(目标, 0.0, 0.99, 1.20)`。
- 技能介绍写“净化 1.4 秒”，与 JASS 的 1.20 秒存在冲突。按英雄制作规则最终以技能介绍为准，TS 使用 1.4 秒；在实现注释中保留 JASS 1.20 秒作为审计值，不能静默改写记录。
- 源特效：`Abilities\Spells\Orc\Purge\PurgeBuffTarget.mdl`、`war3mapImported\OrbOfLightning.mdl`。
- 目标音效：`gg_snd_CorrosiveBreathMissileLaunch1`。

## 7. W：大魔法化 `A0JW`

### 规则

- 介绍：刷新魔法知识 Q 冷却，三种普通魔法升级为大魔法；下一次大魔法二连击，所有效果二连击。
- 魔耗：最大魔法值 20%，由统一百分比魔耗系统处理。
- 冷却：`20 - 0.5 × 技能等级` 秒；1 级 19.5 秒，15 级 12.5 秒。
- 物编 `Cost=125` 与介绍冲突，不能用物编固定魔耗替代统一百分比魔耗。

### 源 JASS 时间线

1. 播放 `gg_snd_SLS_ZW` 与 `gg_snd_Tranquility01`。
2. 创建 `war3mapImported\[AKE]war3AKE.com - 4824137662399555907875383.mdl` 和 `war3mapImported\Teleport.mdl`。
3. 同步设置“大魔法化=true”。
4. 旧 JASS 用 `YDWESetUnitAbilityState` 把 A0JT/A0JQ/A0JR/A0JS 剩余冷却置 0.05；同步冷却刷新属真实游戏数据，TS 用 `技能_设置技能冷却时间`（DzSetUnitAbilityCool）同步实现（2026-08-17 修正：此前误判为“TS 禁止改真实冷却”导致 W 不刷新 Q，已补）。
5. `0.15` 秒后添加 `A0JV`，显示 `A0JQ/A0JR/A0JS`，隐藏 `A0JT/A0JW/A0JX/A0JY`，并同步元素技能等级。
6. 下一次普通魔法按两次结算，然后消费“大魔法化”状态。
7. 关闭入口恢复普通按钮的可用性和显示。

### 状态机要求

建议建立一个塞拉斯专用同步状态表，而不是在每个技能里散落布尔值：

```ts
interface 塞拉斯魔法状态 {
  英雄句柄ID: number;
  普通魔法已开启: boolean;
  大魔法化: boolean;
  当前元素: "火" | "冰" | "雷" | "";
  普通魔法技能等级: number;
  当前技能实例ID: number;
}
```

所有开关动作必须是同步状态修改；`GetLocalPlayer()` 只负责每个本地客户端看到的按钮/文字。状态机必须处理重复开启、关闭、死亡、英雄替换、目标失效和战斗结束。

## 8. E：属性提升 `A0JX`

- 被动技能，15 级。
- 每级魔法伤害增加 `(10 + 3 × 技能等级)%`，因此等级 1-15 为 13%、16%、19% ... 55%。
- `reqLevel=1`，`levelSkip=3`。
- JASS 主技能文件只负责普通/大魔法按钮切换，没有直接应用 E 增伤逻辑。
- 必须接入项目统一魔法伤害修正入口，在一个公共修正器中读取 `A0JX` 等级；不能在火、冰、雷技能中各自重复判断。
- 只修正塞拉斯的魔法技能伤害，不误伤普通攻击、灼烧周期伤害或其他英雄的魔法伤害。
- 伤害修正必须保持同步，不能在本地读取等级后修改真实伤害。

## 9. R：知识与旅行的学者 `A0JY`

## 10. 被动：远程普攻属性附加

来源：`被动效果，配合Q.j`。

### 触发条件

- 统一伤害系统伤害事件判定为普通攻击/普通伤害。
- 伤害来源单位类型为 `H014`。
- 目标为敌方，且不是玩家拥有单位。
- 施法者到目标距离至少 500。
- 之前使用过火焰、雷击、冰冻普通魔法之一，并且对应标记仍在。

### 效果

- 下一次远程普通攻击追加“当前魔法值 × 40%”伤害。
- 追加伤害属性为最近一次普通魔法元素。
- 触发后清除对应元素标记。
- 延迟约 `0.12` 秒，在施法者位置附近 350 范围内对敌人追加一次属性伤害。
- 追加伤害也必须走统一技能伤害封装，并设置内部来源/技能实例标记，防止再次触发本被动。
- 火焰特效：`war3mapImported\minitype flame02.mdx`。
- 雷击特效：`war3mapImported\lightningwrath.mdx`。
- 冰冻特效：`Abilities\Spells\Undead\FreezingBreath\FreezingBreathMissile.mdl`。

### 状态设计

不要只用散落的布尔值。至少记录：英雄句柄、当前元素、标记层/有效时间、是否已被下一次攻击消费、技能实例 ID。英雄替换、死亡、技能关闭和战斗结束都要清理。
