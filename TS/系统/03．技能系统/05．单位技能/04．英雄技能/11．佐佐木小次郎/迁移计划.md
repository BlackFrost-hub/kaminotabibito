## 源 JASS 初步差异审计（行为真源）

### 通用
- 单位类型过滤：`UNIT_TYPE_ANCIENT / UNIT_TYPE_MECHANICAL / UNIT_TYPE_STRUCTURE` 排除，敌人判定 `IsUnitEnemy`。
- 存活判定 `IsUnitAliveBJ`。
- 控制：`SFB_setBuff(target, 21, 0.30)` → 减速 0.3s（对应项目控制系统查询）。
- 伤害：裸 `UnitDamageTarget` → 迁移需走「造成单体技能伤害」或「造成AOE技能伤害」封装，按语义选 AOE。
- 特效：`EC_CreateEffect(model, x, y, 0, 270, sx, sy, sz)` → 对应 TS `创建点特效`，朝向用「面向角度」参数（270=面向？待与封装对齐）。
- 马甲创建：`CreateUnit(owner, 'e07U', x, y, angle)` → 刀光马甲 `e07U`；**纯视觉+伤害，迁移时查物编参数（file/modelScale/moveHeight/timeScale）后考虑改直接点特效或保留马甲**。
- 暂停 / 硬直：`EXSetUnitMoveType(u, 0x02)` + `YDWEUnitRemoveStun` → 迁移对照项目硬直暂停系统。
- 充能技能共享：`SetPlayerAbilityAvailable` 切换 `A0GS↔A0GT`、`A0GQ↔A0GR`，并 `YDWESetUnitAbilityState(skill, 1, 0.01)` 冷却复位。
- D 技能禁用：Q/W 释放时 `UnitRemoveAbility(GetTriggerUnit(), 'A0GU')` 禁分身，结束后 `UnitAddAbility(GetTriggerUnit(), 'A0GU')` + `YDWESetUnitAbilityState('A0GU', 1, 3.00)` 恢复。

### Q 前斩（A0GT / A0GS 共享链）

## 技能槽位说明

佐佐木小次郎技能 ID 与常规「01被动 02Q 03W 04E 05R」不同：
- **Q** = `A0GT`（本体） + `A0GS`（二段），共享充能互切
- **W** = `A0GQ`（本体） + `A0GR`（二段），共享充能互切
- **E** = `A0GV`
- **R** = `A0GP`
- **D** = `A0GW`（常驻被动图标；`A0GU` 仅为源 JASS 的历史冷却壳，TS 不再使用）

实际注册到英雄技能 `index.ts` 时，**槽位序号不按字母 QWER 推导**，要对照技能系统 `00．技能配置.ts` 与总英雄单位注册顺序确认并写注释。

#### 分身创建机制（用户确认 + 源码 `Trig_zzm_QFunc001Func018Func007T` 已验证）
1. 创建**辅助马甲**：`CreateUnit(玩家, YDUserDataGet(string,"辅助马甲","单位类型"), 施法者XY, 0)`（马甲类型ID 待从全局初始化 JASS 查）。
2. 给马甲添加**幻象技能**：`UnitAddAbility(马甲, YDUserDataGet(string,"幻象","技能"))`（技能ID 待查）。
3. 设置幻象技能数据字段（`YDWESetUnitAbilityDataReal`，等级1）：
   - 字段 **108 = 0.10** → 分身造成 **10% 攻击** ✓
   - 字段 **109 = 3.00** → 承伤 **300%**（用户口径 400%，按用户为准写 4.00）
   - 字段 **102 = 3.00**、**103 = 3.00** → 持续时间普通/英雄均为 **3 秒** ✓
4. 马甲对英雄施放幻象：`IssueTargetOrderById(马甲, 852274, 英雄)`。
5. **分身检测**（源码 `Trig_zzm_QFunc002Func026Conditions`）：
   - 事件：单位召唤 `EVENT_PLAYER_UNIT_SUMMON`
   - 判定：`GetUnitTypeId(GetSummonedUnit()) == GetUnitTypeId(GetTriggerUnit())`（召唤物与英雄同类型即分身）
   - **TS 对应封装**：`注册召唤监听/取消召唤监听`（[09．单位召唤事件中心.ts](../../../../00．核心系统/01．事件中心/09．单位召唤事件中心.ts)，回调参数 `(被召唤单位, 召唤单位)`）
6. 检测到分身后立即（源码 W 分支示例）：
   - `YDWEUnitAddStun(分身)`（「几乎不可移动」的来源之一）
   - `EXSetUnitCollisionType(false, 分身, 1)` 去碰撞
   - 传送到目标点 D：`SetUnitX/Y`
   - 播放动作 9（`SetUnitAnimationByIndex(分身, 9)`），`SetUnitTimeScale(分身, 1.20)`
   - **W 分支的分身落地即结算**：以分身/召唤者混合坐标为中心 425 码扇形 ±135°（270°）× **1.70** 伤害 + `coarse slash blue.mdx` 命中特效（⚠️ 源码枚举中心写的是 `GetUnitX(GetSummonedUnit()) + GetUnitY(GetSummoningUnit())`，X 取分身、Y 取召唤者，疑似 GUI 原生 bug，迁移时按语义取分身坐标并记录）
   - 1.00 秒后恢复：`SetUnitTimeScale(分身, 1.00)` + `YDWEUnitRemoveStun(分身)`
