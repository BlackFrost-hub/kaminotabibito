# 食人魔双形态迁移工作记录

更新时间：2026-08-04

本文件用于记录沙漠食人魔与杀戮食人魔的迁移依据、已确认口径、当前完成度和后续实施顺序，避免上下文压缩后重复检索或遗漏机制。

## 工作约束

- 主代理独立完成，不再创建或派发子代理。
- 设计文档决定机制与数值；JASS 决定动作、特效、音效和时间线。
- Boss 动作必须在暂停/硬直建立后播放；硬直技能必须显示吟唱条。
- 需要玩家辨识的持续机制必须使用 TS Buff 表达。
- 特效路径严格沿用 JASS 原路径，不迁移特效模型，不擅自替换为 `Common` 路径。
- 禁止匿名 JASS 回调；所有计时器、事件和弹幕回调使用具名函数并标注 `this: void`。
- 禁止使用 Lua 数学库或 `Math.*`；使用 JASS 数学原语或项目本地函数。
- 不修改 `fix-lua-for-pack.js`，不混用 `jass`、`BJ`、`japi` 的同类普通版接口。
- 新建 TS 文件顶部统一添加 `/** @noSelfInFile */`。
- 优先调用带 `@noSelfInFile` 兼容的安全版封装；普通版不直接调用。
- 调试输出只使用 `TS/lib/扩展函数/自定义扩展函数/03．调试输出.ts`。
- 除检查 TSTL `self/nil` 错位外，不主动查看生成 Lua。
- 只构建，不打包地图；优先 `build:files`，最终接入后再执行一次完整 `npm run build`。

## 已确认的冲突口径

- 蓄力重击按设计文档的第 4 次普攻触发，不复刻旧 JASS 实际延后一击的错误。
- 蓄力重击第四击按设计使用攻击力 100%，并确保 100% 暴击语义。
- 雷霆敲打按设计使用攻击力 200%，不采用旧 JASS 的 300%。
- 血海绞杀按设计使用攻击力 200%，不采用旧 JASS 的其他倍率。
- 痛之束缚按设计使用 10% 与 1200 码，不复刻旧 JASS 的 22%、1250 码或 `T <= 2` 禁用条件。
- 疼痛复仇的 1250 与 2000 使用两个独立累计池，并保留跨阈值余量。
- 疼痛复仇每个 10% 增伤层独立持续 3 秒；Buff 显示当前有效层数，层到期由运行时独立维护。
- 疼痛复仇每累计 2000 伤害时驱散控制并刷新血海绞杀。
- 心脏掌握只在有效目标低于阈值时进入 12 秒冷却，不在每次 Boss 造成伤害时空转冷却。
- 心脏掌握使用完整 3 秒预警；结算时读取目标当前生命值的 200%；300 范围内有效伙伴平均分摊。
- 魔咒中的 `T` 使用 `取当前有效玩家人数()`。
- 单人魔咒持续时间按旧 JASS 分支采用 `3 + T * 0.5`，多人采用 `5 + T * 0.5`。
- 风暴之锤创建后必须把弹幕单位的最大生命值和当前生命值设置为 Boss 最大生命值的 30%。
- 啃食时间严格使用 `2.6 - N * 0.2`，不得自行添加最小值。

## JASS 时间线与表现

### 食人魔咒 / 深渊魔咒

- 技能事件后延迟 1.5 秒施加诅咒。
- 生效特效：`war3mapImported\\desecrate.mdl`。
- 深渊魔咒技能施放反噬特效：`war3mapImported\\ethereal lightning.mdl`。
- 食人魔咒反噬为强化伤害；深渊魔咒反噬为暗属性伤害。
- 有其他存活队友时，技能施放反噬转移给随机其他队友；治疗反噬不转移。

### 风暴之锤

- 指定目标追踪弹幕，持续 5 秒；过程可碰撞任意敌人。
- 弹幕模型：`Abilities\\Spells\\Human\\StormBolt\\StormBoltMissile.mdl`。
- JASS 弹幕单位缩放为 3，红色顶点色，命中检测半径 100。
- 命中点 500 AOE；基础攻击力倍率 500%，眩晕 2 秒。
- 实际碰撞目标不是指定目标时，伤害和眩晕时间均乘 0.6。
- 单人模式下基础伤害与控制先乘 0.6。
- 命中特效：`Abilities\\Spells\\Orc\\WarStomp\\WarStompCaster.mdl`。
- 5 秒到期未命中时只清理弹幕，不产生伤害和控制。

### 雷霆敲打

- 总硬直 5 秒，期间无敌。
- 每 1.2 秒一轮，共 4 轮。
- 每轮先播放动画编号 6，并读取当时 Boss 面向。
- 每轮四方向创建 `war3mapImported\\bossjinggaoh.mdl` 预警。
- 每轮预警后 0.5 秒发射四方向冲击波。
- 每轮约 0.85 秒后转向，旧 JASS 使用随机约 75 至 90 度；迁移配置当前采用 82.5 度稳定旋转。
- 弹幕存活约 1.2 秒，旧 JASS 碰撞检测半径 195。
- 命中特效：`Abilities\\Spells\\Human\\Thunderclap\\ThunderClapCaster.mdl`。
- 设计结算：攻击力 200% 风属性伤害，并减速 25% 持续 1 秒。

### 雷霆震怒

- 总硬直与无敌时间 3.75 秒。
- 普通形态起手动画编号 3；异常形态旧 JASS 使用 `Attack` 动画。
- 0.8 秒开始牵引。
- 牵引 12 次，每 0.07 秒一次，每次 32.5 距离。
- 牵引目标范围 1700。
- 1.9 秒进入敲击阶段；旧 JASS 后续 1.1 秒结算地面伤害。
- 地面结算筛选 Boss 周围 2000 范围内每名敌人，再以各敌人为中心对 600 范围结算；重叠可重复命中。
- 伤害为攻击力 250% 加被命中目标最大生命值 25%，标签为技能普攻伤害。
- 结算表现包含：
  - `Abilities\\Spells\\Human\\Thunderclap\\ThunderClapCaster.mdl`
  - `war3mapImported\\SandWaveDamage.mdl`
- 蓄力表现沿用 JASS：`war3mapImported\\[AKE]war3AKE.com - 8146994216305873548723316.mdl`。

### 血海绞杀

- 技能事件后 0.03 秒进入施法流程。
- 先消耗 Boss 最大生命值 7%。
- 硬直 1.35 秒，动画编号 11，起手阶段无敌。
- 四方向预警：`war3mapImported\\bossjinggaoh.mdl`。
- 0.7 秒后解除无敌并发射四道血海。
- 弹幕模型：`war3mapImported\\blood2022720203813.mdl`。
- 命中特效：`war3mapImported\\bloodex-special-2 (4).mdl`。
- 设计结算：每道血海对 250 范围造成攻击力 200% 暗属性伤害并眩晕 1 秒。

### 痛之束缚

- 施法后建立 Boss 与目标的持续链接，不施加眩晕、定身或减速。
- 闪电代码：`AFOD`。
- Boss 每次实际受伤后，目标承受该次伤害 10% 的强化伤害。
- 距离超过 1200 码立即断裂并清理 Buff/闪电。
- 命中特效：`Abilities\\Spells\\Demon\\DemonBoltImpact\\DemonBoltImpact.mdl`。
- 必须设置递归保护，束缚反伤不能再次触发自身。

### 心脏掌握

- Boss 造成实际伤害后检查受击玩家是否低于 `25% + N * 5%`。
- 单人模式阈值乘 0.6。
- 有效触发后进入 12 秒冷却。
- 旧 JASS 总时间线为 2 秒初步预警加 1 秒斩首结算，共 3 秒。
- 预警特效：
  - `war3mapImported\\[AKE]war3AKE.com - 1716862506547375212002341.mdl`
  - `war3mapImported\\[AKE]war3AKE.com - 1921116848165847633007217.mdl`
- 结算读取目标当时当前生命值的 200%，按 300 范围内参与分摊的有效英雄数量平均结算暗属性伤害。

### 疼痛复仇

- 每累计受到 1250 实际伤害，增加一层 10% 伤害，持续 3 秒且不可驱散。
- 每累计受到 2000 实际伤害，清除控制并刷新 `A0L0` 血海绞杀。
- 解控特效：`Abilities\\Spells\\Other\\HowlOfTerror\\HowlCaster.mdl`。

### 食人魔啃食

- 两形态共享。
- Boss 击杀已注册玩家英雄后触发。
- 持续时间为 `2.6 - N * 0.2` 秒。
- 必须先暂停/硬直，再播放动画编号 7；期间无敌。
- 特效：`Abilities\\Spells\\Undead\\DeathPact\\DeathPactTarget.mdl`。
- 完整结束后恢复生命与魔法至 100%，并重置技能冷却，然后解除暂停与无敌。
