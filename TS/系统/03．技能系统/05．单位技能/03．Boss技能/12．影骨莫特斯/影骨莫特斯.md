# 第一章隐藏 Boss：死灵盗贼首领 - 影骨·莫特斯

> 当前状态：JASS 侧已制作，TS 侧待迁移/优化。当前版本作为第一章支线 / 隐藏 Boss 规划资料。

## 基础定位

- 章节定位：第一章支线 / 隐藏 Boss。
- 战斗主题：亡灵盗贼、背刺角度、骸骨召唤、视野压制、可交互宝箱。
- 场地要点：Boss 场地有 4 根高柱，后续 TS 迁移时可作为遮挡、视野、位移和宝箱刷新参照点。
- 弱点建议：光 / 火 / 钝器。若正式剧情已有设定，以剧情设定为准。
- 难度定位：第一章隐藏 Boss，装备掉落按 C 档 `3500-3900` 分控制。

## 核心机制

### 背刺角度

- 莫特斯的“背刺”不是 180 度背后判定，而是 90 度扇形判定。
- 玩家面向莫特斯时，背刺伤害减半。
- TS 迁移时建议封装为通用角度判定：攻击者、目标、判定角度、正面减免倍率。

### 骸骨重组

- 骷髅盗贼 / 骷髅射手首次死亡后不一定彻底消失。
- 阶段一和阶段二中，场上对应召唤物全部死亡后，延迟 3 秒在莫特斯附近重组为“骸骨战士”。
- 骸骨战士生命值为原召唤物基准生命的 150%，需要再次击杀才彻底死亡。
- 阶段三中，骷髅死亡不再重组。

### 视野压制

- 幽影爆发期间，所有玩家视野大幅降低。
- 后续落地应明确使用项目已有视野修改 API 或封装一个 Boss 战局部视野压制组件，结束后必须恢复。

## 阶段 1：盗贼诡计（100%-70%）

### 主动技能 1：阴影穿梭

- 触发：每 8 秒一次。
- 技能类型：位移 / 强化普攻 / 生存。
- 时间线：
  - 0.00 秒：莫特斯身体逐渐透明，播放消失预警。
  - 0.50 秒：进入短暂无敌。
  - 1.00 秒：出现在随机玩家附近 300 码内，不强制背后位置。
  - 出现后：下一次普通攻击获得“背刺”强化。
- 背刺效果：下一次普通攻击造成高额暴击伤害，建议为 `攻击力 × X%` 的攻击效果伤害。
- 反制：若目标玩家正面朝向莫特斯，则此次背刺最终伤害降低 50%。
- 预警表现：Boss 身体透明、原地残影、目标附近短暂暗影闪烁。
- 迁移备注：适合复用“强化下一次普攻”底层，并指定只认纯普攻。

### 主动技能 2：骸骨召唤

- 冷却：20 秒。
- 技能类型：召唤 / 经济惩罚 / 持续压力。
- 时间线：
  - 开始吟唱后，每 1 秒在预警点召唤 1 个骷髅盗贼。
  - 根据吟唱实际完成段数召唤 2-4 个骷髅盗贼。
- 骷髅生命：较低，约玩家普通攻击 3-4 次可击杀。
- 骷髅偷窃：命中玩家时，减少玩家当前金币 `2% + 100`。
- 贫血金币惩罚：若玩家当前金币少于该英雄最大生命值，则骷髅偷窃命中额外造成伤害，建议为 `攻击力 × X% + 目标最大生命值 × Y%`。
- 掉落：莫特斯召唤物死亡后掉落短时间护甲 / 魔抗符咒。
- 重组：全部骷髅死亡后 3 秒重组为骸骨战士。
- 预警表现：地面暗色召唤阵，莫特斯念咒，每秒出现一个召唤点。

### 主动技能 3：暗影禁锢

- 触发：每 8-16 秒自动顺发。
- 技能类型：控制 / 可交互机制单位。
- 目标：随机玩家脚下。
- 时间线：
  - 0.00 秒：目标脚下生成黑色法阵预警。
  - 0.90 秒：法阵生效。
- 生效范围：320 码。
- 命中效果：禁锢玩家 4 秒，期间无法移动 / 施法。
- 交互：禁锢法阵可被队友攻击摧毁；摧毁后被禁锢玩家的剩余禁锢时间缩短到 1 秒。
- 视觉：黑色能量旋涡。
- 迁移备注：适合做成“可攻击控制法阵”机制模板，参数包括预警时间、范围、控制类型、可摧毁生命值和摧毁后剩余控制时间。

### 主动技能 4：幽影爆发

- 冷却：40 秒。
- 技能类型：大范围压制 / 召唤 / 形态变化。
- 持续时间：20 秒。
- 效果：
  - 所有玩家视野大幅减少。
  - 莫特斯进入幽灵形态。
  - 幽灵形态期间受到的物理伤害降低 40%，受到的魔法伤害提高 40%。
  - 召唤大量骷髅盗贼和骷髅射手攻击玩家，优先集火攻击力最高的玩家。
  - 此期间莫特斯所有召唤物造成暗属性魔法伤害。
  - 每死亡 3 个召唤物会重组为 1 个骸骨战士。
- 结束：持续时间结束后，幽影召唤物受到遏制，损失大量生命值。
- 预警提示：“莫特斯让幽影吞没了战场！”

## 阶段 2：亡灵仆从（70%-40%）

### 主动技能 5：盗贼的遗产

- 冷却：40 秒。
- 技能类型：场地交互 / 奖惩 / 召唤联动。
- 效果：场地出现 4 个永久宝箱。
- 开启方式：玩家需要持续引导 3 秒。
- 干扰：玩家引导宝箱期间，所有骷髅召唤物集火攻击该玩家。
- Boss 增益：每开启 1 个宝箱，莫特斯永久提高 3% 基础攻击力。
- 宝箱结果：
  - 30%：骷髅死亡符咒或照明火把。
  - 25%：随机数量金币。
  - 25%：随机装备，范围 D+ 到 B-，难度越高高等级概率越高。
  - 10%：帝国货币 × 1。
  - 10%：陷阱，玩家损失大量生命值但不致死，随后眩晕 1.5 秒。
- 迁移备注：宝箱最好做成机制单位或可破坏物统一注册，开启结果走可配置权重表。

## 阶段 3：阴影主宰（40%-0%）

- 骷髅死亡不再重组。
- 幽影爆发使用频率提高，具体冷却建议缩短为阶段一的 60%-70%。
- 莫特斯攻击力提高 30%。
- 这一阶段应保留阴影穿梭和暗影禁锢，让玩家持续处理背刺和控制压力。

## TS 迁移优先复用点

- 强化下一次普攻：阴影穿梭后的背刺只认纯普攻，排除技能攻击和技能伤害。
- 角度判定：90 度背刺、玩家正面朝向减伤，都适合做成通用角度工具。
- 可攻击法阵：暗影禁锢需要“预警 -> 生效 -> 可攻击缩短控制”的机制单位模板。
- 召唤物重组：骸骨召唤和幽影爆发都需要“死亡计数 / 延迟重组 / 阶段禁用”的召唤物组件。
- 视野压制：幽影爆发需要统一记录旧视野并在结束、Boss 死亡、战斗重置时恢复。
- 宝箱权重：盗贼的遗产适合抽成 Boss 战内可交互宝箱组件。

## 测试重点

- 阴影穿梭是否正确透明、无敌、瞬移，并只强化下一次纯普攻。
- 背刺 90 度角度、玩家正面减伤是否准确。
- 骸骨召唤是否按吟唱段数召唤 2-4 个骷髅，偷金币和额外伤害是否正确。
- 阶段一 / 二中骷髅是否会重组，阶段三是否停止重组。
- 暗影禁锢是否有 0.9 秒预警，法阵被摧毁后剩余控制是否缩短到 1 秒。
- 幽影爆发结束、Boss 死亡、战斗重置时，视野和幽灵形态是否全部清理。
- 盗贼的遗产宝箱是否能引导、被骷髅集火、按权重开奖，并给 Boss 累加永久攻击力。
