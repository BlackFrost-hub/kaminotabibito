# Boss 技能分类

Boss 技能按剧情定位分为三类，目录分类优先于强度、模型和技能风格：

- `01．主线Boss`：章节主线流程中必须击败或处理的 Boss。
- `02．挑战与隐藏Boss`：可选挑战、隐藏支线、祖地守卫等非主线必经 Boss。
- `03．异界Boss`：来自其他世界或异界挑战体系的 Boss。

## 目录规则

- 新 Boss 放入对应分类目录，再在该分类的 `index.ts` 中导出。
- Boss 自身仍按 `00．配置.ts`、运行时上下文、数值与表现配置、单技能文件、`index.ts` 组织。
- 多个 Boss 共用的播放或机制工具放 `00．公共`，不要复制到各分类目录。
- Boss 改变剧情定位时，技能目录与 `05．Buff系统/03．Buff表/01．Boss` 下的专属 Buff 必须同步迁移。
- 分类只表示剧情来源；AI、战斗启动、死亡结算和奖励仍在各自系统中登记。

根 `index.ts` 只汇总公共模块和三个分类；具体 Boss 由分类 `index.ts` 汇总。
