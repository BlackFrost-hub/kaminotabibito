# 点名技能模板

## 选型

| 需求 | 使用入口 |
| --- | --- |
| 同一时刻点名一名或多名目标，统一延迟后结算 | `开始点名预警结算模板` |
| 多个落点和触发时间在技能开始时已经全部确定 | `创建多波延迟AOE` |
| 每轮开始时重新读取有效目标，再锁定坐标并延迟结算 | `开始分批点名落点模板` |

不要为具体 Boss 复制“取目标、延迟、提示圈、清理”计时器。调用方只保留目标来源、伤害、特效和阶段限制。

## 分批点名示例

```ts
开始分批点名落点模板({
  名称: '连续追点',
  清理: context.清理,
  轮数: 3,
  轮次间隔秒: 0.5,
  预警秒: 0.8,
  取目标列表: function 取本轮目标(this: void): any[] {
    return 获取当前有效敌对英雄();
  },
  提示圈: { 类型: '敌方圆形', 半径: 240, 来源单位: boss },
  on结算: function 结算本轮(this: void, 结果): void {
    结算落点(结果.锁定X, 结果.锁定Y);
  },
});
```

默认按轮次序号轮换目标。需要固定优先级时传 `选择目标`；需要结算时追随目标当前位置时传 `锁定坐标: false`。
