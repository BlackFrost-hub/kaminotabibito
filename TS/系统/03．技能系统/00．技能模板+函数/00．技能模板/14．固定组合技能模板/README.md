# 固定组合技能模板

用于必须严格按既定时间轴执行、期间不能被普通随机技能插入的组合机制。典型场景包括双灵卫的“践踏 -> 缓冲 -> 祷潮”、安兹的时间停止结算顺序，以及夏提雅的延迟女武神复制。

## 约束

- `最大持续毫秒` 必须覆盖整条阶段链；模板会在这段时间预约互斥组，并在完成或中断时提前释放。
- 同一个执行器同一时间只运行一条组合；多个单位需要共享预约时，传入同一个 `技能互斥锁`。
- 组合需要参与更高层技能抢占时，传入共享的 `可抢占独占状态管理器`。
- 战斗清理时会中断当前阶段链，并释放互斥与独占状态。

```ts
const 执行器 = 创建固定组合技能执行器<双灵卫上下文>({
  名称: "双灵卫固定组合",
  清理: context.清理,
  互斥锁: context.共享技能锁,
  互斥组: "双灵卫主要技能",
});

执行器.开始({
  key: "断誓践踏接失名祷潮",
  单位: context.赤誓灵卫,
  上下文: context,
  最大持续毫秒: 5000,
  阶段列表: [
    创建立即执行阶段(() => 释放断誓践踏(context)),
    创建延迟阶段(2000, "组合缓冲"),
    创建立即执行阶段(() => 释放失名祷潮(context)),
  ],
});
```
