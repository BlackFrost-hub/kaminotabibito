# 战斗技能调度模板

用于代码驱动的 Boss、护卫和双 Boss 技能轮转。事件触发技能、被动伤害修正和单次剧情演出不应强行接入本模板。

## 适用能力

- 阶段、血量和外部状态门槛
- 首次延迟、冷却、忙碌时间
- 优先级与同优先级权重随机
- 目标选择与施法距离等目标验证
- Boss 与护卫共享大技能互斥锁
- 低优先级常驻机制被正常技能无阻塞抢占
- 技能成功后的指定协同行动
- 通过机制清理篮子停止周期驱动并释放状态

## 最小用法

```ts
const 调度器 = 创建战斗技能调度器({
  名称: "示例Boss技能调度",
  清理: context.清理,
  间隔毫秒: 250,
  取上下文列表: () => [context],
  取上下文键: ctx => 取单位ID(ctx.Boss单位),
  可调度: ctx => 单位有效(ctx.Boss单位),
  技能列表: [{
    key: "示例大技能",
    首次延迟毫秒: 5000,
    冷却毫秒: 20000,
    忙碌毫秒: 3000,
    互斥组: "主要走位技能",
    互斥持续毫秒: 3500,
    优先级: 10,
    选择目标: ctx => 选择技能目标(ctx),
    目标有效: (_ctx, target) => 单位有效(target),
    执行: (ctx, target) => {
      释放示例技能(ctx, target);
    },
  }],
});
```

Boss 与护卫需要协调时，分别创建调度器并传入同一个 `技能互斥锁`。关键组合通过 `成功后` 明确触发配合，不要依赖两套随机 AI 碰巧同时选中对应技能。

## 可抢占常驻机制

安兹与雅儿贝德的“守护者之职责”属于低优先级常驻机制：它只能在双方技能空档开始，但不能反过来阻塞任何正常技能。两套调度器应共享同一个 `可抢占独占状态管理器`。

```ts
const 共享独占状态 = 创建可抢占独占状态管理器({
  名称: "安兹与雅儿贝德共享状态",
  清理: context.清理,
});

const 雅儿贝德调度器 = 创建战斗技能调度器({
  名称: "雅儿贝德技能调度",
  独占状态管理器: 共享独占状态,
  默认独占优先级: 10,
  // 其余参数省略
  技能列表: [{
    key: "守护者之职责",
    冷却毫秒: 18000,
    独占优先级: 1,
    独占持续毫秒: 7000,
    独占状态可被抢占: true,
    独占状态结束: (_ctx, _target, event) => {
      if (event.原因 !== "完成") 静默结束守护者职责(context);
    },
    执行: () => 启动守护者职责(context),
  }],
});
```

安兹与雅儿贝德的普通技能都使用默认优先级 `10`。任意普通技能开始时，会先结束优先级 `1` 的职责连接，再正常施法；职责不会在施法结束后自行恢复。
