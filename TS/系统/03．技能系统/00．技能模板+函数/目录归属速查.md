# 技能模板、技能函数、通用函数归属速查

这个文件用于判断新增复用能力应该放在哪里，避免把流程模板、具体行为、小工具和机制状态混在一起。

## 00．技能模板

放“一个技能怎么组织”的流程模板。

适合放这里：

- 前摇 -> 提示圈 -> 执行 -> 收尾。
- 点名 -> 预警 -> 延迟结算。
- 蓄力 -> 多段落点 -> 每段结算。
- 跳跃 -> 落地 -> 范围伤害。
- 路径铺设 -> 持续区域 -> 到期清理。
- 阶段变体的同一技能编排。

不放这里：

- 具体怎么造成伤害。
- 具体怎么击退、跳跃、发射弹幕。
- 具体 Buff、Debuff、控制、护盾实现。
- 某个 Boss 专属台词、数值、剧情语义。

判断标准：如果它主要回答“这个技能由哪些阶段组成”，放技能模板。

## 01．技能函数

放“技能能做什么”的具体行为能力。

适合放这里：

- 弹幕、投射物、跳链。
- 冲锋、击退、跳跃、击飞、持续顶飞。
- 圆形、矩形、扇形、胶囊形区域判定。
- 持续区域、周期范围效果、落点打击。
- 召唤物创建、召唤物行为入口。
- 控制、护盾、反击、扩散伤害。
- 强化普攻、纯普攻触发、同目标普攻计数。
- 光环、魔法吸收、无视控制输入。

不放这里：

- 完整装备业务。
- 完整 Boss 技能业务。
- 纯坐标计算、纯单位筛选、纯表现创建这种小工具。
- 多技能共享的长期状态表。

判断标准：如果它主要回答“这个技能动作本身怎么执行”，放技能函数。

## 02．通用函数

放跨技能高频复用的小工具。

适合放这里：

- 单位动画、动画守护、站桩。
- 单位与范围筛选。
- 坐标、角度、矩形平移、区域辅助计算。
- 提示特效、技能提示圈工厂。
- 闪电效果代码、通用特效旋转。
- 控制与 Buff 的轻量入口。
- 调试输出、单位组工具、无敌帧。
- 技能壳名字/Tip/UberTip 动态修改。

不放这里：

- 完整技能流程。
- 完整技能行为模块。
- 需要生命周期和状态表的复杂机制。

判断标准：如果它主要回答“我需要一个很小的公共工具”，放通用函数。

## 04．机制组件

放有状态、有生命周期、跨多个技能共享的复杂机制。

适合放这里：

- 阶段上下文。
- 单位状态表。
- 机制单位生命周期。
- 召唤物组状态管理。
- 战斗区域、安全区、宫格区域。
- 点名预警执行器。
- 反击窗口、视野压制、非伤害生命移除。
- 装备通用机制、战斗状态触发器。

不放这里：

- 单次技能动作。
- 纯工具函数。
- 具体 Boss 的完整技能业务。

判断标准：如果它需要“启动、运行、清理、被多个技能共享状态”，放机制组件。

## 当前新增模板

- `00．技能模板/04．主动技能流程模板/01．前摇预警执行模板.ts`
  - 用于 Boss、英雄、小怪等主动技能的转向、前摇、提示圈和执行回调。
- `00．技能模板/05．点名技能模板/01．点名预警结算模板.ts`
  - 用于一名或多名目标的点名、预警和延迟结算。

这两个模板只做流程编排；具体伤害、弹幕、召唤、分摊、Buff 仍然由调用方或技能函数处理。
