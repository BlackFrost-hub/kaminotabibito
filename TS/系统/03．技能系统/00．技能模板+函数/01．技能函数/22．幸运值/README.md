# 幸运值系统说明

本目录提供玩家幸运值与概率修正入口。幸运值使用 `YDUser` 按玩家存储，属性名为 `幸运值`。

## 数值语义

- `0`：不修改概率。
- `0.3`：把原概率提高 30%，例如 `0.2` 变成 `0.26`。
- `-0.3`：把原概率降低 30%，例如 `0.2` 变成 `0.14`。
- `5`：把原概率提高 500%，例如 `0.1` 变成 `0.6`。
- 修正后的概率会限制在 `0..1`。

## 当前入口

- `取玩家幸运值(玩家)`：读取玩家幸运值。
- `设置玩家幸运值(玩家, 幸运值)`：覆盖玩家幸运值。
- `增加玩家幸运值(玩家, 增量)`：累加玩家幸运值。
- `按玩家幸运修正概率(原始概率, 玩家)`：返回玩家幸运修正后的概率。
- `按单位所属玩家幸运修正概率(原始概率, 单位)`：按单位所属玩家修正概率。
- `玩家幸运概率通过(原始概率, 玩家)`：修正概率后直接做随机判定。
- `单位幸运概率通过(原始概率, 单位)`：按单位所属玩家修正概率后随机判定。
- `装备触发概率修正(原始概率, 触发单位)`：装备系统使用的最终概率计算入口。
- `装备触发概率通过(原始概率, 触发单位)`：装备系统使用的概率判定入口。

## 装备概率约定

装备触发概率统一使用 `装备触发概率通过` 或 `装备触发概率修正`，不要在装备文件里直接使用 `GetRandomReal`、`随机实数` 或自己重复写幸运值倍率。

攻击效果配置表的 `概率`、`概率计算`、`伤害概率`、`治疗概率` 已由攻击效果核心统一接入幸运值。配置式装备只填写原始概率，不要二次修正。

## 未来概率系统入口

后续暴击率、命中率、闪避率如果迁移进 TS，优先在本目录或本目录下的子模块新增统一入口，不要散落到单装备文件。

- 暴击率：建议提供 `暴击概率修正`、`暴击概率通过`，统一接入玩家属性里的暴击率与幸运值。
- 命中率：建议提供 `命中概率修正`、`命中概率通过`，统一接入玩家属性里的命中率与幸运值。
- 闪避率：建议提供 `闪避概率修正`、`闪避概率通过`，统一接入玩家属性里的闪避率与幸运值。
- 暴击伤害：不是概率判定，但如果迁移到 TS，也应提供统一读取与修正入口，避免装备各自读取玩家属性。

新增这些入口后，装备和战斗系统只调用统一函数；底层玩家属性读取、幸运值倍率、概率限制都留在本目录处理。
