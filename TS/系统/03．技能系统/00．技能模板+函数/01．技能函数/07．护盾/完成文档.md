# 护盾系统 - 完成文档

## 概述

护盾系统已实现，支持：
- 3种护盾类型：通用/物理/魔法
- 优先级排序：专用护盾 > 通用护盾
- 同类型内部：抵挡优先级 > 最早到期优先
- 头顶护盾条显示
- 开始/破碎/到期/结束回调
- 伤害吸收接入

## 优先级规则

### 类型优先级

| 类型 | 优先级 |
|------|--------|
| 物理护盾 | 100 |
| 魔法护盾 | 100 |
| 通用护盾 | 50 |

### 抵挡优先级

- 默认值：50
- 破碎有收益的护盾：设为更高（如 100）
- 存在时有增益的护盾：设为更低（如 10）

### 同类型内部排序

1. 抵挡优先级 降序
2. 剩余时间 升序（最早到期优先）
3. 永久护盾排在最后

## 伤害吸收流程

1. 伤害计算完成（calculateDamage 返回）
2. 调用 `处理护盾吸收(目标, 伤害值, 是物理, 是魔法, 攻击者)`
3. 按优先级依次扣减护盾
4. 护盾破碎时触发破碎回调
5. 返回剩余伤害
6. 调用 `YDWESetEventDamage(剩余伤害)`

## 护盾条表现

- 复用 `e011` 进度条单位
- 通过 `SetUnitAnimationByIndex` 切动画帧（0-99对应0%-100%）
- 颜色三态闪色反馈：
  - 物理伤害：棕色 (180,100,30)
  - 魔法伤害：深蓝 (30,30,180)
  - 其他/通用伤害：灰白 (200,200,200)
- 闪色持续 0.3 秒后恢复默认黄色
- 护盾耗尽或单位死亡自动删除

## 注意事项

1. **`@noSelfInFile`**：所有文件都添加了，避免 TSTL self 参数问题
2. **`this: void`**：所有回调类型都声明了 `this: void`
3. **中心计时器**：使用 `onTick10ms` 推进生命周期
4. **单位死亡**：通过 `registerDeathListener` 清理护盾
5. **globalThis 暴露**：`开始护盾`、`移除护盾`、`处理护盾吸收` 已暴露到 globalThis

## 接入伤害系统

需要在 `04．伤害系统/00．伤害计算/04．主计算流程.ts` 的 `onDamageEvent` 中接入：

```typescript
// 在 YDWESetEventDamage 之前调用护盾吸收
const 护盾吸收 = (globalThis as any).处理护盾吸收;
if (typeof 护盾吸收 === "function") {
  const 剩余伤害 = 护盾吸收(target, result.finalDamage, isPhysDmg, isMagicDmg, attacker);
  result.finalDamage = 剩余伤害;
}
```

## 验收测试

1. 给单位加 300 通用护盾，受 100 物理伤害后护盾剩 200，护盾条闪棕色
2. 同时有魔法护盾 300 + 通用护盾 500，受 400 魔法伤害后魔法护盾清空、通用护盾剩 400，护盾条闪深蓝
3. 给单位加 300 通用护盾，受 100 真实伤害后护盾剩 200（通用护盾吸收所有伤害）
4. 两个魔法护盾按"抵挡优先级降序 > 最早到期优先"扣减
5. "破碎有收益"的护盾（抵挡优先级高）优先被打掉
6. 护盾到时自动消失，触发到期回调
7. 单位死亡护盾和护盾条都清理，触发结束回调（原因=单位死亡）
8. 破碎回调只触发一次
9. 护盾条按动画帧显示进度，不缩放
