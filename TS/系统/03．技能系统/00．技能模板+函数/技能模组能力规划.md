# 技能模组能力规划

本文档用于整理 `TS/系统/03．技能系统/00．技能模板+函数` 当前能力覆盖情况，以及后续建议补齐的模块。

目标不是一次性做完，而是给后续 AI / 开发者一个统一的扩展顺序，避免重复造轮子或优先级失衡。

## 当前已有

当前已经具备的核心模块：

- 位移类：冲锋、击退、跳跃、牵引
- 区域类：持续区域、动态范围、扇形、动态扇形、矩形、条形、胶囊形
- 表现类：提示特效、前摇提示工厂、进度条特效、残影表现、单位绑定闪电、技能表现预设库
- 机制类：施法/蓄力/充能、护盾、扩散伤害、落点打击、纯跳链
- 模板类：多阶段技能编排、前摇/引导/生效帧/后摇/收尾、路径技能模板、目标选择模板
- 通用类：控制与 Buff、单位与范围、动画等待、调试输出、闪烁、无敌帧、单位组工具

当前结构已经不只是“动作模块雏形”，而是已经有一批可直接复用的技能零件与组合模板。

当前仍然相对偏薄的部分主要是：

- `01．弹幕` 内的 TS 原生弹道框架
- `01．弹幕` 内的可插拔轨迹层（贝塞尔、圆弧、追踪插值）
- 命中规则与弹幕实例生命周期的联动
- 更完整的组合示例模板

已经完成并已收口到现有能力中的方向：

- 真实形状区域判定
- 技能阶段编排模板
- 持续施法 / 引导系统
- 落雷 / 延迟落点打击模板
- 多段地面路径技能模板
- 技能表现预设库
- 技能目标选择模板（基础版）
- 命中规则模板（基础版）

已经部分完成、但暂不建议从规划中完全移除的方向：

- 连锁 / 跳链执行器
  当前只完成了“不依赖飞行物”的纯跳链。
  依赖 TS 原生弹道 / 弹幕系统的“飞出去后再弹射”“弹体命中后再跳链”等变体仍未完成。
- 位移/弹道命中规则模板
  当前只完成了“不依赖弹幕系统”的基础命中状态。
  弹体穿透、回程再次命中、命中后继续/停止与弹幕实例生命周期联动，仍建议等 TS 原生弹道框架落地后再接。

## 高优先级

### 1. `01．弹幕` 内的弹道轨迹层

建议目录：

- `01．技能函数/01．弹幕/01．轨迹`

建议先补：

- 二阶贝塞尔轨迹
- 三阶贝塞尔轨迹
- 圆弧轨迹
- 追踪插值轨迹
- 路径采样接口：按进度返回 `x/y/z`

为什么优先级高：

- 当前跳跃只有“水平直线 + 垂直抛物线高度”，没有 XY 平面的曲线轨迹层。
- 很多技能需要弧线突进、回旋刀、绕点飞行、蛇形飞行、回收型武器。
- 二阶贝塞尔不建议单独做成孤立系统，更适合作为 `01．弹幕` 内 TS 原生弹道框架的首个轨迹实现。
- 这样能直接复用弹道层已有的生命周期、命中、结束、回调管理，避免再造一套独立飞行逻辑。

### 2. `01．弹幕` 内的 TS 原生弹道框架

建议目录：

- `01．技能函数/01．弹幕`

建议先补：

- 直线弹道
- 轨迹可插拔接口
- 追踪弹道
- 曲线路径接入（优先接二阶贝塞尔）
- 延迟发射
- 最大转向角 / 最大追踪时间
- 生命周期 / 穿透 / 回收 / 超时管理
- 命中、失效、超时回调

为什么优先级高：

- 当前 `01．弹幕/弹幕系统.ts` 更多是对旧 JASS DMXT 的封装，不是 TS 原生、可编排的弹道层。
- 如果直接把 JASS 弹幕系统的核心运行框架迁到 TS，再把轨迹层挂进去，会比“先做孤立贝塞尔、再做弹道”更省代码。
- 简单直线够用，但复杂追踪、回旋、回收、锁敌切换仍然不够顺手。
- 这一层完成后，贝塞尔、圆弧、回收型武器都能作为 `01．弹幕` 同一框架下的轨迹策略复用。

## 中优先级

### 3. 位移/弹道命中规则模板（基础版已完成，弹幕联动待补）

建议目录：

- `02．通用函数/10．命中规则`

已落地：

- 首个命中
- 每单位只命中一次
- 允许重复命中
- 每单位最大命中次数
- 最大总命中次数
- 命中后停止 / 命中后继续
- 目标筛选函数

后续等 `01．弹幕` TS 原生弹道框架落地后再补：

- 穿透上限与弹体生命周期联动
- 回程再次命中规则
- 弹体命中后继续 / 停止的运行时策略

为什么是中优先级：

- 这层不是新的位移系统，而是把“命中后怎么处理”抽成统一模板。
- 当前基础版已经可给冲锋、跳跃、区域、落点打击等“不依赖弹幕实例”的模块复用。
- 弹幕侧还需要等 TS 原生弹道框架稳定后，把“命中后怎么处理”和弹体生命周期接起来。
- 后续重点不是再造命中状态，而是把这套状态安装进弹幕、回旋、回程、穿透等运行流。

### 4. 连锁 / 跳链扩展模板

建议目录：

- `01．技能函数/10．跳链`
- 或后续与 `01．技能函数/01．弹幕` 组合

建议后续补：

- 弹体命中后再跳链
- 飞行后弹射
- 回旋 / 回收途中再跳链
- 与 TS 原生弹道框架组合的跳链变体

为什么是中优先级：

- 当前 `纯跳链系统.ts` 已经足够支撑闪电链、治疗波这类“瞬时连线”技能。
- 但依赖弹体飞行过程的链式技能，仍要等 `01．弹幕` 内的 TS 原生弹道框架先成熟。
- 所以这条不是“完全未做”，而是“基础版已完成，弹道联动版待补”。

## 低优先级

### 5. 回旋 / 回收型武器模板

建议目录：

- `01．技能函数/13．回旋武器`

建议先补：

- 去程
- 回程
- 返回主人
- 去回程不同命中规则

为什么是低优先级：

- 价值很高，但更适合放在 TS 原生弹道框架与轨迹层落地后再做。
- 尤其是去程 / 回程 / 回收 / 回旋命中规则，会明显依赖弹幕系统和贝塞尔等轨迹能力先成熟。
- 现在先做它，成本会高，沉淀也不稳定。

### 6. 组合型完整示例模板

建议目录：

- `00．技能模板/04．组合示例`

建议先补：

- “前摇 + 冲锋 + 扇形伤害”
- “读条 + 落雷 + 区域持续”
- “弹道 + 命中扩散 + 连锁”

为什么是低优先级：

- 主要用于教学、演示和约束 AI 的拼装方式。
- 很有价值，但应该在基础模块先稳定后再补。

## 建议实现顺序

推荐按下面顺序推进：

1. TS 原生弹道 / 追踪弹道
2. 通用曲线路径层
3. 命中规则与弹幕实例生命周期联动
4. 连锁 / 跳链的弹道联动扩展
5. 回旋 / 回收型武器模板
6. 其余低优先级组合示例

## 一句话总结

当前技能模组已经具备较完整的基础动作模块、形状判定、前摇引导模板、跳链与地面路径模板，但还缺：

- 更真实的玩法判定
- 更强的轨迹表达能力
- 更完整的 `01．弹幕` 内 TS 原生弹道层
- 命中规则与弹幕实例生命周期的联动

后续优先补“基础层”，再补“花样层”，这样复用价值最高。
