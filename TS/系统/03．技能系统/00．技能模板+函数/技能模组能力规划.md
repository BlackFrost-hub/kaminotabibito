# 技能模组能力规划

本文档用于整理 `TS/系统/03．技能系统/00．技能模板+函数` 当前能力覆盖情况，以及后续建议补齐的模块。

目标不是一次性做完，而是给后续 AI / 开发者一个统一的扩展顺序，避免重复造轮子或优先级失衡。

## 当前已有

当前已经具备的核心模块：

- 位移类：冲锋、击退、跳跃、牵引
- 区域类：持续区域、动态范围、扇形、动态扇形、矩形、条形、胶囊形
- 表现类：提示特效、前摇提示工厂、进度条特效、残影表现、单位绑定闪电、技能表现预设库
- 机制类：施法/蓄力/充能、护盾、扩散伤害、落点打击、纯跳链
- 弹幕类：旧 JASS 弹幕桥接、TS 原生弹幕、可插拔轨迹、弹道跳链、回旋/回收弹幕、弹幕组合示例
- 模板类：多阶段技能编排、前摇/引导/生效帧/后摇/收尾、路径技能模板、目标选择模板
- 通用类：控制与 Buff、单位与范围、动画等待、调试输出、闪烁、无敌帧、单位组工具

当前结构已经不只是“动作模块雏形”，而是已经有一批可直接复用的技能零件与组合模板。

弹幕部分已经完成本轮收口：

- `01．弹幕/弹幕系统.ts`：保留旧 JASS DMXT 桥接，兼容历史调用。
- `01．弹幕/01．TS原生弹幕`：新增 TS 原生弹幕核心，包含实例注册、中心计时器驱动、生命周期、命中、阻挡血量、STES 传参事件。
- `01．弹幕/01．TS原生弹幕/01．轨迹`：新增二阶贝塞尔、三阶贝塞尔、圆弧、追踪插值与路径采样接口。
- `01．弹幕/02．弹道跳链`：新增“飞出去命中后再跳链”的弹道跳链模板，区别于已有纯跳链。
- `01．弹幕/03．回旋回收`：新增去程/回程可分别配置命中规则和伤害的回旋回收弹幕模板。
- `01．弹幕/04．组合示例`：新增弹道命中后触发弹道跳链的组合模板。

已经完成并已收口到现有能力中的方向：

- 真实形状区域判定
- 技能阶段编排模板
- 持续施法 / 引导系统
- 落雷 / 延迟落点打击模板
- 多段地面路径技能模板
- 技能表现预设库
- 技能目标选择模板（基础版）
- 命中规则模板（基础版）

## 后续建议

当前弹幕规划里的基础层已经落地。后续更适合按具体技能需求继续扩展，而不是继续在规划里空列大项：

- 蛇形 / 绕点 / 多段路径等特殊轨迹。
- 阻挡弹幕的伤害事件接入点，例如某个技能对弹幕造成 200 点阻挡伤害。
- 弹幕与护盾、Buff、技能表现预设库的更高层组合。
- 更具体的聊天指令测试文件，按需要逐个补。

## 组合阶段缺口

当前技能 combo 的基础零件已经基本齐全，可以开始按具体需求拼技能组合。后续主要缺的不是新的底层动作模块，而是让组合更快、更稳、更少胶水代码的上层封装：

- 成品技能组合库：沉淀常见套路，例如前摇提示冲锋斩、跳跃砸地、蓄力落雷、路径燃烧、弹幕命中跳链。
- 统一配置结构：统一伤害、范围、提示、前摇、命中特效、音效、冷却消耗等参数风格，减少每个技能重复手写转换。
- 测试 / 调参工具：统一聊天命令注册、快速生成敌人、快速显示范围与命中结果，提升技能手感调试效率。
- 弹幕高级玩法：反弹、分裂、穿透次数、拦截规则、被技能阻挡后的标准回调；复杂弹幕需要，普通技能可暂缓。
- 表现组合预设：把提示特效、命中特效、音效、镜头震动、残影等打包成风格包，减少表现层重复配置。

这些不建议一次性空做。更合理的方式是先制作具体技能，遇到重复胶水代码后再沉淀成组合库或配置层。

## 一句话总结

当前技能模组已经具备较完整的基础动作模块、形状判定、前摇引导模板、跳链与地面路径模板，但还缺：

- 成品技能组合库与统一配置结构
- 测试 / 调参工具
- 少量复杂弹幕玩法与表现组合预设

弹幕基础层已经可作为后续“花样技能”的复用底座。
