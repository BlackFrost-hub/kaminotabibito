# Boss血条弱点韧性

## 对外接口

`08．对外接口.ts` 当前提供：

- `设置Boss血条头像(Boss单位, 头像贴图路径)`：修改活动 Boss 的血条头像；传入空字符串恢复单位物编 `Art` 默认头像。Boss 运行状态尚未建立或已经结束时返回 `false`。

```typescript
  "系统.03．技能系统.06．AI自动使用技能.03．Boss战启动桥接.03．Boss血条弱点韧性.08．对外接口",

  设置Boss血条头像: (this: void, Boss单位: any, 头像贴图路径: string) => boolean;

设置Boss血条头像(Boss单位, "ReplaceableTextures\\CommandButtons\\BTNHeroPaladin.blp");
```

## 多 Boss 血条

- 同时存在多个活动 Boss 时，血条按注册顺序从上到下占用连续槽位。
- Boss 结束或死亡后释放槽位，剩余血条、头像、护盾与弱点 UI 自动向上压紧，不保留中间空位。
- 当前槽位垂直间距由 `Boss血条UI常量.槽位垂直间距` 控制。

## 护卫 mini 血条

- 护卫单位配置显式填写 `显示护卫血条: true` 后，护卫创建时自动注册 mini 血条。
- 护卫配置必须填写 `护卫血条归属类型: "共享" | "独立"`，不支持第三种归属类型。
- `独立`护卫紧跟各自主 Boss 排列，每个 Boss 最多显示两个；护卫行按 mini 比例占用紧凑槽位，不按完整主血条高度拉开下一组。
- `共享`护卫由当前 Boss 组共用，最多显示两个，并统一排在所有主 Boss 与独立护卫组之后。
- 一个护卫固定占左侧 40%；两个护卫分别占左侧 40% 与右侧 40%，中间保留 20% 空隙。
- 任一护卫消失后，同组右侧护卫自动补到左槽；Boss 或护卫组消失后，其余主条与护卫行自动向上压紧。
- mini 血条保留头像、生命、护盾、弱点和韧性状态；没有完整机制配置时只创建头像、生命条与血量文本。

## 机制整组创建

- 护盾、弱点、韧性视为绑定整组。
- 仅当目标同时具有正数初始护盾和至少一个弱点时，才创建护盾/弱点相关 Frame 并注册伤害结算。
- 没有完整配置的主 Boss 或护卫仍会正常显示生命条和头像，不创建半套机制 UI。
