# 错误弱点保护机制

来源：`JASS/世界地图/boss血条和弱点韧性/111.j:695-1451`

当前 TS 迁移状态：**未迁移**

---

## JASS 原始逻辑

### 1. 触发条件

当物理攻击命中 Boss 时，先累计伤害到「器弱伤害累计」，达到「器弱伤害需求」阈值后，才检查攻击者的武器类型是否匹配 Boss 已配置的弱点。

如果攻击者的武器类型不匹配 Boss 的任何已配置弱点（例如 Boss 只有「剑弱」，玩家用「枪」攻击），则设置局部变量 `错误弱点 = true`。

触发位置（以剑为例）：
```jass
if (ATTACK_TYPE_MELEE == true) then
    if (Boss的"剑弱" == true) then
        // 正常弱点逻辑
    else
        call YDLocalSet(..., "错误弱点", true)  // ← 错误弱点
    endif
```

六种武器类型（剑/枪/斧/弓/短剑/杖）和六种属性类型（火/冰/雷/风/光/暗）都有对应的错误弱点判断。

### 2. 保护效果

当 `错误弱点 == true` 时，触发「保护护盾」：

```jass
if ("错误弱点" == true) then
    if (Boss的"保护护盾" == false) then
        Boss的"保护护盾" = true
        显示警告消息（TRIGSTR_9022）
        启动 6 秒计时器 → 解除"保护护盾"
    endif
endif
```

### 3. 保护期间的行为

当 `保护护盾 == true` 时，所有弱点命中逻辑被跳过：

```jass
if (Boss的"剑弱" == true) then
    if (Boss的"保护护盾" == false) then  // ← 这里拦截
        if (Boss的"剑弱暴露" == false) then
            // 暴露弱点
        endif
        if (Boss的"剑弱保护" == false and "剑弱暴露" == true) then
            // 弱点命中
        endif
    endif
endif
```

### 4. 保护时长

固定 6 秒，由计时器控制：
```jass
call TimerStart(ydl_timer, 6.00, false, function ...)
```

计时器到期后：
```jass
Boss的"保护护盾" = false
```

---

## 设计意图

防止玩家用非弱点武器「误触」弱点机制。如果 Boss 配置了「剑弱」，玩家用「枪」攻击，不应该触发任何弱点效果，反而应该进入 6 秒保护期，强制玩家等待后再用正确的武器攻击。

---

## TS 迁移建议

在 `06．Boss弱点伤害结算.ts` 的 `取命中弱点索引` 函数中：

1. 新增 `错误弱点` 状态字段（`05．Boss弱点运行状态.ts`）
2. 当武器类型不匹配任何已配置弱点时，设置 `错误弱点 = true`
3. 在 `onBoss弱点命中伤害修正` 中检查 `错误弱点`，触发 6 秒保护
4. 保护期间跳过所有弱点命中逻辑（包括属性弱点）

注意：JASS 中「保护护盾」同时影响武器弱点和属性弱点，不是只针对单个弱点。
