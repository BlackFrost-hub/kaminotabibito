# Boss血条弱点韧性

迁移 `JASS/世界地图/boss血条和弱点韧性` 的 Boss 战中 UI 与弱点韧性逻辑。

当前落地结构只接 Boss 战生命周期，注册顺序固定为：

1. 注册 Boss 血条 UI
2. 注册 Boss 弱点 UI
3. 注册 Boss 弱点伤害结算

后续迁移时，`血条.j` 优先落到 `03．Boss血条UI.ts`，`111.j` 的弱点图标与伤害结算分别落到 `04．Boss弱点UI.ts` 与 `06．Boss弱点伤害结算.ts`，不要按旧 JASS 的重复分支一比一搬运。

`03．Boss血条UI.ts` 已迁移 `血条.j` 的血条、头像、HP 文本、护盾条创建与 0.05 秒刷新逻辑；`04．Boss弱点UI.ts` 与 `06．Boss弱点伤害结算.ts` 已接入问号/弱点图标、护盾提示、弱点击中、破盾控制/独立伤害倍率、护盾恢复与反馈音效。表现文本、音效、YD 字段名、消息类型 fallback 与默认时长统一放在 `01．常量定义.ts`，单个 Boss 差异优先通过 `02．Boss弱点韧性配置表.ts` 承接。

后续实现 `06．Boss弱点伤害结算.ts` 时，属性伤害类型优先对齐 `TS/系统/09．表现系统/09．伤害数字模型/01．伤害数字核心.ts` 的 `伤害类型快照` 判定语义；武器弱点类型按旧 JASS 的弱点顺序与字段语义对齐。
