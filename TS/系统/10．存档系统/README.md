# 存档系统

## 范围

这里维护两类东西：

- 玩家本机配置存档
- 平台侧全局存档 / 埋点统计

不要把它们混成一类。

## 1. 玩家本机存档

对应目录：[01．本地存档](/c:/Users/Administrator/Desktop/syzl/TS/系统/10．存档系统/01．本地存档)

用途：

- 保存玩家自己的本地配置
- 例如按键、显示开关、QWERD 面板偏好
- 读写的是玩家机器上的 `.sav` 数据

特征：

- 只影响单个玩家
- 可以跨局保存
- 不适合拿来做全服统计

常用入口：

- `加载玩家本地存档`
- `保存玩家本地存档`
- `读取本地存档整数`
- `设置本地存档整数`
- `读取本地存档布尔`
- `设置本地存档布尔`

## 2. 平台全局存档

对应封装：

- `TS/平台扩展API动作.ts`
- `TS/平台扩展API取值.ts`

核心接口：

- `DzAPI_Map_Global_StoreString`
- `DzAPI_Map_Global_GetStoreString`

用途：

- 存平台侧的全局字符串
- 适合做全服共用状态、版本标记、活动开关、公共配置

不适合：

- 高频实时数据
- 每帧/每 tick 写入
- 依赖 `GetLocalPlayer()` 的本地分支写入

## 3. 平台统计埋点

核心接口：

- `DzAPI_Map_Statistics(玩家, eventKey, eventType, value)`

用途：

- 给平台后台上报统计数据
- 适合做英雄选择次数、Boss 击杀次数、玩法使用率、事件分布

推荐字段约定：

- `eventKey`：统计分类名，固定不变，例如 `hero_pick`
- `eventType`：统计子项，例如英雄内部 ID、玩法名、难度名
- `value`：次数或权重，一般传 `1`

示例：

```ts
DzAPI_Map_Statistics(Player(0), "hero_pick", "N00C", 1);
DzAPI_Map_Statistics(Player(0), "boss_kill", "地精祭祀", 1);
```

### 统计建议

- 英雄选择成功后上报一次
- Boss 击杀成功后上报一次
- 选人、禁用、模式确认这类节点也可以上报
- 不要在高频循环里重复打点

### 适合做的后台数据

- 某英雄被选了多少次
- 某 Boss 被击败了多少次
- 某模式的选择比例
- 某事件的触发量

## 4. 使用边界

### 可以放这里的

- 本地配置存档
- 平台全局字符串
- 平台统计埋点

### 不要放这里的

- 战斗中每秒刷新的临时状态
- 纯本地 UI 显示状态
- 只在 `GetLocalPlayer()` 内部变化的数据

### 原则

- 玩家配置，走本地存档
- 平台后台看数据，走统计埋点
- 全局公共状态，走全局存档

## 5. 后续建议

- 英雄选择统计统一使用 `hero_pick`
- Boss 击杀统计统一使用 `boss_kill`
- 版本信息统一用 `global_version`
- 活动开关统一用 `global_event_flag`

这样后面你要看后台数据时，口径会一致。
