# 玩家单位管理器（单位状态管理）

## 文件结构（常量 / 核心 / 功能）

| 文件 | 职责 |
|------|------|
| `00．常量.ts` | 移速阈值、特效模型与挂点、轮询间隔、`YDUserData` 表键常量 |
| `02．基础核心.ts` | 注册 `onTick10ms`、按间隔调用各功能 `sync`（后续在此追加调用即可） |
| `03．移速龙卷特效.ts` | 移速 > 阈值时挂/卸龙卷提示特效、`Map` 去重与离组清理 |
| `01．玩家单位管理器.ts` | 薄门面：绝对 `require` 再导出 `initPlayerUnitManager`，保持旧路径不变 |

## 功能
- 从 `YDUserData` 读取维护好的“玩家英雄单位组”：  
  `YDUserDataGet("string", "玩家英雄", "单位组", "group")`
- 使用 `系统.00．核心系统.05．中心计时器` 周期检查该组内每个单位移速：
  - `moveSpeed > 400`：挂载 `Abilities\\Spells\\Other\\Tornado\\Tornado_Target.mdl` 特效（attach=`origin`）
  - `moveSpeed <= 400`：移除特效

## 特效状态
- 使用内部 `Map(unitHandleId -> effectHandle)` 避免重复创建/销毁。
- 每次遍历后会对“本轮未枚举到但仍存在于 Map 的单位”执行清理（通常表示单位已不在 heroGroup）。

## 接入方式
- 入口为：
  - `TS/系统/00．核心系统/00．玩家系统/index.ts`
  - 调用 `initPlayerUnitManager()`，由 `TS/系统/00．核心系统/index.ts` 在启动时 require。
