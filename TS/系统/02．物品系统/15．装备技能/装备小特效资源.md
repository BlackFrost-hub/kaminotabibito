# 装备小特效资源

本文件记录装备触发类小表现资源。装备特效默认服务于“让玩家知道装备触发了”，不要做成 Boss 技能级大范围表现；单次表现建议控制在 300 半径以内。

## 资源表

| 用途 | 游戏内模型路径 | 颜色 / 备注 |
| --- | --- | --- |
| 暗影潜行烟雾 | `Common\Effect\Element\Dark\ShadowStealthSmoke.mdx` | 影骨披风潜行开始 / 结束。短促播放，不做持续大烟。 |
| 暗影命中小爆点 | `Common\Effect\Element\Dark\ShadowHitBurst.mdx` | 幽影匕首背刺、暗属性额外伤害。 |
| 水雷湿痕 | `Common\Effect\Element\Water\WetShockMark.mdx` | 卡瑟拉深渊法典、电鳗类水雷联动。 |
| 阴影陷阱符文 | `Common\Effect\Form\MagicCircle\ShadowTrapRune.mdx` | 阴影陷阱触发瞬间；待机陷阱仍可使用兽族静止陷阱模型。 |
| 装备护盾小闪光 | `Common\Effect\Form\Shield\EquipmentShieldFlash.mdx` | 可用运行时 API 改 RGB：神风偏青白，莫尔特斯偏暗绿，绝缘珊瑚偏白蓝。 |
| 小型风爆扩散 | `Common\Effect\Element\Wind\SmallWindBurst.mdx` | 里科特风蚀、神风触发、小范围风爆。 |
| 腐败 / 根须 | `Abilities\Spells\NightElf\EntanglingRoots\EntanglingRootsTarget.mdl` | 直接使用魔兽自带纠缠根须，不迁入 imports。 |

## 目录规则

- 模型直接放在分类目录下，不为单个模型再建同名子目录。
- 同分类下的随包贴图放到该分类共享 `Texture` 目录。
- TS / 文档引用模型时不带 `imports\` 前缀。
- 本批由临时模型改名而来：`file_001268`、`file_001282`、`file_001346` 已改为语义化名称。
