# 区域背景音乐

## 目标

- 把旧 JASS 里手写的 `SetStackedSoundBJ(...)` 收敛成 TS 配置表。
- 统一维护普通场景区域、Boss 战区域、胜利音乐区域。
- 便于后续从 Excel 或别的表格半自动导出。

## 当前目录

- `00．区域背景音乐类型.ts`
  - 配置类型定义。
- `01．区域背景音乐配置表.ts`
  - 区域背景音乐主配置表。
- `02．区域背景音乐.ts`
  - 初始化、清空、挂载等运行时逻辑。
- `03．动态区域背景音乐.ts`
  - 剧情运行时区域的配置和兼容入口。
- `04．区域背景音乐运行时.ts`
  - 所有区域音频的统一运行时注册表和低层挂载入口。
  - 剧情表达式、Boss 战音频和静态配置都通过这里调用 `SetStackedSoundBJ`。

## 字段约定

- `场景定义`
  - 逻辑上的场景名。
  - 用来做“清空某个场景的背景音乐”。
  - 例如：`精灵森`、`沙漠区域`、`地精洞窟`。
- `矩形区域名称列表`
  - 统一矩形区域配置表中的名称列表。
  - 同一音乐方案可以挂载到多块地图矩形。
- `默认环境音乐变量名`
  - 普通固定环境音乐。
  - 例如：`gg_snd_BGM007`。
- `随机环境音乐变量名列表`
  - 同一个场景开局随机一种环境音乐时使用。
  - 例如：`["gg_snd_BGM016", "gg_snd_BGM017"]`。
- `随机音乐组`
  - 多个区域要共用同一次随机结果时填写同一个组名。
  - 例如沙漠 3 个区域要么一起 `016`，要么一起 `017`，就必须填同一个组名。
- `战斗音乐变量名`
  - 进入战斗或 Boss 战时使用的区域音乐。
- `胜利音乐变量名`
  - 战斗结束后使用的区域音乐。
- `胜利音乐持续毫秒`
  - 胜利音乐保留时长。
- `同区域重开时先清旧音乐`
  - 用于 Boss 战场景接管时的清理策略。
- `Boss单位ID`
  - 如果该区域配置和某个 Boss 绑定，可以记录单位 4 位 ID。

## 已有规则

- 同一个 `随机音乐组` 只随机一次。
- 同组下所有区域共用同一个随机结果。
- `清空单个区域背景音乐(...)` 会尝试卸载：
  - `默认环境音乐变量名`
  - `随机环境音乐变量名列表` 里的所有候选
  - `战斗音乐变量名`
  - `胜利音乐变量名`
- `清空指定场景区域背景音乐(场景定义)` 会按 `场景定义` 清。
- `清空全部区域背景音乐()` 会按整张表清。

## 运行时区域音频

- `注册运行时区域背景音乐(配置)` 只创建音频和矩形句柄，不自动播放。
- `启用运行时区域背景音乐(键)` / `停用运行时区域背景音乐(键)` 负责挂载和卸载。
- `清理运行时区域背景音乐(键)` 会停止音频，并释放运行时创建的矩形；地图编辑器矩形不会被删除。
- 剧情中的 `gg_snd_xxx @ gg_rct_xxx` 表达式由 `切换区域背景音乐表达式(...)` 统一解析，旧配置格式可以继续使用。

## 维护约定

- 先以 TS 配置表为主，不急着上 Excel 宏。
- 现阶段字段还在调整，直接改 TS 更稳。
- 等字段稳定、条目足够多后，再做 Excel 导出更合适。
- 如果同一个矩形名称出现在多条配置里，要确认是不是故意复用。
  - 否则会导致同一区域被挂多套音乐。

## 后续你给我数据时

你后面可以直接按这种格式给我：

```text
场景定义：精灵森
矩形区域名称列表：["精灵森"]
环境音乐：gg_snd_BGM007
```

如果是随机环境音乐：

```text
场景定义：沙漠区域
矩形区域名称列表：["沙漠区域.区域1", "悲风山谷", "沙漠区域.区域3"]
随机环境音乐：gg_snd_BGM016 / gg_snd_BGM017
随机音乐组：沙漠区域
```

如果是 Boss 战区域：

```text
场景定义：异界Boss场景
矩形区域名称列表：["gg_rct______________1522"]
战斗音乐：gg_snd_battleBoss001
胜利音乐：gg_snd_shengliBgm2
Boss单位ID：E07E
```
