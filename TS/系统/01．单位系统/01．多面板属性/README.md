# 多面板属性系统

## 概述

多面板属性系统用于显示玩家英雄的各项属性，定时刷新数据。

## 文件结构

```
01．多面板属性/
├── 00．常量定义.ts    # 开关、刷新间隔、属性名映射
├── 01．核心功能.ts    # 多面板创建与刷新逻辑
├── index.ts          # 统一导出
└── README.md
```

## 系统开关

在 `00．常量定义.ts` 中设置：
```typescript
export const MULTIBOARD_SYSTEM_ENABLED = true;  // true启用，false禁用
```

## 属性名映射

属性名已与装备系统统一，映射表在 `ATTR_NAME_MAP` 中。

### 预注册属性（装备系统暂无）

以下属性已预留显示位置，但装备系统暂无对应属性：
- `强化抗性`
- `土属性伤害` / `土属性抗性`
- `总生命恢复` / `总魔法恢复`
- `重伤`

## 使用方式

系统自动初始化，无需手动调用。

```typescript
// 手动初始化（可选）
import { initMultiboardSystem } from "系统.01．单位系统.01．多面板属性.index";
initMultiboardSystem();
```

## 注意事项

1. 多面板仅对在线玩家显示
2. 刷新间隔默认4秒
3. 攻速和移速从英雄单位实时获取
4. 其他属性从 YDUserData 读取
