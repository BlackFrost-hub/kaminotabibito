# 护卫系统

Boss 长期从属单位统一通过本系统创建和登记。运行时可以按单位实例判断其是否为护卫、护卫类型及所属 Boss。护卫可以配置血条优先级；优先级大于 0 的护卫死亡后保留登记，以便复活后重新进入血条队列，最终由所属战斗上下文统一注销。其余护卫在死亡事件结束后自动注销。

当前审计并迁移的护卫来源：

- 战斗启动配置：恶魔领袖、蛇之领主、蛇之遗迹看守者。
- 主线 Boss：巴尔扎罗斯的格鲁姆与塞拉、树魔首领的猎头者/巫医/投掷者。
- 异界 Boss：安兹乌尔恭的雅儿贝德。

战斗启动护卫支持按 Boss 战矩形中心的随机环形位置生成，并可配置每批数量和同单位类型最大存活数量；达到上限时跳过该次生成。剧情中已经存在的存活单位可以在 Boss 战启动前登记为待带入护卫，转场完成后会搬到 Boss 周围并进入同一套护卫攻击与结束清理流程。

不纳入护卫：短时技能召唤、投影、分身、弹道/机制单位，以及本身作为联合 Boss 的祖地双灵卫。

## Boss 护卫血条优先级

- `护卫血条优先级 <= 0`：不进入护卫血条队列。
- 优先级越高越先显示；同优先级按登记顺序显示。
- 每组最多显示两个护卫，未显示的存活护卫继续排队。
- 显示中的护卫死亡后由后续候选补位；高优先级护卫复活或重新创建后会重新插入前两名。
- 树魔首领：投掷者 `300`、巫医 `200`、猎头者 `100`。
