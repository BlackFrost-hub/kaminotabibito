# 英雄恢复系统 - 规划文档

## 一、系统概述

| 项目 | 说明 |
|------|------|
| 系统名称 | 英雄恢复系统 |
| 建议归属 | 01．单位系统 或 新建属性系统 |
| 触发时机 | 周期计时器（每1秒） |

## 二、核心功能模块

### 2.1 基础恢复计算

**生命恢复：**
```
基础生命恢复 = 力量 × 0.32
```

**魔法恢复：**
```
基础魔法恢复 = 智力 × 0.15
```

### 2.2 百分比恢复

**生命百分比恢复：**
- 来源：`百分比生命回复` 玩家属性
- 上限：6%

**魔法百分比恢复：**
- 来源：`百分比魔法回复` 玩家属性
- 上限：4%

### 2.3 属性增幅

```
总生命恢复 = (1 + 生命恢复属性增幅) × (百分比生命恢复 + 固定生命恢复)
总魔法恢复 = 百分比魔法恢复 + 固定魔法恢复
```

### 2.4 恢复执行条件

| 条件 | 说明 |
|------|------|
| 总恢复 > 0.50 | 或 |
| 百分比恢复 ≥ 1% | 满足任一条件才执行恢复 |

## 四、接口设计

### 4.1 恢复计算

```typescript
/**
 * 计算单位总生命恢复
 * @param unit 目标单位
 * @returns 每秒生命恢复值
 */
export function calcTotalLifeRegen(unit: any): number;

/**
 * 计算单位总魔法恢复
 * @param unit 目标单位
 * @returns 每秒魔法恢复值
 */
export function calcTotalManaRegen(unit: any): number;

/**
 * 计算基础生命恢复（力量×0.32）
 * @param unit 目标单位
 * @returns 基础恢复值
 */
export function calcBaseLifeRegen(unit: any): number;

/**
 * 计算基础魔法恢复（智力×0.15）
 * @param unit 目标单位
 * @returns 基础恢复值
 */
export function calcBaseManaRegen(unit: any): number;
```

### 4.2 恢复上限

```typescript
/** 百分比生命恢复上限 */
export const LIFE_REGEN_PERCENT_CAP = 0.06;  // 6%

/** 百分比魔法恢复上限 */
export const MANA_REGEN_PERCENT_CAP = 0.04;  // 4%

/**
 * 应用百分比恢复上限
 * @param value 原始值
 * @param isLife 是否为生命恢复
 */
export function applyRegenCap(value: number, isLife: boolean): number;
```

### 4.3 恢复执行

```typescript
/**
 * 执行单位恢复
 * @param unit 目标单位
 * @param lifeRegen 生命恢复值
 * @param manaRegen 魔法恢复值
 */
export function applyRegeneration(
  unit: any,
  lifeRegen: number,
  manaRegen: number
): void;
```

## 六、特殊效果处理（单独文件）

### 6.1 装备效果处理

**触发文件：** `TS/系统/01．单位系统/02．恢复系统/04．装备恢复效果.ts`

**物品I0BR效果：**
- 增加 12% 最大生命恢复
- 叠加到基础生命恢复

```typescript
/**
 * 装备恢复效果配置
 */
const ITEM_REGEN_EFFECTS: Record<number, ItemRegenEffect> = {
  'I0BR': {
    type: 'life_percent',
    value: 0.12,  // 12%最大生命
  },
  // 可扩展更多装备
};

/**
 * 计算装备提供的恢复加成
 * @param unit 目标单位
 * @returns 装备恢复加成
 */
export function calcItemRegenBonus(unit: any): {
  lifeBonus: number;
  manaBonus: number;
};
```

### 6.2 单位特性处理

**触发文件：** `TS/系统/01．单位系统/02．恢复系统/05．单位恢复特性.ts`

**单位H00R效果：**
