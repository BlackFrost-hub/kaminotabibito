# 仇恨系统规划

本文档用于规划敌方单位的仇恨值系统。

目标不是控制玩家，也不是替代现有技能模块，而是给敌方单位提供一个稳定的“目标选择 / 切换目标 / 维持攻击对象”的 AI 决策层。

## 放置位置建议

推荐放在：

- `TS/系统/01．单位系统/06．仇恨系统`

不推荐放在：

- `TS/系统/03．技能系统/00．技能模板+函数/01．技能函数/16．嘲讽`

原因：

- 仇恨系统本质是单位 AI 与目标决策系统，不是技能函数。
- 嘲讽只是“临时强制覆盖目标”的控制模块，应当反向接入仇恨系统，而不是让仇恨系统挂在嘲讽下面。
- 后续如果要接入 Boss、召唤物、宠物、治疗仇恨、脱战清空，都更像单位系统职责。

## 推荐目录结构

- `00．仇恨存储.ts`
- `01．仇恨计算.ts`
- `02．仇恨目标选择.ts`
- `03．仇恨驱动.ts`
- `04．仇恨事件接入.ts`
- `README.md`

## 第一版目标

第一版只做最小可用，不追求 MMO 级完整度。

建议先支持：

- 敌人记录玩家 1-4 英雄的仇恨值
- 敌人记录必要的召唤物 / 宠物仇恨值
- 伤害行为增加仇恨
- 周期选取最高仇恨目标
- 低频驱动敌人攻击该目标
- 目标死亡 / 无效 / 超距时移除仇恨
- 脱战后清空仇恨
- 嘲讽期间暂停仇恨接管

## 系统分层

### 1. 仇恨存储层

每个敌人一张仇恨表：

- `enemyHid -> { targetHid: threat }`

需要提供：

- `增加仇恨(敌人, 来源, 数值, 原因)`
- `设置仇恨(敌人, 来源, 数值)`
- `获取仇恨(敌人, 来源)`
- `清空仇恨(敌人, 来源?)`
- `获取最高仇恨目标(敌人)`

### 2. 仇恨计算层

第一版建议只接最常见来源：

- 造成伤害：按“实际伤害占目标最大生命值的百分比”换算仇恨
- 治疗友军：后续再加
- 开怪接触：给基础仇恨
- 嘲讽：临时强制锁目标，不直接当作普通仇恨处理

推荐基础公式：

- `仇恨值 = (实际伤害 / 目标最大生命值) * 100`

也就是：

- 打掉目标 `1%` 最大生命值 = `1` 点基础仇恨
- 打掉目标 `25%` 最大生命值 = `25` 点基础仇恨

这样比“1伤害 = 1仇恨”更稳定，原因是：

- 后期伤害数字膨胀时不容易失控
- 不同血量怪物之间的仇恨尺度更统一
- 后续做切换阈值、嘲讽附加值、Boss 特判时更容易调参

第一版最稳的方案：

- 先只做伤害仇恨
- 治疗仇恨、光环仇恨、召唤仇恨转移放后续

### 3. 目标选择层

不要每帧切目标。

推荐：

- 每 `0.20 ~ 0.30` 秒检查一次
- 取最高仇恨目标
- 加目标粘性，防止频繁横跳

建议切换条件：

- 新目标仇恨 >= 当前目标仇恨的 `1.2` 倍，再切换

### 4. 驱动层

仇恨系统不要等于“立刻发攻击命令”。

更合理的是：

- 周期得到“应攻击目标”
- 再低频驱动敌人攻击
- 与施法、硬直、暂停、冲锋、跳跃互斥

建议驱动时检查：

- 单位是否活着
- 是否暂停 / 硬直 / 被强制位移
- 是否正在执行不可打断技能
- 是否正处于嘲讽强制期

### 5. 事件接入层

建议优先接入：

- 伤害系统最终伤害事件
- 单位死亡事件中心
- 单位所有者变更事件中心
- 嘲讽系统

## 与嘲讽系统的关系

推荐关系：

- `嘲讽 = 强制覆盖层`
- `仇恨 = 常态决策层`

具体规则：

- 嘲讽生效时：敌人临时只攻击嘲讽来源
- 嘲讽期间：仇恨值仍可累计
- 嘲讽结束后：恢复由仇恨系统接管

也就是：

- 嘲讽不负责长期 AI
- 仇恨不负责硬控制

两者是叠加关系，不是替代关系

## 第一版不建议做的内容

这些容易把系统复杂度瞬间抬高，建议后做：

- 治疗仇恨
- 群体共享仇恨
- 仇恨衰减曲线
- Boss 特殊阶段仇恨重置
- 假死 / 隐身 / 伪装
- 技能脚本自定义仇恨倍率
- 宠物给主人转移仇恨
- 完整坦克技能模板

## 推荐实现顺序

### 阶段 1：可用骨架

- 建仇恨存储
- 建最高仇恨目标选择
- 建 0.25 秒低频驱动
- 建死亡 / 超距 / 脱战清理

### 阶段 2：接入战斗

- 接入伤害事件
- 普攻 / 技能统一加仇恨
- 给聊天测试文件

### 阶段 3：接入控制

- 接入嘲讽
- 嘲讽期间暂停仇恨接管
- 嘲讽结束恢复最高仇恨目标

### 阶段 4：后续增强

- 治疗仇恨
- Boss 专用规则
- 仇恨粘性与切换阈值配置
- 召唤物 / 宠物 / 特殊中立单位扩展

## 一句话结论

仇恨系统推荐放在：

- `TS/系统/01．单位系统/06．仇恨系统`

不要放在嘲讽系统下面。

嘲讽应当作为仇恨系统的“强制覆盖模块”接入，而不是作为仇恨系统的父级目录。
