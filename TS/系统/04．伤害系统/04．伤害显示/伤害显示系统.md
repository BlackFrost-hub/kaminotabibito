# 伤害显示系统

## 概述

伤害显示系统在单位受到伤害时显示伤害数字，使用图片形式逐位显示，并根据伤害类型显示不同颜色。

## 文件结构

```
04．伤害显示/
├── 00．常量定义.ts    # 配置常量、颜色配置
├── 02．核心功能.ts    # 伤害数字显示核心逻辑
├── 03．Boss战统计.ts  # Boss战伤害统计
├── 04．事件注册.ts    # 伤害事件注册与分发
└── index.ts          # 统一入口
```

## 模块说明

### 00．常量定义.ts
- 伤害阈值、图片尺寸、间距等配置
- 伤害类型颜色配置（12种伤害类型）

### 02．核心功能.ts
- `showDamageNumber()` - 显示伤害数字
- `updateAllDamageDigits()` - 更新所有数字位置
- 使用中心计时器统一更新

### 03．Boss战统计.ts
- `updateBossDamageStats()` - 更新Boss战伤害统计
- `getPlayerDamageToBoss()` - 获取玩家对Boss伤害
- `getPlayerDamageFromBoss()` - 获取玩家承受Boss伤害

### 04．事件注册.ts
- 注册伤害事件回调
- 分发事件到核心功能和Boss战统计
- 自动初始化

## 与JASS原版差异

### 可优化部分
- 使用数组存储活跃数字，不依赖YDLocal
- 使用中心计时器统一更新
- 使用registerDamageCallback注册回调

### 不可优化部分
- `YDWEIsEventDamageType`：JASS端函数，判断伤害类型
- `YDUserDataGet/YDUserDataSet`：Boss战伤害统计依赖
