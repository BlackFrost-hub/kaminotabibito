# 广播提示消息系统规划

## 目标

在 `TS/系统/09．表现系统/06．广播提示消息` 下实现一套新的广播提示 UI，复刻 `JASS/世界地图/广播提示消息.j` 的滑入、停留、淡出效果，但把原喇叭图标替换为单位头像。

资源已经迁入：

- `UI/xiaoxi/UInoticebackdrop.tga`：消息长条背景。
- `UI/xiaoxi/UInotice.tga`：旧喇叭图标，仅保留为备用资源。
- `UI/BuffTestTooltip.fdf`：已合并 `textmoban` 与 `Demo_BorderBack` 模板。

## 对外接口

计划提供这些入口：

```ts
初始化广播提示消息系统();
广播单位提示(来源单位: any, 文本: string, 持续时间?: number): void;
发送单位提示给玩家(目标玩家: any, 来源单位: any, 文本: string, 持续时间?: number): void;
发送头像提示给玩家(目标玩家: any, 头像路径: string, 文本: string, 持续时间?: number): void;
```

其中 `广播单位提示` 面向全体玩家，`发送单位提示给玩家` 面向指定玩家，`发送头像提示给玩家` 允许业务侧传入特殊图标。

## 目录结构

建议拆成：

- `00．常量定义.ts`：资源路径、槽位数量、尺寸、动画时间、位置和默认头像。
- `01．头像读取.ts`：根据单位或单位类型 ID 读取头像贴图。
- `02．UI创建.ts`：预创建消息槽 Frame。
- `03．消息队列.ts`：管理每个玩家的消息槽状态、入队和覆盖。
- `04．动画驱动.ts`：中心计时器回调，统一推进滑入、停留、淡出。
- `index.ts`：初始化和对外 API。

## 头像读取

单位头像优先读取物编 `Art` 字段，失败后读取 `uico` 字段，再失败使用默认图标。

伪代码：

```ts
const art = getObjectProperty(ObjectType.UNIT, unitTypeId, "Art");
if (isTexturePath(art)) return art;

const icon = getObjectProperty(ObjectType.UNIT, unitTypeId, "uico");
if (isTexturePath(icon)) return icon;

return DEFAULT_ICON;
```

必须按 `unitTypeId` 做单层缓存：

```ts
const 单位头像缓存: Record<number, string | undefined> = {};
```

禁止在动画 tick 中反复读取物编字段。

## UI 结构

每条消息槽使用：

- `root BACKDROP`：长条背景，贴图 `UI\\xiaoxi\\UInoticebackdrop.tga`。
- `icon BACKDROP`：单位头像，运行时通过 `DzFrameSetTexture(icon, iconPath, 0)` 设置。
- `text TEXT`：提示文本。

原 JASS 的 `UInotice.tga` 是喇叭图标，新系统不默认使用它。图标位保留为动态头像位。

## 联机安全

初始化时所有客户端创建同样数量的消息槽，不在 `GetLocalPlayer()` 分支里创建或销毁 Frame。

消息数据应先在全端同步路径中确定：

- 目标玩家 ID。
- 文本。
- 头像路径。
- 持续时间。

最后只在本地展示阶段按 `GetLocalPlayer() === 目标玩家` 控制显示和隐藏。

如果实现全体广播，所有客户端可以对同一批槽位设置相同文本和头像。  
如果实现单玩家提示，推荐按玩家槽位预创建 N 组 Frame，槽位 `playerId` 只服务对应玩家。

## 动画策略

不要照搬 JASS 示例里每条消息创建多个 Timer 的做法。

推荐接入中心计时器：

- 每 30ms 或 50ms 统一更新所有活动槽。
- 状态机：`slideIn -> hold -> fadeOut -> hidden`。
- 每个槽记录 `elapsedMs`、`alpha`、`x`、`state`。

这样可以避免大量独立 timer 和匿名回调，也方便检查 TSTL 生成的回调形态。

## 验收点

实现时需要验证：

- `npm run build` 通过。
- 生成 Lua 中 `DzCreateFrameByTagName`、`DzFrameSetTexture`、`DzFrameSetText`、中心计时器回调没有 `self/nil` 错位。
- 头像路径只在入队或缓存未命中时读取。
- `UI\\xiaoxi\\UInoticebackdrop.tga` 能正常显示。
- 原喇叭图标不再作为默认图标出现。
