# UI属性系统

## 入口

- 运行时入口：`require("系统.09．表现系统.03．UI属性系统.index")`
- 表现系统总入口：`TS/系统/09．表现系统/index.ts`
- JASS 参考源：`JASS/jass复制粘贴/属性查看.j`

## 当前实现

- 已按 `属性查看.j` 重建为 DzFrame UI，不再沿用之前弄错的多面板实现。
- 包含 `Tab` 显示伤害统计、`F2-F6` 跳镜头、英雄头像悬浮显示属性框。
- 属性读取统一走当前 TS 正式字段名，优先对齐 `TS/系统/02．物品系统/11．装备系统.ts`。
- 系统延迟 2 秒初始化，每 3 秒刷新一次伤害统计和属性文本。

## 依赖

- `lib.扩展函数.YDWE函数.index`
- `lib.扩展函数.Star扩展函数.Star扩展库.index`
- `玩家 -> 英雄`、`造成伤害/承受伤害/治疗量` 等 YDUserData 数据源

## 接手注意

- 继续使用绝对路径 `require("系统.xxx")`，不要回退到 `./`。
- 不要把 BJ 包装函数当 JASS/JAPI 原生函数使用。
- 旧目录 `TS/系统/01．单位系统/01．多面板属性` 不是这个系统，不能误删。
