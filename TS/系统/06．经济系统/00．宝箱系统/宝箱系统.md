# 宝箱系统

## 概述

宝箱系统处理玩家与可交互目标的交互逻辑，支持任意类型的可交互目标（宝箱、宝物等）。

## 文件结构

```
00．宝箱系统/
├── 00．常量定义.ts      # 配置常量、可交互类型列表
├── 01．宝箱核心.ts      # 核心逻辑（交互检测、进度条）
├── 02．宝箱掉落配置.ts  # 掉落数据集中管理
├── 03．宝箱掉落核心.ts  # 掉落逻辑处理
├── 02．事件注册.ts      # 事件注册与英雄联动
└── index.ts            # 统一入口
```

## 添加新的可交互类型

在 `00．常量定义.ts` 的 `INTERACTABLE_TYPES` 数组中添加：

```typescript
export const INTERACTABLE_TYPES: InteractableConfig[] = [
  { destructableType: "B00Z", openTime: 3.0, name: "宝箱" },
  { destructableType: "B010", openTime: 5.0, name: "大宝箱" }, // 新增
  { destructableType: "B011", openTime: 2.0, name: "小宝箱" }, // 新增
];
```

系统会自动识别并处理这些类型。

## 宝箱掉落配置

### 掉落规则（学习 05.装备掉落.ts）

| 配置项 | 说明 |
|--------|------|
| `picks` | 最多掉落多少件（不是必定掉满） |
| `itemPool` 带权重 | 如 `I01K:1.5;I06X:1`，按权重在池中随机抽 `picks` 件 |
| `itemPool` 无权重 | 如 `I01K;I06X;I06Y`，从池中选 `min(picks, 池大小)` 件不重复 |
| `scoreRange` 单独使用 | 从装备数据中筛选分数范围内的物品，等权重随机 |
| `scoreRange` + `itemPool` | 先按分数筛选，再按 `itemPool` 权重抽取 |
| `always` | 必掉且仅掉一次，不参与随机 |

### 配置示例

在 `02．宝箱掉落配置.ts` 的 `CHEST_DROP_CONFIGS` 中添加：

```typescript
// 示例1: 分数范围随机掉落
"chest_low": {
  id: "chest_low",
  scoreRange: { min: 100, max: 500 },
  picks: 1,
},

// 示例2: 指定物品池（带权重）
"chest_specific": {
  id: "chest_specific",
  itemPool: "I01K:1.5;I06X:1;I06Y:2",
  picks: 2,
},

// 示例3: 混合模式 + 必掉物品
"chest_mixed": {
  id: "chest_mixed",
  scoreRange: { min: 500, max: 1500 },
  itemPool: "I01K:2;I06X:1",
  picks: 2,
  always: ["I00V"], // 必掉I00V
},
```

### 可破坏物类型映射

在 `02．宝箱掉落配置.ts` 的 `DESTRUCTABLE_TO_CHEST_CONFIG` 中映射：

```typescript
export const DESTRUCTABLE_TO_CHEST_CONFIG: Record<string, string> = {
  "B00Z": "chest_low",      // 普通宝箱 -> 低分配置
  "B010": "chest_mid",      // 中级宝箱 -> 中分配置
  "B011": "chest_high",     // 高级宝箱 -> 高分配置
};
```

## API使用

### 通过配置ID掉落

```typescript
const { dropItemsFromChest } = require("系统.06．经济系统.00．宝箱系统.04．宝箱掉落核心");

// 在指定位置掉落
const items = dropItemsFromChest("chest_low", x, y);
```

### 通过可破坏物类型掉落

```typescript
const { dropItemsByDestructable } = require("系统.06．经济系统.00．宝箱系统.04．宝箱掉落核心");

// 根据可破坏物类型自动选择配置
const items = dropItemsByDestructable("B00Z", x, y);
```

### 便捷函数

```typescript
const { dropItemsByScore, dropItemsByPool } = require("系统.06．经济系统.00．宝箱系统.04．宝箱掉落核心");

// 按分数范围掉落
dropItemsByScore(100, 1000, 2, x, y);

// 按物品池掉落
dropItemsByPool("I01K:1.5;I06X:1", 2, x, y);
```

## STES事件

| 事件名 | 参数 | 说明 |
|--------|------|------|
| 玩家准备开启宝箱 | 预开启者(unit), 被预开启的宝箱(destructable) | 开始开启时触发 |
| 宝箱被开启 | 开启者(unit), 被开启的宝箱(destructable) | 成功开启时触发 |

```typescript

function registerHeroDependents(whichHero: any): void {
  // ...
```

## 配置常量

|------|--------|------|

## 设计说明

### 可优化部分
- 使用Map存储数据，不依赖YDLocal
- 使用中心计时器统一更新
- 可交互类型通过配置数组扩展
- 掉落配置独立管理，支持分数范围和权重

### 不可优化部分
- STES事件触发链：`YDLocalExecuteTrigger → saveParentIndex → YDLocal5Set → YDTriggerExecuteTrigger`
- YDLocal5Set传参：JASS端依赖这些参数名读取数据
