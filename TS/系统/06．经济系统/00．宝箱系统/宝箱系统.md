# 宝箱系统

## 概述

宝箱系统处理玩家与可交互目标的交互逻辑，支持任意类型的可交互目标（宝箱、宝物等）。

## 文件结构

```
00．宝箱系统/
├── 00．常量定义.ts    # 配置常量、可交互类型列表
├── 01．宝箱核心.ts    # 核心逻辑
├── 02．事件注册.ts    # 事件注册与英雄联动
└── index.ts          # 统一入口
```

## 添加新的可交互类型

在 `00．常量定义.ts` 的 `INTERACTABLE_TYPES` 数组中添加：

```typescript
export const INTERACTABLE_TYPES: InteractableConfig[] = [
  { destructableType: 0x4230305A, openTime: 3.0, name: "宝箱" }, // 'B00Z'
  { destructableType: 0x4230305B, openTime: 5.0, name: "大宝箱" }, // 新增
  { destructableType: 0x4230305C, openTime: 2.0, name: "小宝箱" }, // 新增
];
```

系统会自动识别并处理这些类型。

## STES事件

| 事件名 | 参数 | 说明 |
|--------|------|------|
| 玩家准备开启宝箱 | 预开启者(unit), 被预开启的宝箱(destructable) | 开始开启时触发 |
| 宝箱被开启 | 开启者(unit), 被开启的宝箱(destructable) | 成功开启时触发 |

## 英雄注册联动

宝箱系统已注册到玩家英雄注册联动，当英雄被登记时自动注册目标命令事件：

```typescript
// 在 00．玩家英雄获取桥接.ts 中
function registerHeroDependents(whichHero: any): void {
  // ...
  chestSystem.registerChestSystemHero(whichHero);
}
```

## 配置常量

| 常量 | 默认值 | 说明 |
|------|--------|------|
| INTERACTABLE_TYPES | [{...}] | 可交互目标类型列表 |
| DEFAULT_OPEN_TIME | 3.0 | 默认开启时间(秒) |
| INTERACT_RANGE | 150.0 | 交互范围 |

## 设计说明

### 可优化部分
- 使用Map存储数据，不依赖YDLocal
- 使用中心计时器统一更新
- 可交互类型通过配置数组扩展

### 不可优化部分
- STES事件触发链：`YDLocalExecuteTrigger → saveParentIndex → YDLocal5Set → YDTriggerExecuteTrigger`
- YDLocal5Set传参：JASS端依赖这些参数名读取数据
