# 控制抗性系统 - 规划文档

## 一、系统概述

| 项目 | 说明 |
|------|------|
| 系统名称 | 控制抗性系统 |
| 建议归属 | 新建 05．Buff系统 或 独立控制抗性系统 |
| 触发时机 | EVENT_PLAYER_UNIT_SPELL_CHANNEL（技能施放开始） |

## 二、核心功能模块

### 2.1 控制时间削减

```
检测控制技能 → 读取减少控制时间属性 → 应用上限 → 重新施放缩短控制
```

**属性来源：**
- `减少控制时间`：优先读取单位属性，其次读取玩家属性

**上限规则：**
| 类型 | 上限 |
|------|------|
| 通用削减上限 | 90% |
| Boss单位(N05U)控制时间上限 | 1秒 |

### 2.2 控制技能判定

**判定条件：**
1. 技能命令不是 `ward`（守卫类）
2. 技能命令不是 `web`（蛛网类）
3. 技能英雄持续时间(HeroDur1) > 0.02秒
4. 目标有「减少控制时间」属性 > 0.01
5. 目标当前命令为 `stop` 或被控制状态

### 2.3 控制重施放流程

```
1. 移除原控制技能
2. 发送stop命令打断目标
3. 计算缩短后的控制时间
4. 创建辅助马甲单位
5. 马甲添加控制技能(A051)
6. 设置技能持续时间
7. 马甲对目标施放控制技能
```

### 2.4 辅助马甲配置

| 项目 | 值 |
|------|-----|
| 马甲类型 | YDUserData "辅助马甲（减控用）"/"单位类型" |
| 控制技能 | A051（雷霆一击） |
| 设置字段 | 102(持续时间), 103(英雄持续时间) |

## 四、接口设计

### 4.1 控制检测

```typescript
/**
 * 判断技能是否为控制技能
 * @param abilityId 技能ID
 * @returns 是否为控制技能
 */
export function isControlAbility(abilityId: number): boolean;

/**
 * 检查单位是否处于被控制状态
 * @param unit 目标单位
 * @returns 是否被控制
 */
export function isUnitControlled(unit: any): boolean;
```

### 4.2 控制时间计算

```typescript
/**
 * 计算削减后的控制时间
 * @param target 目标单位
 * @param originalDuration 原始控制时间
 * @returns 实际控制时间
 */
export function calcReducedControlTime(
  target: any,
  originalDuration: number
): number;

/**
 * 获取单位的减少控制时间属性
 * @param unit 目标单位
 * @returns 减少比例(0-0.9)
 */
export function getControlReduction(unit: any): number;
```

### 4.3 控制重施放

```typescript
/**
 * 重施放控制技能
 * @param caster 原施法者
 * @param target 目标单位
 * @param abilityId 技能ID
 * @param duration 控制时间
 */
export function recastControlAbility(
  caster: any,
  target: any,
  abilityId: number,
  duration: number
): void;
```

## 六、特殊单位处理（单独文件）

### Boss控制时间上限

**触发文件：** `TS/系统/05．Buff系统/01．控制抗性/05．Boss控制上限.ts`

**逻辑：**
- 检测目标单位类型是否为 N05U
- 控制时间超过1秒时，强制设为1秒
- 可扩展配置更多Boss单位

```typescript
/**
 * Boss单位控制时间上限配置
 */
const BOSS_CONTROL_LIMITS: Record<number, number> = {
  'N05U': 1.0,  // 1秒上限
  // 可扩展更多Boss
};

/**
 * 检查并应用Boss控制时间上限
 */
export function applyBossControlLimit(
  unitTypeId: number,
  duration: number
): number;
```
