# BJ函数 `@noSelfInFile` 说明

记录时间：2026-05-22 21:16:42

这次在 `TS/lib/扩展函数/BJ函数` 下补了 `@noSelfInFile`，目的只有一个：

- 修正 TSTL 生成 Lua 时的 `self / nil` 参数错位
- 让这些 BJ 包装函数能被正常的 `require` / 直接调用 / 交叉引用

本次已处理的文件：

- `00．BJ全局兜底.ts`
- `02．单位与英雄.ts`
- `03．物品与库存.ts`
- `04．矩形与区域.ts`
- `05A．电影函数.ts`
- `05B．音效函数.ts`
- `06．任务消息.ts`
- `07．杂项.ts`
- `08．单位BJ扩展.ts`
- `09．物品操作.ts`
- `10．图像函数.ts`
- `11．贴图函数.ts`
- `13．多面板函数.ts`
- `index.ts`

说明：

- 这批文件里，外部引用和生成 Lua 都已经检查过。
- 如果以后再出现 `fn(nil, ...)`、`function xxx(self, ...)` 之类的错位，优先先查这里的文件。
- 不要因为看到旧报错就回退这次改动，先看对应文件是否真的需要 `self`。
