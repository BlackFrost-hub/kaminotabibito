# 魔兽争霸3 随机数使用规则

## 随机数使用的两种正确方案

### 方案1（推荐）：完全不碰 math.randomseed()
- 魔兽3引擎会自动管理随机数序列，保证所有玩家同步
- 每次新游戏会有不同的随机序列，可玩性好
- 最简单、最安全

### 方案2（可选）：用固定种子 + 只初始化一次
如果确实需要设置随机种子，必须满足：
1. 只在模块加载时初始化 **一次**（用 globalThis 的 key 检查避免重复执行）
2. 用 **固定种子**（所有玩家都一样）

**正确示例代码：**
```typescript
// 安全初始化随机种子（只执行一次，所有玩家一致）
(() => {
  const key = "__equip_drop_rand_init";
  if ((globalThis as any)[key]) return;
  (globalThis as any)[key] = true;
  math.randomseed(123456789);
  // 预先消耗一些随机数，确保随机性
  for (let i = 0; i < 10; i++) math.random();
})();
```

### 随机种子不同步的具体例子
- **错误做法1**：用 `tostring({})` 获取字符串（内存地址不同）作为种子
- **错误做法2**：每次调用随机函数都设置一次种子
