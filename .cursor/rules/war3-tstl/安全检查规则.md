## 4. 使用建议

### 原生 JASS 函数
```typescript
// 不需要检查，直接调用
const t = jass.CreateTimer();
jass.TimerStart(t, 1.0, false, callback);
jass.DestroyTimer(t);
```

### JAPI / EX 函数
```typescript
// 默认直接调用
japi.DzFrameSetText(frame, "text");
```

### 返回值检查
```typescript
// 创建类函数需要检查返回值
const t = jass.CreateTimer();
if (!t) return; // 创建失败

const item = jass.CreateItem(itemId, x, y);
if (!item) return; // 创建失败
```
