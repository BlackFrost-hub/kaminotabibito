# 装备评分与章节强度

本规则用于估算装备的 HP 等效价值、章节梯度和控制技能预算。评分是设计参照，不代替对现有装备池、Boss 奖励池和实际战斗体验的比较。

## 地图基线

- 类型：4 人剧情 RPG，核心由探索、解密、成长和 Boss 战组成。
- `1 点生命值 = 1 分`，其他属性换算为 HP 等效值。
- 参考难度：难度 1 为 100% 攻击/生命；难度 3 约 135% 攻击、155% 生命；难度 6 约 180% 攻击、320% 生命。这里的生命倍率指 Boss 生命，后续可按实际难度系统调整。
- 参考战斗时长：20 秒。

## 战斗环境假设

| 项目 | 参考值 |
|------|--------|
| 敌人平均护甲 | 33 |
| 敌人平均魔抗 | 25% |
| 敌人平均闪避 | 10% |
| 敌人平均暴击 | 20% 概率、160% 暴击伤害 |
| 敌人基础命中率 | 100% |
| 护甲减伤公式 | `N / (N + 50)` |
| 英雄无加成基础攻速 | 2.4 秒/次 |
| 玩家基础暴击伤害 | 普攻 150%，技能 125% |

“强化伤害”按 Dota 纯粹伤害理解；本项目魔抗也能减免属性伤害。

护甲公式和单位物编档位属于全局 [游戏平衡数据](../balance/游戏平衡数据.mdc)。上表的“敌人平均护甲 33”只用于装备估值采样，不代表普通单位或 Boss 的默认物编护甲；普通单位、主线 Boss、精英单位默认分别为 `10 / 25 / 35`。

## 覆盖率与价值系数

| 属性类型 | 系数/覆盖率 | 说明 |
|----------|-------------|------|
| 生命恢复 | 1.0 | 被动回血按完整覆盖计算 |
| 主动生命恢复 | 0.65 | 主动使用需要折价 |
| 冷却缩减 | 0.9 | 同时提升伤害、功能性和安全窗口 |
| 魔法值、魔法恢复、技能消耗减少 | 0.7 | 地图整体较耗蓝 |
| 暴击率、暴击伤害、穿透、魔法伤害等直接伤害属性 | 0.75 | 假设装备给到需要该属性的角色 |
| 护甲、物理伤害减少 | 0.75 | 结合平均敌方物理压力 |
| 魔抗 | 0.5 | 同时影响魔法和属性伤害承受 |

| 技能治疗 | 0.6 | 按战斗内有效治疗覆盖率折算 |
| 眩晕抗性 | 0.5 | 按控制覆盖率折算 |
| 属性伤害提高/减少 | 0.45 | 按属性伤害占比折算 |

## 伤害构成假设

- 默认一次战斗中普攻与技能伤害各占 50%。
- 装备明显偏向普攻、技能、魔法伤害或治疗时，对应方向按 70% 占比估算。
- 装备只强化物理或魔法其中一种伤害、且没有同时强化另一种时，该伤害类型可按 75% 占比估算。
- 评分只是预算工具；技能机制、范围、命中稳定性和团队价值仍需单独估算。

## 硬控与控制技能红线

- 攻击概率附带硬控时，控制词条必须占装备总评分的大比例，不能按普通触发伤害估值。
- 基准：`10% 概率攻击击晕 1 秒` 至少占装备总评分的 70%；总分越高，剩余常驻属性越要主动让位。
- 主动技能带控制时，控制部分至少占装备总评分的 40%。范围、长持续、稳定命中、可打断 Boss 或群体控场时继续上调。
- 硬控包括眩晕、冰冻、缠绕/定身、恐惧、沉默、缴械、变形、睡眠、强制位移，以及显著剥夺行动、施法或攻击能力的效果。
- 控制和高伤害、高治疗或高护盾同时出现时，继续压缩常驻属性，避免控制装变成无代价全能装。
- 先预留控制预算，再分配基础属性；禁止把控制当作满分属性之外的免费特效。
