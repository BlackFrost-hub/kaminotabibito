# 图标资源与物遍规则

## 图标资源

- 装备图标默认放在 `imports\Equipment\Icon\` 下，并按装备限制 / 装备数据分类。
- 资源路径在物编 / TS 中引用时必须去掉 `imports\` 前缀。
- 会显示在首领奖励 UI 里的装备图标输出 `100x100`，保证奖励选择界面清晰。
- 不会进入首领奖励 UI 的普通装备、任务物品、消耗品、材料等默认输出 `80x80`，避免无意义增加地图体积。
- 装备图标最终导入格式默认 `.blp`。
- PNG 只作为生成 / 调整中间产物，完成转换后从项目资源目录删除，避免 PNG 和 BLP 同时打包。
- 装备图标必须使用统一的黑铁 / 黑银魔兽 BTN 边框：暗色金属外框、低亮度冷灰倒角、左上角窄高光、右下角暗角；不要生成金色边框、白色边框、Boss/Buff 鲜艳边框、现代扁平 UI 边框，也不要额外画一圈明显的双层内边框。

PNG 转 BLP：

- 优先复用本机 VSCode 插件 `war3-texture-preview` 的转换能力。
- 转换后用同插件解码回读检查尺寸和画面，确认不是黑图、翻转图或错误尺寸。
- `war3-texture-preview` 插件右键菜单与当前文件后缀有关：选中 `.png` / `.tga` 时才会出现“转换为 BLP”；选中 `.blp` 时只会出现“转换为 PNG / TGA”。
- AI 不要因为 BLP 文件右键菜单里没看到“转换为 BLP”就误判插件不支持 PNG/TGA -> BLP。
- 需要脚本化时，优先复用该插件的 `out/conversion/textureConvert.js` / `blpEncode.js` 编码器，并再用插件解码器回读验证。

## 目录归类

- 主武器继续按 `weaponType` 细分：`Sword`、`AxeHammer`、`Staff`、`Dagger`、`Spear`、`Bow`、`Shield`。
- `饰品`、`手腕`、`特殊` 等非装备槽道具默认归入 `Item`。
- `披风` 默认归入 `Clothes`，除非用户明确指定新分类。

## 装备物编模型规则

- 装备物编模型路径和图标路径一样，引用时必须去掉 `imports\` 前缀。例如 `imports\Common\Model\wepon\zb12.mdx` 写成 `Common\Model\wepon\zb12.mdx`。
- 衣服 / 披风默认模型：`war3mapImported\Item Jerkin.mdl`。
- 名称带“盾”的装备默认模型：`war3mapImported\ItemRoundShield.mdl`。
- 鞋子默认模型：`war3mapImported\PVP_Rune_Speed_Icon.mdl`。
- 名称带“书”的普通书默认模型：`war3mapImported\SpellBook.mdl`；魔法书 / 高级书默认模型：`war3mapImported\TomeOfRetraining.mdl`。
- 戒指 / 首饰可按表现选择：紫色首饰用 `war3mapImported\SpiderRingItem.mdl`，接近守护指环的绿金色首饰用 `war3mapImported\RingOfProtection.mdl`。
- 高级 Boss 掉落特殊道具可用：`war3mapImported\ItemNerzhulMask.mdx`。
- 手套 / 护腕默认模型：`war3mapImported\Gloves.mdl`。
- 道具类容器 / 圣瓮 / 壶状器物默认模型：`war3mapImported\Urn.mdl`。
- 普通低级头盔第二套模型：`war3mapImported\equipment_helmet.mdl`。
- 卡牌默认模型：`war3mapImported\2CardItemEQuake.mdl`。
- 能量物品默认模型：`Objects\InventoryItems\CrystalShard\CrystalShard.mdl`。
- 战斗中临时拾取的神符 / 碎片 / 祝福类消耗品默认模型：`Objects\InventoryItems\runicobject\runicobject.mdl`。
- 法杖默认模型：`war3mapImported\SylvanEdge.mdl`。
- 斧 / 锤通用模型：`Common\Model\wepon\zb10.mdx`；正经锤子模型：`war3mapImported\TheDoomhammer.mdl`。
- 弓默认模型：`Common\Model\wepon\zb16.mdx`。
- 匕首默认模型：`Common\Model\wepon\zb5.mdx`。
- 恶魔剑 / Boss 剑默认模型：`Common\Model\wepon\zb12.mdx`。
- 普通剑默认模型：`war3mapImported\Sword.mdl`。
- 正义剑 / 王剑默认模型：`war3mapImported\ysj.mdx`。

## 装备物编分类规则

- 装备物编 `classification` 对应物编里的物品分类字段 `icla`。
- 主武器分类默认写 `Campaign`（战役）。
- 饰品 / 道具 / 戒指 / 护腕等装备向道具默认写 `PowerUp`（力量提升）。
- 任务物品统一放在物编分类 `Charged`（可充），并放入 `objediting\Equipment\QuestItem\`；TS 数据里仍写 `type: "任务"` 表达业务语义。
- 材料 / 消耗品默认写 `Charged`（可充）。
- 可购买物品 / 药剂默认写 `Purchasable`（可购买）。
- 人造物品 / 额外特殊收纳物默认写 `Artifact`（人造）。
- `Soul` 目录下的灵魂物品默认写 `Miscellaneous`（混杂）。
- 其它装备分类默认写 `Permanent`（永久），例如衣服、鞋子、裤子、头盔、副武器、双手武器等。
- 消耗品、Buff 和战斗临时拾取物的提示文本必须写清楚实际数值，例如持续时间、移动速度百分比、伤害、冷却、触发概率；不要只写“短时间内提高”“获得少量加成”这类模糊描述。

## 装备物编售价规则

- 正式装备默认按 `score * 20%` 计算物编 `goldcost`；`score` 来自 `TS/系统/02．物品系统/01．装备数据.ts`，物编 `createEquipmentItem` 也要同步填写 `score`。
- 默认 `priority` 与物编 `goldcost` 保持一致，避免旧的 `priority = 1000` 兜底继续污染排序/显示。
- 默认售价大于 0 的装备允许卖给商店；如果某件物品需要单独售价、不可出售或特殊可售性，必须在该物品的物遍 options 里显式写 `goldCost` / `salePrice` / `canBeSoldToMerchants`。
- 自定义物品提示 UI 的金币字段显示回收价，不显示物编 `goldcost` 原值；回收价口径为 `goldcost * 50%`。
