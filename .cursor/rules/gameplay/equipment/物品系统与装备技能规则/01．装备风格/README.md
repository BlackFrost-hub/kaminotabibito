# 装备风格基线

先读本页，再读取对应风格文件。风格文件只记录差异与尚未固化的口径，不重复通用原则。

## 通用原则

- 每件装备先明确核心角色与战斗价值，不能只堆属性。
- Boss 掉落应把 Boss 的视觉、元素或战斗风格转化为未来通用价值，不设计成专门反制已死亡 Boss 的战后解法。
- 新经验先补到本页；确属某一风格独有时再写入对应风格文件。
