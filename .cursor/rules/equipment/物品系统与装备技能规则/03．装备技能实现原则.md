# 装备技能实现原则

## 文件组织

- 一个物品 / 装备一个独立文件。
- 放在：`TS/系统/02．物品系统/15．装备技能/00．物品`

## index 规则

新建 / 追加 `index.ts` 时，只做：

```ts
export * from "./xxx";
```

不要做二次 `require`。

## 业务挂载规则

- 只有“伤害修正器自己”继续挂 `registerDamageCallback`。
- 业务侧受伤 / 命中逻辑优先挂：`registerAppliedFinalDamageListener`。

## 周期效果

- 除非确实必要，不要做“每 tick 扫玩家英雄单位组是否持有物品”。
- 若必须做持有型效果，用获取 / 丢弃注册与注销，不要靠每 tick 扫描物品持有状态。

## 计时器

- 全部走中心计时器。
- 不要自己单独创建原生 timer。

## 通用物品目录规则

目录：

- `TS/系统/02．物品系统/15．装备技能/00．物品/00．通用物品`

当前通用物品逻辑按功能拆分：

- `01．吃书清理.ts`
- `02．获取特效.ts`
- `03．合成打造.ts`
- `04．领取技能.ts`
- `01．传送集合/`

适合放这里的：

- 不属于“单件装备技能”的公共物品逻辑
- 任务物品
- 合成 / 打造类
- 传送门类
- 领取技能类

## 新增装备技能公共化

新增装备技能时，如果有 2 件以上装备复用同一类冷却、护盾、临时属性、反查逻辑，优先复用或补充 `TS/系统/03．技能系统/00．技能模板+函数/01．技能函数/20．物品辅助` 下的装备辅助 / 物品辅助分类工具，或复用既有机制组件。

不要在 `00．物品` 下新增“某某战利品公共.ts”这类装备组公共文件。数字物品文件应保持“一个编号 = 一个可测试/可发放装备”，组内共用逻辑要么下沉到物品辅助 / 机制组件，要么在唯一使用的单件装备文件内局部实现。

## 通用能力归属

装备技能目录只放“装备业务配置、装备名反查、装备注册表、单件装备效果”。如果能力未来也可能被单位技能、Boss 技能、召唤物技能、测试技能复用，必须优先放到 `TS/系统/03．技能系统/00．技能模板+函数`。

推荐归属：

- 物品获取 / 丢弃监听、物品次数转移、物品使用辅助、持有型周期效果：`01．技能函数/20．物品辅助`
- 普攻强化、攻击效果监听、攻击派生伤害、范围攻击效果工具：`01．技能函数/21．攻击效果`
- 同目标纯普攻计数触发：`01．技能函数/21．攻击效果/05．同目标普攻计数触发.ts`
- 配置型攻击效果的伤害计算、额外伤害、范围伤害、持续伤害、斩杀、击飞、临时属性等执行逻辑：`01．技能函数/21．攻击效果/01．配置型攻击效果`
- 装备叠层、累计承伤、距离减伤、延迟承伤、治疗护盾联动、控制 Debuff 联动：`04．机制组件/09．装备通用机制`
- 装备响应最终伤害后的概率触发、内置 CD、技能 / 普攻过滤：优先用 `04．机制组件/09．装备通用机制/11．最终伤害触发模板.ts`
- 临时百分比移速、临时固定移速，并且需要同步移动速度突破时：优先用 `01．技能函数/19．拓展效果/02．buff/04．移速提升.ts`

允许保留在装备侧的内容：

- 装备名列表、装备配置表、装备触发注册表。
- 单件装备独有且只有本装备使用的小函数。
- 为兼容旧引用保留的 re-export 壳文件；壳文件只能转发，不要继续写实现。

不要让 `TS/系统/03．技能系统/00．技能模板+函数` 反向 require `TS/系统/02．物品系统/15．装备技能`。

旧目录中已经存在的 `02．累计伤害`、`04．伤害事件`、`08．攻击效果` 属于历史装备侧聚合。新增装备不要照抄这些核心里的监听器；如果语义能用机制组件表达，优先走机制组件。老装备迁移时需要逐件对照行为，不能一次性机械替换。

## 优先复用机制组件

装备技能出现以下语义时，优先查 `TS/系统/03．技能系统/00．技能模板+函数/04．机制组件/09．装备通用机制`，不要在单件装备里重新手写监听器：

- 普攻 / 伤害 / 施法叠层、满层消费、内置 CD、层数持续时间。
- X 秒内对同一敌人纯普攻 X 次后触发额外效果。
- 进入战斗状态后每 X 秒获得强化，或持续战斗 X 秒后获得下一次普攻强化。
- X 秒内累计承伤后触发护盾、减伤、治疗等效果。
- 距离减伤、延迟承伤、单次承伤上限。
- 根据已损失生命 / 魔法获得档位收益。
- 治疗、获得护盾、给予队友治疗 / 护盾后的额外效果。
- 施加控制或 Debuff 后的额外效果。
- 装备在最终伤害结算后触发额外伤害、治疗、护盾、临时属性、控制或范围效果。

## 普攻与攻击效果语义

- “纯普攻 / 普通攻击 / 右键普攻”要求：`isNormalAttack === true`，并且 `isSkillAttack/isSkillDamage` 都不是 `true`。
- “技能普攻 / 攻击效果 / 攻击特效”可以走攻击伤害入口，但不能默认算纯普攻。
- 装备配置里的 `仅普通攻击: true` 必须理解为纯普攻过滤；如果装备文案写“攻击效果/攻击特效/技能普攻也触发”，不要使用 `仅普通攻击`。
- `添加强化普攻` 默认只会被纯普攻消耗；只有明确需要技能普攻也消耗强化时，才传 `允许技能普攻: true`。
