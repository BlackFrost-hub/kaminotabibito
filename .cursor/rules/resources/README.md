# 资源规则索引

本目录集中存放“资源生产、资源命名、资源临时目录、正式导入路径、外置包打包”的规则，避免资源规则散落在 `tooling/`、`gameplay/` 或具体 Boss 目录里。

## 分类

| 目录 | 内容 |
|------|------|
| [`audio/`](audio/) | AI 音效、Boss SFX、Boss Voice、试听目录、音频封装播放、外置语音 MIX 包 |
| [`visual/`](visual/) | 模型、贴图、特效资源路径与导入约定 |

## 使用原则

1. 做 Boss 音效、配音、外置语音包时，先读 `audio/README.md`。
2. 做模型、贴图、特效、导入路径时，先读 `visual/README.md`。
3. `audio_temp/` 只用于试听和候选，不代表已经迁入 `imports/`。
4. 用户确认前，不要把 AI 生成资源迁入 `imports/`，不要接入代码。
5. 资源最终落地时，需要同时记录临时路径、建议正式路径、规格和语义备注。
