# 生成工作流

## 执行摘要

1. 先确定角色声线、中文显示台词、英文 TTS 文本和触发场景。
2. 使用 `eleven_v3` 生成到 `audio_temp/Boss/<BossKey>/Voice/`，用户确认前不接代码。
3. 用户确认后记录配置与 `voice_pack_manifest/Boss/<BossKey>.json`；Voice 不迁入地图 `imports`。
4. 代码使用 `Sound/Boss/<BossKey>/Voice/<file>.mp3`，该路径必须与 MIX target 完全一致。
5. 只有 manifest 变化且用户要求更新外置包时，才重建 MPQ/MIX。

## 适用范围

- 用于 Boss 台词 / Voice 生成。
- 试听稿必须先生成到 `audio_temp`。
- Voice 不迁入地图 `imports`；用户确认前不要接入代码播放或写入 manifest。
- 游戏内中文系统消息和 AI 配音文本可以分开记录：`台词` 保持中文，`配音台词` 可记录英文 TTS 文本。
- 普通 Boss Voice 默认不允许同时播放两句台词；新一句播放前应停止上一句。只有双重人格、多实体、多声部等明确设定，才可在配置里显式允许重叠。
- 怪物拟声 / Creature Vocal SFX 不是 Voice 台词。拟声可以做机制补层，但不要和剧情台词、宝箱、系统提示混用。

## 默认路径

```text
试听源文件：C:\Users\Administrator\Desktop\syzl\audio_temp\Boss\<BossKey>\Voice\
MIX 内部路径：Sound/Boss/<BossKey>/Voice/
manifest：voice_pack_manifest/Boss/<BossKey>.json
```

## 本地生成脚本

```powershell
python scripts\elevenlabs_tts_generation.py "TEXT" "OUTPUT_PATH" VOICE_ID MODEL_ID STABILITY SIMILARITY_BOOST STYLE SPEED OUTPUT_FORMAT USE_SPEAKER_BOOST LANGUAGE_CODE
```

推荐基线：

```text
MODEL_ID: eleven_v3
OUTPUT_FORMAT: mp3_44100_128
LANGUAGE_CODE: en
```

确认方向后，或用户担心体积时，压缩为 64kbps mono：

```powershell
ffmpeg -y -i input.mp3 -ar 44100 -ac 1 -b:a 64k output_64k.mp3
```

## ElevenLabs v3 注意

- `[angry]`、`[stern]`、`[fading]`、`[coughs weakly]` 这类情绪 / 表演标签优先用 `eleven_v3`。
- 不要用 `eleven_multilingual_v2` 生成带英文情绪标签的台词，它可能把标签本身读出来。
- 优先使用短而明确的情绪标签，不要默认塞整段导演提示词。
- 写英文 `配音台词` 前先读 `09-配音台词与分段提示词.md`。如果一句话前后情绪有转折，可以在句中加入第二个情绪标签改变后半句语气；短句不要强行塞多段标签。
- 战斗台词不要过慢、过悠闲；除非是开场宣判、死亡收束、仪式感台词。

较好的写法：

```text
[stern] No blood is to be spilled in Moonlit Grove. [cold] Not by outsiders. Not by anyone.
```

## 确认配音时必须记录

- Boss / BossKey / 单位 ID。
- 场景与触发锚点。
- Voice ID 和声线名。
- Model ID。
- 实际 TTS 文本。
- 临时绝对路径。
- MIX 内部 target：`Sound/Boss/<BossKey>/Voice/<file>.mp3`。
- 规格：mp3、采样率、声道、kbps、时长、文件大小。
- 状态：仍在 `audio_temp`、是否写入配置/manifest、是否已重建并部署 MIX。
