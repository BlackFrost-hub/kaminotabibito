## 选择原则

- 先按角色语义选分类，不要只看 voice 名字。
- 如果角色要说清楚长台词，优先选“可读性强”的人形声线。
- 如果只是机制拟声或短吼，可以选怪物化更强的声线。
- 带 `[angry]`、`[stern]`、`[fading]` 等情绪标签的英文台词优先使用 `eleven_v3`。
- 用户确认前，生成文件只放 `audio_temp`，不要迁入 `imports`，不要接代码。
